# B02 帳簿と伝票

## 要点3行 {#summary}

1. 仕訳帳と総勘定元帳が **主要簿**。取引の明細を記録するそのほかの帳簿が **補助簿**。
2. 伝票は3種類。現金が入る取引は **入金伝票**、現金が出る取引は **出金伝票**、現金が動かない取引は **振替伝票**。
3. 現金とそれ以外が混ざる取引は「分けて起票」か「全額を掛けにしてから入金・出金」で起票し、伝票は **仕訳日計表** に集計して総勘定元帳に転記する。

## 仕訳パターン {#patterns}

### 帳簿の種類 {#books}

| 区分 | 帳簿 | 記録するもの |
|---|---|---|
| 主要簿 | 仕訳帳 | すべての取引の仕訳(日付順) |
| 主要簿 | 総勘定元帳 | 勘定ごとの増減(T勘定の正式な形) |
| 補助簿(補助記入帳) | 現金出納帳、当座預金出納帳、小口現金出納帳、仕入帳、売上帳 | 特定の取引の明細 |
| 補助簿(補助元帳) | 商品有高帳、売掛金元帳、買掛金元帳、固定資産台帳 | 商品別・取引先別・資産別の明細 |

### 証ひょう {#vouchers}

取引の証拠になる書類が **証ひょう**(納品書、請求書、領収書、振込の控え、通帳や入出金明細など)。証ひょうを見て仕訳します。

**例** 文房具店を営む当社は、仕入先から次の請求書を受け取った。商品はすでに受け取っていて、代金は月末に支払う。

| 品物 | 数量 | 単価 | 金額 |
|---|--:|--:|--:|
| ボールペン(商品) | 50 | 1,200 | 60,000 |
| 合計 | | | 60,000 |

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕入 | 60,000 | 買掛金 | 60,000 |

### 3種類の伝票 {#slips}

| 伝票 | 使う取引 | 決まっている側 | 伝票に書くもの |
|---|---|---|---|
| 入金伝票 | 現金が入る | 借方は必ず現金 | 相手の科目(貸方)と金額 |
| 出金伝票 | 現金が出る | 貸方は必ず現金 | 相手の科目(借方)と金額 |
| 振替伝票 | 現金が動かない | なし | 借方・貸方の科目と金額(仕訳と同じ) |

**例1** 手数料 ¥20,000 を現金で受け取った。(仕訳: 現金 20,000 / 受取手数料 20,000)

| 入金伝票(科目) | 金額 |
|---|--:|
| 受取手数料 | 20,000 |

**例2** 文房具 ¥3,000 を現金で買い、すぐに使った。(仕訳: 消耗品費 3,000 / 現金 3,000)

| 出金伝票(科目) | 金額 |
|---|--:|
| 消耗品費 | 3,000 |

**例3** 商品 ¥80,000 を掛けで仕入れた。(現金が動かない)

| 振替伝票(借方科目) | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕入 | 80,000 | 買掛金 | 80,000 |

### 一部現金取引の2つの起票方法 {#partial}

**例4** 商品 ¥100,000 を売り上げ、代金のうち ¥30,000 は現金で受け取り、残りは掛けとした。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 現金 | 30,000 | 売上 | 100,000 |
| 売掛金 | 70,000 | | |

**方法A 取引を分けて起票する**(現金の分と掛けの分に分ける)

| 入金伝票(科目) | 金額 |
|---|--:|
| 売上 | 30,000 |

| 振替伝票(借方科目) | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売掛金 | 70,000 | 売上 | 70,000 |

**方法B 全額をいったん掛けにする**(全額を掛け売上にしてから、すぐに一部を回収したと考える)

| 振替伝票(借方科目) | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売掛金 | 100,000 | 売上 | 100,000 |

| 入金伝票(科目) | 金額 |
|---|--:|
| 売掛金 | 30,000 |

どちらの方法でも、合わせた結果(現金 +30,000、売掛金 +70,000、売上 100,000)は同じです。問題文の指示や、すでに書かれている伝票から、どちらの方法かを読み取ります。

## T勘定・ボックス図 {#t-account}

### 補助簿の選び方 {#choose-books}

仕訳に出てくる **科目ごとに** 補助簿を思い浮かべます。

| 仕訳に出てくる科目 | 書く補助簿 |
|---|---|
| 現金 | 現金出納帳 |
| 当座預金 | 当座預金出納帳 |
| 仕入 | 仕入帳 と 商品有高帳 |
| 売上 | 売上帳 と 商品有高帳 |
| 売掛金 | 売掛金元帳 |
| 買掛金 | 買掛金元帳 |
| 建物・備品・車両運搬具・土地 | 固定資産台帳 |
| 未払金・未収入金・借入金など | なし(補助簿はない) |

例: 「商品を売り上げ、代金のうち一部は現金、残りは掛け」→ 仕訳の科目は 現金・売掛金・売上 → **現金出納帳、売掛金元帳、売上帳、商品有高帳**

### 仕訳日計表:1日分の伝票を集計する {#daily}

ある日の伝票が次のとおりだったとします。

- 入金伝票: 売上 50,000、売掛金 40,000
- 出金伝票: 仕入 30,000、消耗品費 5,000
- 振替伝票: 売掛金 60,000 / 売上 60,000、仕入 25,000 / 買掛金 25,000

**仕訳日計表**(勘定ごとに、借方と貸方の合計を書く)

| 借方 | 勘定科目 | 貸方 |
|--:|---|--:|
| 90,000 | 現金 | 35,000 |
| 60,000 | 売掛金 | 40,000 |
| | 買掛金 | 25,000 |
| | 売上 | 110,000 |
| 55,000 | 仕入 | |
| 5,000 | 消耗品費 | |
| 210,000 | 合計 | 210,000 |

- 現金の借方 = 入金伝票の合計、現金の貸方 = 出金伝票の合計
- 合計 = すべての伝票の金額の合計(入金 90,000 + 出金 35,000 + 振替 85,000 = 210,000)
- 総勘定元帳へは、仕訳日計表から勘定ごとにまとめて転記します(相手科目の欄は「仕訳日計表」)。

## 引っかけポイント {#traps}

1. 入金伝票・出金伝票の科目欄に **「現金」と書かない**。書くのは相手の科目。
2. 振替伝票は現金が動かない取引だけ。方法B(全額を掛けにする)では、振替伝票の金額は取引の **全額**。
3. 未払金・未収入金・借入金には補助簿がない。備品を後払いで買っても **買掛金元帳には書かない**(書くのは固定資産台帳)。
4. 商品の仕入・売上は、仕入帳・売上帳だけでなく **商品有高帳** にも書く。
5. 証ひょうの送料など、買うためにかかった費用(付随費用)は、備品などの金額に含める。→ [B09](B09.md)

## 決算書ではここに出る {#fs}

帳簿と伝票は決算書の元データです。決算書の数字は総勘定元帳の残高から作られます。M&Aの調査(デューデリジェンス)では、売掛金元帳などの補助簿で「残高の相手先はどこか、回収が遅れていないか」を確かめます。
