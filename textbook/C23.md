# C23 株主資本等変動計算書

## 要点3行 {#summary}

1. **株主資本等変動計算書** は、純資産の部の各項目が、1年間で **なぜ・いくら** 変わったかを示す表。当期首残高 + 当期変動額 = 当期末残高。
2. 株主資本(資本金・資本剰余金・利益剰余金)は、新株の発行・剰余金の配当・当期純利益などの **変動事由ごと** に書く。
3. その他有価証券評価差額金(評価・換算差額等)は、事由に分けず **当期変動額(純額)** の1行にまとめて書く。

## 仕訳パターン {#patterns}

この章の例は、次の会社の1年間です(当期首の純資産)。

| 項目 | 当期首残高 |
|---|--:|
| 資本金 | 5,000,000 |
| 資本準備金 | 600,000 |
| その他資本剰余金 | 100,000 |
| 利益準備金 | 300,000 |
| 繰越利益剰余金 | 1,200,000 |
| その他有価証券評価差額金 | 40,000 |

### 剰余金の配当 {#dividend}

**例1** 株主総会で、繰越利益剰余金から ¥400,000 の配当を決め、利益準備金を ¥40,000 積み立てた(10分の1。積立の上限は C19)。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 繰越利益剰余金 | 440,000 | 未払配当金 | 400,000 |
| | | 利益準備金 | 40,000 |

株主資本等変動計算書では「剰余金の配当」の行に、繰越利益剰余金 △440,000、利益準備金 +40,000 と書きます。

### 新株の発行 {#issue}

**例2** 新株 1,000株を 1株 ¥1,000 で発行し、払込金は当座預金とした。資本金は会社法で認められる最低限(2分の1)とする。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 当座預金 | 1,000,000 | 資本金 | 500,000 |
| | | 資本準備金 | 500,000 |

### 当期純利益と評価差額金 {#income}

**例3** 当期純利益は ¥700,000 だった(損益 / 繰越利益剰余金)。その他有価証券評価差額金の当期末残高は ¥70,000 になった。

- 繰越利益剰余金は「当期純利益」の行で +700,000
- その他有価証券評価差額金は、期末 70,000 − 期首 40,000 = 30,000 を「株主資本以外の項目の当期変動額(純額)」の行に書く

## T勘定・ボックス図 {#t-account}

### 株主資本等変動計算書(縦にした形) {#statement}

本当の表は、項目を横に並べた大きな表です。ここでは見やすいように、項目を縦に並べます。

| 項目 | 当期首 | 当期変動額 | 当期末 |
|---|--:|--:|--:|
| 資本金 | 5,000,000 | 500,000 | 5,500,000 |
| 資本準備金 | 600,000 | 500,000 | 1,100,000 |
| その他資本剰余金 | 100,000 | 0 | 100,000 |
| 利益準備金 | 300,000 | 40,000 | 340,000 |
| 繰越利益剰余金 | 1,200,000 | 260,000 | 1,460,000 |
| 評価差額金 | 40,000 | 30,000 | 70,000 |
| 純資産合計 | 7,240,000 | 1,330,000 | 8,570,000 |

評価差額金は、その他有価証券評価差額金です。

### 繰越利益剰余金の変動事由 {#retained}

| 変動事由 | 金額 |
|---|--:|
| 当期首残高 | 1,200,000 |
| 剰余金の配当(配当 + 利益準備金の積立) | △440,000 |
| 当期純利益 | 700,000 |
| 当期末残高 | 1,460,000 |

純資産合計の変動は、新株の発行 +1,000,000、配当の支払い △400,000(積立の 40,000 は純資産の中の移動なので合計は変わらない)、当期純利益 +700,000、評価差額金 +30,000 です。

> [!覚える]
> - 当期首残高 + **当期変動額** = 当期末残高
> - 剰余金の配当の行: 繰越利益剰余金は **配当 + 積立額** だけ減り、利益準備金は積立額だけ増える
> - 新株の発行の行: **資本金と資本準備金** が増える
> - その他有価証券評価差額金は **純額** で1行にまとめる

## 引っかけポイント {#traps}

1. 繰越利益剰余金の減少は、配当額だけでなく、利益準備金の積立額も含む。
2. 利益準備金の積立は、純資産の中での移動なので、純資産合計は配当額だけ減る。
3. 新株の発行で資本金を2分の1にしたときは、残りを資本準備金にする。
4. 評価差額金は、増えた理由(時価の上昇・売却など)に分けず、期末 − 期首の純額で書く。

## 決算書ではここに出る {#fs}

株主資本等変動計算書は、損益計算書・貸借対照表と並ぶ決算書の1つです。M&Aでは、配当をどれだけ出しているか(当期純利益に対する割合)や、増資で資金を集めているかを確かめます。利益に比べて配当が多すぎる会社は、手元の資金が減っていきます。
