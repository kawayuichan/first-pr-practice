# B09 有形固定資産①

## 要点3行 {#summary}

1. 建物・備品・車両運搬具・土地は、**購入代価 + 付随費用**(運送費・据付費・仲介手数料など)で記録する。価値を高める改良は資産に加え、元に戻すだけの修繕は修繕費。
2. 決算で、使った分を **減価償却費** にする。定額法 = (取得原価 − 残存価額)÷ 耐用年数、定率法 = 期首の帳簿価額 × 償却率。**間接法** で減価償却累計額を使い、期の途中で買った・売ったときは **月割**。
3. 売却は「売却価額 − 帳簿価額」が売却益・売却損。除却・廃棄は帳簿価額を **固定資産除却損** にする(売れる見込みの分は貯蔵品)。

## 仕訳パターン {#patterns}

### 買ったとき(付随費用) {#acquire}

**例1** 備品 ¥400,000 を購入し、運送費 ¥10,000 と据付費 ¥20,000 とあわせて、代金は月末に支払うことにした。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 備品 | 430,000 | 未払金 | 430,000 |

- 使える状態にするまでにかかった費用(**付随費用**)は、取得原価に含める
- 土地なら、仲介手数料・登記費用・整地費用なども土地の取得原価
- 商品ではないので、代金をあとで払うなら買掛金ではなく **未払金**(B07)

### 改良と修繕 {#improve}

**例2** 建物の改良と修繕を行い、代金 ¥500,000 を普通預金口座から支払った。このうち ¥300,000 は建物の価値を高める改良で、残りは元の状態に戻す修繕である。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 建物 | 300,000 | 普通預金 | 500,000 |
| 修繕費 | 200,000 | | |

- 価値が上がる・使える年数が延びる **改良**(資本的支出)→ 建物などの資産に加える
- 壊れたところを元に戻すだけの **修繕**(収益的支出)→ 修繕費(費用)

### 減価償却(定額法・定率法) {#depreciation}

**例3(定額法)** 決算で、備品(取得原価 ¥800,000、残存価額ゼロ、耐用年数8年)の減価償却を定額法で行う。記帳は間接法。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 減価償却費 | 100,000 | 備品減価償却累計額 | 100,000 |

- 定額法:(取得原価 − 残存価額)÷ 耐用年数。毎年 **同じ額**
- 残存価額が「取得原価の10%」なら、取得原価から10%を引いてから割る
- **間接法**: 備品は減らさず、**減価償却累計額** に積み上げる(備品減価償却累計額。減価償却累計額でもよい)

**例4(定率法)** 例3の備品を、定率法(償却率 0.25)で償却する場合。

| 年 | 計算 | 減価償却費 |
|---|---|--:|
| 1年目 | 800,000 × 0.25 | 200,000 |
| 2年目 | (600,000)× 0.25 | 150,000 |

- 定率法:**期首の帳簿価額**(取得原価 − 減価償却累計額)× 償却率。はじめに多く、だんだん少なくなる
- 3級の問題では償却率が与えられる。200%定率法の保証率・改定償却率は2級(C11)で学ぶ

### 期の途中で買ったとき(月割) {#monthly}

**例5** 会計期間は4月1日から3月31日まで。12月1日に備品 ¥360,000(残存価額ゼロ、耐用年数5年、定額法)を購入した。決算での減価償却費は?

- 1年分 = 360,000 ÷ 5 = 72,000
- 使ったのは12月〜3月の **4か月** → 72,000 × 4/12 = 24,000

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 減価償却費 | 24,000 | 備品減価償却累計額 | 24,000 |

### 売ったとき {#sale}

**例6(期首に売却)** 備品(取得原価 ¥500,000、減価償却累計額 ¥300,000)を期首に ¥230,000 で売却し、代金は月末に受け取ることにした。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 未収入金 | 230,000 | 備品 | 500,000 |
| 備品減価償却累計額 | 300,000 | 固定資産売却益 | 30,000 |

帳簿価額 = 500,000 − 300,000 = 200,000。売却価額 230,000 のほうが多いので、差額が **固定資産売却益**(収益)。

**例7(期中に売却)** 会計期間は4月1日から3月31日まで。備品(取得原価 ¥600,000、期首の減価償却累計額 ¥360,000、定額法で1年分の償却費 ¥120,000)を9月30日に ¥150,000 で売却し、代金は現金で受け取った。当期の減価償却費は月割で計上する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 備品減価償却累計額 | 360,000 | 備品 | 600,000 |
| 減価償却費 | 60,000 | | |
| 現金 | 150,000 | | |
| 固定資産売却損 | 30,000 | | |

- 4月〜9月の **6か月分** の減価償却費 60,000 を先に計上する
- 売る直前の帳簿価額 = 600,000 − 360,000 − 60,000 = 180,000
- 売却価額 150,000 のほうが少ないので、差額が **固定資産売却損**(費用)

### 除却・廃棄したとき {#disposal}

**例8(除却)** 備品(取得原価 ¥400,000、減価償却累計額 ¥320,000)を除却した。この備品は ¥30,000 で売れる見込みがある。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 備品減価償却累計額 | 320,000 | 備品 | 400,000 |
| 貯蔵品 | 30,000 | | |
| 固定資産除却損 | 50,000 | | |

**例9(廃棄)** 備品(取得原価 ¥300,000、減価償却累計額 ¥270,000)を廃棄し、廃棄のための費用 ¥10,000 を現金で支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 備品減価償却累計額 | 270,000 | 備品 | 300,000 |
| 固定資産除却損 | 40,000 | 現金 | 10,000 |

- **除却** = 使うのをやめて帳簿から外す。売れる見込みの額は **貯蔵品**(資産)にする
- **廃棄** = 捨てる。廃棄にかかった費用も損失に含める
- 公式の勘定科目表では、どちらも標準の科目は **固定資産除却損**(固定資産廃棄損でもよい)

## T勘定・ボックス図 {#t-account}

### 定額法と定率法の比べ {#compare}

例3・例4の備品(取得原価 ¥800,000)の3年間です。帳簿価額 = 取得原価 − 減価償却累計額。

**減価償却費**

| 年 | 定額法 | 定率法 |
|---|--:|--:|
| 1年目 | 100,000 | 200,000 |
| 2年目 | 100,000 | 150,000 |
| 3年目 | 100,000 | 112,500 |

**期末の帳簿価額**

| 年 | 定額法 | 定率法 |
|---|--:|--:|
| 1年目 | 700,000 | 600,000 |
| 2年目 | 600,000 | 450,000 |
| 3年目 | 500,000 | 337,500 |

定率法は、はじめの年に多く費用にし、だんだん少なくなります。

### 固定資産台帳 {#ledger}

固定資産台帳は、固定資産ごとの明細です。当期末の例で、備品Aは例3の備品(定額法、購入から2年目)、備品Bは例5の備品(12月1日に購入)です。

| 項目 | 備品A | 備品B |
|---|--:|--:|
| 取得原価 | 800,000 | 360,000 |
| 期首の累計額 | 100,000 | 0 |
| 当期の償却費 | 100,000 | 24,000 |
| 期末の帳簿価額 | 600,000 | 336,000 |

期末の帳簿価額 = 取得原価 − 期首の累計額 − 当期の償却費。

> [!覚える]
> - 取得原価 = **購入代価 + 付随費用**。改良は資産、修繕は **修繕費**
> - 定額法 = **(取得原価 − 残存価額)÷ 耐用年数**
> - 定率法 = **期首の帳簿価額 × 償却率**
> - 期の途中で買った・売ったら **月割**
> - 売却益・売却損 = **売却価額 − 帳簿価額**。除却で売れる見込みの分は **貯蔵品**

## 引っかけポイント {#traps}

1. 運送費・据付費・仲介手数料などの **付随費用** は取得原価に含める。費用にしない。
2. 価値が上がる **改良** は資産、元に戻すだけの **修繕** は修繕費。
3. 定率法は **期首の帳簿価額** × 償却率。取得原価にかけるのは1年目だけ。
4. 期の途中で買ったら、使った月数だけ月割。期の途中で売ったら、先に売る月までの減価償却費を計上する。
5. 売却益・売却損は「売却価額 − **帳簿価額**」。取得原価と比べない。
6. 除却で売れる見込みの分は **貯蔵品**。廃棄の費用は固定資産除却損に含める。

## 決算書ではここに出る {#fs}

貸借対照表の「有形固定資産」に、取得原価から減価償却累計額を差し引いて表示します。損益計算書では、減価償却費は「販売費及び一般管理費」(工場の分は製造原価)、売却益・売却損・除却損は特別利益・特別損失になることが多いです。M&Aでは、減価償却費は **お金が出ていかない費用** なので、営業利益に足し戻した EBITDA(イービットディーエー)で会社の稼ぐ力を比べます。減価償却累計額が取得原価に近い会社は設備が古く、近いうちに買い替えのお金が必要になるかもしれません。
