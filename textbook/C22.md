# C22 財務諸表の作成

## 要点3行 {#summary}

1. 2級の損益計算書は **報告式**。売上総利益 → **営業利益** → **経常利益** → 税引前当期純利益 → 当期純利益の順に、段階ごとの利益を出す。
2. 貸借対照表は **区分表示**。資産は流動資産と固定資産(有形・無形・投資その他の資産)、負債は流動負債と固定負債、純資産は株主資本と評価・換算差額等に分ける。
3. 流動か固定かは、営業の取引から生じたもの(売掛金・商品・買掛金など)は **正常営業循環基準** で流動、それ以外は **1年基準**(決算日の翌日から1年以内なら流動)で決める。

## 仕訳パターン {#patterns}

財務諸表は、決算整理後残高試算表(C21)の金額を、決まった形に並べ直したものです。新しい仕訳はありません。

| 項目 | 金額 |
|---|--:|
| Ⅰ 売上高 | 5,000,000 |
| Ⅱ 売上原価 | 3,416,000 |
| 売上総利益 | 1,584,000 |
| Ⅲ 販売費及び一般管理費 | 894,000 |
| 営業利益 | 690,000 |
| Ⅳ 営業外収益 | 35,000 |
| Ⅴ 営業外費用 | 25,000 |

| Ⅵ 特別利益 | 40,000 |
| Ⅶ 特別損失 | 60,000 |
| 税引前当期純利益 | 680,000 |
| 法人税、住民税及び事業税 | 210,000 |
| 法人税等調整額 | △6,000 |
| 当期純利益 | 476,000 |

資料の内訳は次のとおりです。

- 売上原価: 期首商品 300,000 + 当期仕入 3,500,000 − 期末商品 400,000 に、棚卸減耗損 10,000 と商品評価損 6,000 を加える
- 販売費及び一般管理費: 給料 700,000、減価償却費 150,000、貸倒引当金繰入(売掛金の分)8,000、保険料 36,000
- 営業外収益: 受取配当金 20,000、有価証券評価益 15,000。営業外費用: 支払利息 25,000
- 特別利益: 固定資産売却益 40,000。特別損失: 火災損失 60,000
- 法人税等調整額 △6,000 は貸方の残高(税金の費用を減らす)

### 損益計算書と貸借対照表のつながり {#link}

**例3** 損益勘定で計算した当期純利益を、繰越利益剰余金に振り替える(例1の当期純利益)。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 損益 | 476,000 | 繰越利益剰余金 | 476,000 |

損益計算書の当期純利益は、この振替で貸借対照表の純資産(繰越利益剰余金)を増やします。だから、2つの表は当期純利益でつながっています。

### 損益計算書の区分 {#pl-sections}

| 区分 | 主な科目 |
|---|---|
| 販売費及び一般管理費 | 給料、広告宣伝費、減価償却費、貸倒引当金繰入(売掛金など) |
| 営業外収益 | 受取利息、受取配当金、有価証券利息、有価証券評価益 |
| 営業外費用 | 支払利息、有価証券評価損、貸倒引当金繰入(貸付金など) |
| 特別利益 | 固定資産売却益 |
| 特別損失 | 固定資産売却損、火災損失 |

> [!覚える]
> - 売上総利益 − 販管費 = **営業利益**、± 営業外 = **経常利益**、± 特別 = 税引前当期純利益
> - 売掛金・商品・買掛金は **正常営業循環基準** で流動
> - それ以外は **1年基準**(決算日の翌日から1年以内なら流動)
> - 繰越商品 → **商品**、売買目的有価証券 → **有価証券**、満期保有・その他 → **投資有価証券**

## 引っかけポイント {#traps}

1. 固定資産売却益・火災損失は特別損益。経常利益には入れない。
2. 貸倒引当金繰入は、売掛金など営業の債権の分は販売費及び一般管理費、貸付金など営業外の債権の分は営業外費用。
3. 貸付金や前払費用は、決算日の翌日から1年を超える分を固定資産(長期貸付金・長期前払費用)にする。
4. 法人税等調整額が貸方の残高なら、法人税、住民税及び事業税から差し引く。

## 決算書ではここに出る {#fs}

この章で作るものが、決算書そのものです。M&Aでは、営業利益(本業のもうけ)と経常利益・当期純利益の差を見て、利益が本業から出ているか、資産の売却など一時的なものかを確かめます。貸借対照表では、流動資産と流動負債を比べて、1年以内の支払いに困らないか(流動比率)を見ます。
