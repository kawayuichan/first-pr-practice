# K10 標準原価計算

## 要点3行 {#summary}

1. 製品1個あたりの目標の原価(**標準原価カード**)を決め、標準原価 = 1個あたりの標準 × 数量で計算する。実際原価との差が **標準原価差異**。
2. 差異は原因ごとに分ける。直接材料費は **価格差異・数量差異**、直接労務費は **賃率差異・時間差異**、製造間接費は **予算差異・能率差異・操業度差異**。
3. 記帳は、仕掛品勘定で差異を出す **パーシャル・プラン** と、材料などの勘定で差異を出す **シングル・プラン**。差異は年度末に **売上原価** に加減する。

## 仕訳パターン {#patterns}

この章の例は、次の標準原価カードの工場です。

**標準原価カード(製品1個あたり)**

| 費目 | 標準 | 金額 |
|---|---|--:|
| 直接材料費 | ¥200 × 3kg | 600 |
| 直接労務費 | ¥1,000 × 0.5時間 | 500 |
| 製造間接費 | ¥800 × 0.5時間 | 400 |
| 合計 | | 1,500 |

製造間接費は公式法変動予算で、変動費率 ¥300、固定費の月間予算 ¥250,000、基準操業度 500時間(固定費率 500)。

### 当月の標準原価 {#standard}

**例1** 当月の生産は、月初仕掛品 100個(進捗度 50%)、完成品 900個、月末仕掛品 200個(進捗度 50%)。直接材料は始点で投入する。

| | 計算 | 標準原価 |
|---|---|--:|
| 完成品 | 900 × 1,500 | 1,350,000 |
| 月初仕掛品 | 100 × 600 + 50 × 900 | 105,000 |
| 月末仕掛品 | 200 × 600 + 100 × 900 | 210,000 |

仕掛品の加工費(直接労務費・製造間接費)は、完成品換算量に1個あたりの標準(500 + 400 = 900)をかけます。

差異の計算では、**当月投入** の量を使います。

- 直接材料の当月投入: 完成 900 + 月末 200 − 月初 100 = 1,000個 → 標準消費量 3,000kg
- 加工の当月投入(換算量): 900 + 100 − 50 = 950個 → 標準直接作業時間 475時間

### 差異の分析 {#variance}

**例2** 当月の実際原価は、直接材料費 ¥635,500(3,100kg × ¥205)、直接労務費 ¥489,600(480時間 × ¥1,020)、製造間接費 ¥395,000。

| 差異 | 計算 | 金額 |
|---|---|--:|
| 価格差異 | (標準単価 − 実際単価)× 実際消費量 | -15,500 |
| 数量差異 | 標準単価 ×(標準消費量 − 実際消費量) | -20,000 |
| 賃率差異 | (標準賃率 − 実際賃率)× 実際時間 | -9,600 |
| 時間差異 | 標準賃率 ×(標準時間 − 実際時間) | -5,000 |
| 予算差異 | 予算許容額 − 実際発生額 | -1,000 |
| 能率差異 | 標準配賦率 ×(標準時間 − 実際時間) | -4,000 |
| 操業度差異 | 固定費率 ×(実際時間 − 基準操業度) | -10,000 |

マイナスは不利差異(借方)です。予算許容額は 300 × 480 + 250,000 = 394,000。この章では、能率差異は変動費と固定費の両方から計算します(標準配賦率を使う)。

### パーシャル・プラン {#partial}

仕掛品勘定の借方に **実際原価**、貸方に **標準原価** を書き、差額(差異)を仕掛品勘定から振り替えます。

**例3** 例2の実際原価を仕掛品に振り替え、完成品を標準原価で製品に振り替え、差異を振り替える。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕掛品 | 1,520,100 | 材料 | 635,500 |
| | | 賃金・給料 | 489,600 |
| | | 製造間接費 | 395,000 |
| 製品 | 1,350,000 | 仕掛品 | 1,350,000 |

差異は、当月投入の標準原価 1,455,000 と実際原価 1,520,100 の差 65,100(不利)で、例2の7つの差異の合計と一致します。仕訳は、借方が各差異、貸方が仕掛品です。

### シングル・プラン {#single}

材料・賃金・製造間接費の勘定で差異を出し、仕掛品勘定には **借方も貸方も標準原価** だけを書きます。

**例4** 例2の直接材料の消費を、シングル・プランで記帳する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕掛品 | 600,000 | 材料 | 635,500 |
| 価格差異 | 15,500 | | |
| 数量差異 | 20,000 | | |

### 年度末の処理(売上原価加減法) {#year-end}

**例5** 会計年度末に、数量差異の借方残高 ¥30,000(不利)と、賃率差異の貸方残高 ¥8,000(有利)を売上原価に振り替えた。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売上原価 | 22,000 | 数量差異 | 30,000 |
| 賃率差異 | 8,000 | | |

不利差異は売上原価に加え、有利差異は売上原価から差し引きます(この例では差し引きして 22,000 を加算)。

## T勘定・ボックス図 {#t-account}

### 直接材料費の差異の図 {#box}

縦が単価、横が数量の図で考えます。外側の長方形が実際、内側が標準です。

| | 標準消費量 3,000kg | 差 100kg |
|---|---|---|
| 実際単価 ¥205 | 価格差異 15,000 | 価格差異 500 |
| 標準単価 ¥200 | 標準原価 600,000 | 数量差異 20,000 |

価格差異は実際消費量全体(3,000 + 100 = 3,100kg)に、数量差異は標準単価にかけます。

### パーシャル・プランの仕掛品勘定 {#t-wip}

**仕掛品**

| 借方 | 貸方 |
|---|---|
| 月初(標準)105,000 | 製品(標準)1,350,000 |
| 当月の実際原価 1,520,100 | 原価差異 65,100 |
| | 月末(標準)210,000 |

> [!覚える]
> - 標準原価は、1個あたりの標準 × **当月投入**(材料は数量、加工費は換算量)
> - 価格差異・賃率差異は **実際の量(時間)** にかける
> - 数量差異・時間差異・能率差異は **標準の単価・率** にかける
> - 操業度差異 = **固定費率 ×(実際時間 − 基準操業度)**
> - パーシャルは **仕掛品** で、シングルは **材料などの勘定** で差異を出す

## 引っかけポイント {#traps}

1. 標準消費量・標準時間は、完成品数量ではなく当月投入の量(材料は数量、加工は換算量)で計算する。
2. 価格差異は「標準 − 実際」で計算し、マイナスなら不利。実際消費量にかける(標準消費量にかけない)。
3. 能率差異を変動費と固定費の両方から計算するときは、標準配賦率を使う。操業度差異は固定費率だけ。
4. パーシャル・プランでは、仕掛品勘定の借方は実際原価、貸方は標準原価。
5. 有利差異は、年度末に売上原価から差し引く。

## 決算書ではここに出る {#fs}

標準原価差異は、年度末に売上原価に加減されるので、損益計算書の売上原価に含まれます。M&Aでは、毎年大きな不利差異が出ている工場は、標準が甘い(古い)か、実際の効率が悪いかのどちらかなので、差異の中身と標準の見直し時期を確かめます。
