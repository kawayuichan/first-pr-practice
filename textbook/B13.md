# B13 決算①精算表

## 要点3行 {#summary}

1. 決算は「決算整理前の残高試算表 → **決算整理**(期末の正しい金額に直す) → 決算整理後残高試算表 → 損益計算書・貸借対照表」の順に進む。
2. **精算表(8桁)** は、試算表に修正記入を足し引きし、収益・費用は損益計算書の欄へ、資産・負債・純資産は貸借対照表の欄へ移す表。差額が当期純利益(純損失)。
3. 試算表は貸借の合計が必ず一致する(転記ミスの発見に使う)。**月次決算** では、減価償却費などを毎月見積もって計上し、決算では残りの月の分を計上する。

## 仕訳パターン {#patterns}

### 試算表 {#trial-balance}

試算表は、総勘定元帳の各勘定の金額を1つの表に集めたものです。

- **合計試算表**: 各勘定の借方合計と貸方合計を書く
- **残高試算表**: 各勘定の残高(借方合計と貸方合計の差)を書く
- **合計残高試算表**: 両方を書く

**例1** 現金勘定の借方合計が ¥500,000、貸方合計が ¥320,000 のとき、残高試算表の現金は借方に ¥180,000。

貸借の一致は「転記の金額の誤り」を見つける手がかりになります。ただし、仕訳そのものを忘れた・科目を間違えたなど、貸借が同じだけずれる誤りは見つけられません。

### 決算整理(まとめ) {#adjustments}

期中の記録を、期末の正しい金額に直す仕訳です。これまでの論点で学んだものが集まります。

| 決算整理 | 仕訳の例 | 学んだ論点 |
|---|---|---|
| 現金過不足の整理 | 雑損 / 現金過不足 など | B03 |
| 当座借越の振替 | 当座預金 / 当座借越 | B03 |
| 売上原価の計算 | 仕入 / 繰越商品、繰越商品 / 仕入 | B04 |
| 貸倒引当金 | 貸倒引当金繰入 / 貸倒引当金 | B08 |
| 減価償却 | 減価償却費 / 備品減価償却累計額 | B09 |
| 貯蔵品・経過勘定 | 貯蔵品 / 通信費、前払保険料 / 保険料 など | B10 |
| 消費税・法人税等 | 仮受消費税 / 仮払消費税・未払消費税 など | B11 |

**例2(売上原価の計算)** 期首商品棚卸高 ¥60,000、期末商品棚卸高 ¥70,000(売上原価は仕入勘定で計算する)。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕入 | 60,000 | 繰越商品 | 60,000 |
| 繰越商品 | 70,000 | 仕入 | 70,000 |

### 月次決算 {#monthly}

毎月の業績をすぐに知るため、1年分の費用を見積もって **毎月** 計上する方法です。

**例3** 備品の減価償却費の年間見積額は ¥120,000 で、毎月 ¥10,000 ずつ計上している。4月から2月までの11か月分は計上済みで、決算で3月分を計上する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 減価償却費 | 10,000 | 備品減価償却累計額 | 10,000 |

- 決算整理前の試算表には、すでに11か月分 110,000 が入っている
- 決算で計上するのは **残りの1か月分** だけ(1年分をもう一度計上しない)

精算表の読み方:

- 各行は「試算表 + 修正記入(同じ側) − 修正記入(反対側)」を、行き先の欄に書く。例: 仕入 = 620,000 + 60,000 − 70,000 = 610,000
- 収益・費用 → **損益計算書** の欄、資産・負債・純資産 → **貸借対照表** の欄
- 決算整理で新しく出てくる科目(貸倒引当金繰入・減価償却費)は、下に行を足して書く
- 損益計算書の欄の差額が **当期純利益**。損益計算書の借方と、貸借対照表の貸方に同じ金額を書くと、どちらの欄も貸借が一致する

### 決算整理後残高試算表 {#after-tb}

決算整理後残高試算表は、精算表の「試算表 + 修正記入」の結果を1つの表にしたものです。上の例では、仕入 610,000、繰越商品 70,000、貸倒引当金 6,000 のように、決算整理のあとの金額が並びます。

> [!覚える]
> - 決算の流れ: **試算表 → 決算整理 → 精算表・決算整理後残高試算表 → 財務諸表**
> - 精算表は **同じ側なら足す、反対側なら引く**
> - 収益・費用 → **損益計算書** の欄、資産・負債・純資産 → **貸借対照表** の欄
> - 当期純利益は、損益計算書の **借方** と貸借対照表の **貸方**
> - 月次決算では、決算で計上するのは **残りの月の分だけ**

## 引っかけポイント {#traps}

1. 試算表と修正記入が **同じ側なら足す、反対側なら引く**。
2. 収益・費用の行は損益計算書へ、資産・負債・純資産の行は貸借対照表へ。繰越商品(資産)と仕入(費用)を取り違えない。
3. 当期純利益は、損益計算書の欄では **借方**、貸借対照表の欄では **貸方** に書く(純損失なら逆)。
4. 月次決算では、決算整理前に11か月分が計上済みのことが多い。決算で計上するのは残りの月の分だけ。
5. 試算表の貸借が一致しても、仕訳を忘れた・科目を間違えたなどの誤りは見つけられない。

## 決算書ではここに出る {#fs}

精算表は、損益計算書と貸借対照表を作る前の下書きです。精算表の損益計算書の欄・貸借対照表の欄が、そのまま決算書の数字になります。M&Aでは、決算書のほかに **月次の試算表**(月次決算の結果)をよく求めます。最近の業績の動きや、季節による売上の波を確かめるためです。
