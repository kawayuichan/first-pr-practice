# K08 総合原価計算①

## 要点3行 {#summary}

1. 同じ製品を大量に作るときは、1か月分の原価をまとめて **完成品** と **月末仕掛品** に分ける(総合原価計算)。**直接材料費** と **加工費**(直接労務費・製造間接費など)に分けて計算する。
2. 月末仕掛品の加工費は、**完成品換算量**(数量 × 加工進捗度)で分ける。分け方は **平均法** と **先入先出法**。
3. 正常な仕損・減損の原価は、良品に負担させる(度外視法)。**終点** で発生したら **完成品だけ**、月末仕掛品の進捗度より前で発生したら **完成品と月末仕掛品の両方** が負担する。

## 仕訳パターン {#patterns}

### 完成品換算量 {#equivalent}

直接材料は工程の始点ですべて投入するので、月末仕掛品にも完成品と同じだけ入っています。加工費は、加工の進み具合(加工進捗度)に応じてかかります。

**例1** 月末仕掛品 200個、加工進捗度 50%。

- 直接材料費の計算に使う数量: 200個
- 加工費の計算に使う数量(完成品換算量): 200 × 50% = 100個

### 平均法 {#average}

月初仕掛品と当月投入を合わせた平均の単価で、月末仕掛品を計算します。

**例2** 次の資料で、平均法により月末仕掛品原価と完成品総合原価を計算する。

| | 数量 | 材料費 | 加工費 |
|---|--:|--:|--:|
| 月初 | 200個(50%) | 40,000 | 12,000 |
| 当月投入 | 1,000個 | 260,000 | 252,000 |
| 完成品 | 1,000個 | | |
| 月末 | 200個(50%) | | |

月初・月末は仕掛品で、( )は加工進捗度です。材料費は直接材料費(始点で投入)です。

- 直接材料費: (40,000 + 260,000) ÷ (1,000 + 200) = 250。月末 200 × 250 = 50,000
- 加工費: (12,000 + 252,000) ÷ (1,000 + 100) = 240。月末 100 × 240 = 24,000
- 月末仕掛品原価 = 74,000
- 完成品総合原価 = 原価の合計 564,000 − 月末 74,000 = 490,000

加工費の分母は、完成品 1,000個 + 月末の換算量 100個です。

### 先入先出法 {#fifo}

先に作り始めた月初仕掛品から先に完成したと考えます。月末仕掛品は、すべて **当月投入** から出たものなので、当月投入の単価だけで計算します。

**例3** 例2と同じ資料で、先入先出法により計算する。

- 当月投入の加工費の換算量 = 完成 1,000 + 月末 100 − 月初 100 = 1,000個
- 直接材料費: 260,000 ÷ 1,000 = 260。月末 200 × 260 = 52,000
- 加工費: 252,000 ÷ 1,000 = 252。月末 100 × 252 = 25,200
- 月末仕掛品原価 = 77,200
- 完成品総合原価 = 564,000 − 77,200 = 486,800

月初仕掛品の換算量(200 × 50% = 100個)を差し引くのを忘れないようにします。

### 完成品の振替 {#journal}

**例4** 例2(平均法)の完成品を製品勘定に振り替える。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 製品 | 490,000 | 仕掛品 | 490,000 |

### 正常仕損(度外視法) {#spoilage}

仕損品の数量を計算から除いて(度外視して)、残りの良品で原価を分けます。結果として、仕損の原価は良品が負担します。蒸発などで目に見えなくなる **減損** も同じ考え方です。

**例5(仕損が終点で発生)** 月初仕掛品はなし。当月投入 1,100個(直接材料費 330,000、加工費 199,500)。完成品 900個、正常仕損 100個、月末仕掛品 100個(進捗度 50%)。仕損は工程の終点で発生した。

月末仕掛品は終点まで進んでいないので、仕損の原価は **完成品だけ** が負担します。月末仕掛品の計算では仕損の数量も分母に入れ、仕損の原価は完成品に含めます。

- 直接材料費: 330,000 ÷ (900 + 100 + 100) = 300。月末 100 × 300 = 30,000
- 加工費: 199,500 ÷ (900 + 100 + 50) = 190。月末 50 × 190 = 9,500
- 月末仕掛品原価 = 39,500、完成品総合原価 = 490,000

**例6(仕損が始点で発生)** 例5と同じ資料で、仕損が工程の始点で発生した場合。

月末仕掛品も始点を通っているので、**両方** が負担します。仕損の数量を分母から除きます(始点なので加工費はかかっていない)。

- 直接材料費: 330,000 ÷ (900 + 100) = 330。月末 100 × 330 = 33,000
- 加工費: 199,500 ÷ (900 + 50) = 210。月末 50 × 210 = 10,500
- 月末仕掛品原価 = 43,500、完成品総合原価 = 486,000

仕損品に売れる価値(評価額)があるときは、完成品だけが負担する場合、その額を完成品総合原価から差し引きます。

### 仕損の負担 {#who-bears}

| 仕損の発生点 | 負担するもの |
|---|---|
| 終点(月末仕掛品の進捗度より後) | 完成品だけ |
| 始点など(月末仕掛品の進捗度以前) | 完成品と月末仕掛品 |

> [!覚える]
> - 直接材料(始点投入)は **数量**、加工費は **完成品換算量** で分ける
> - 平均法は **(月初 + 当月)÷(完成 + 月末)** の単価
> - 先入先出法は、月末を **当月投入の単価** で計算する
> - 仕損が **終点** なら完成品だけ、**月末の進捗度以前** なら両者が負担する

## 引っかけポイント {#traps}

1. 直接材料費を始点で投入するときは、月末仕掛品の進捗度にかかわらず、数量そのもので分ける。
2. 先入先出法の当月投入の換算量は、完成 + 月末 − 月初(月初の換算量を引く)。
3. 先入先出法では、月初仕掛品の原価はすべて完成品に入る。
4. 仕損が終点で発生するときは、仕損の数量も分母に入れて月末を計算する(仕損の原価が月末に入らないようにする)。
5. 仕損の発生点と月末仕掛品の進捗度を比べて、どちらが負担するかを決める。

## 決算書ではここに出る {#fs}

月末仕掛品は貸借対照表の「仕掛品」、完成品原価は製品を経て売上原価になります。M&Aでは、仕掛品の加工進捗度の見積りが高すぎると、月末仕掛品が大きくなって利益が多く出るので、進捗度の決め方を確かめます。
