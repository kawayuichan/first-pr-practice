# K06 部門別計算

## 要点3行 {#summary}

1. 製造間接費を部門ごとに集める。その部門だけで発生した **部門個別費** は直接、複数の部門に共通の **部門共通費** は床面積などの基準で配賦する(第1次集計)。
2. 動力部・修繕部などの **補助部門** の費用は、製品を作る **製造部門** に配賦する(第2次集計)。方法は **直接配賦法** と **相互配賦法**。
3. 製品へは、製造部門ごとの **予定配賦率** で配賦する。実際との差は **製造部門費配賦差異**。

## 仕訳パターン {#patterns}

この章の例は、製造部門が切削部門・組立部門、補助部門が動力部門・修繕部門の工場です。

### 第1次集計(部門個別費と部門共通費) {#first}

**例1** 工場の建物の減価償却費 ¥120,000(部門共通費)を、床面積で配賦する。床面積は、切削 400㎡、組立 300㎡、動力 200㎡、修繕 100㎡。

- 切削部門 = 120,000 × 400 ÷ 1,000 = 48,000
- 組立 36,000、動力 24,000、修繕 12,000

部門個別費(切削 100,000、組立 80,000、動力 36,000、修繕 18,000)と合わせて、製造間接費を各部門費に振り替えます。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 切削部門費 | 148,000 | 製造間接費 | 354,000 |
| 組立部門費 | 116,000 | | |
| 動力部門費 | 60,000 | | |
| 修繕部門費 | 30,000 | | |

### 第2次集計①直接配賦法 {#direct}

補助部門どうしのサービスのやり取りを **無視** して、製造部門だけに配賦します。

**例2** 動力部門費 ¥60,000 を電力の使用量(切削 600kWh、組立 400kWh、修繕 200kWh)で、修繕部門費 ¥30,000 を修繕時間(切削 60時間、組立 20時間、動力 20時間)で配賦する。

- 動力: 切削 60,000 × 600 ÷ 1,000 = 36,000、組立 24,000(修繕の 200kWh は使わない)
- 修繕: 切削 30,000 × 60 ÷ 80 = 22,500、組立 7,500(動力の 20時間は使わない)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 切削部門費 | 58,500 | 動力部門費 | 60,000 |
| 組立部門費 | 31,500 | 修繕部門費 | 30,000 |

### 第2次集計②相互配賦法(簡便法) {#mutual}

1回目は、補助部門どうしにも配賦します。2回目は、1回目で受け取った分を、直接配賦法で製造部門だけに配賦します。

**例3** 例2と同じ条件を、相互配賦法で配賦する。

| 配賦 | 切削 | 組立 | 動力 | 修繕 |
|---|--:|--:|--:|--:|
| 1回目 動力 60,000 | 30,000 | 20,000 | | 10,000 |
| 1回目 修繕 30,000 | 18,000 | 6,000 | 6,000 | |
| 2回目 動力 | 3,600 | 2,400 | | |
| 2回目 修繕 | 7,500 | 2,500 | | |
| 合計 | 59,100 | 30,900 | | |

1回目の基準には補助部門の使用量も入れます(動力は 1,200kWh、修繕は 100時間で割る)。2回目の基準は製造部門だけです。

### 予定配賦(製造部門ごとの率) {#apply}

**例4** 予定配賦率は、切削部門が1時間 ¥400、組立部門が1時間 ¥250。当月の実際の作業時間は、切削 500時間、組立 600時間。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕掛品 | 350,000 | 切削部門費 | 200,000 |
| | | 組立部門費 | 150,000 |

### 部門費配賦差異 {#variance}

**例5** 当月の実際の部門費(例2の直接配賦法の結果)は、切削 206,500、組立 147,500。例4の予定配賦額との差を振り替える。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 製造部門費配賦差異 | 6,500 | 切削部門費 | 6,500 |
| 組立部門費 | 2,500 | 製造部門費配賦差異 | 2,500 |

切削は実際が多い(不利差異・借方)、組立は実際が少ない(有利差異・貸方)です。

## T勘定・ボックス図 {#t-account}

### 費用の流れ {#flow}

| 段階 | 借方 | 貸方 |
|---|---|---|
| 第1次集計 | 各部門費(製造部門・補助部門) | 製造間接費 |
| 第2次集計 | 製造部門費 | 補助部門費 |
| 製品への配賦 | 仕掛品 | 製造部門費 |

### 2つの配賦方法 {#methods}

| 方法 | 補助部門どうしのやり取り | 配賦の回数 |
|---|---|---|
| 直接配賦法 | 無視する | 1回(製造部門だけ) |
| 相互配賦法(簡便法) | 1回目だけ考える | 2回(2回目は製造部門だけ) |

> [!覚える]
> - 部門個別費は **直接**、部門共通費は **配賦基準** で各部門へ
> - 補助部門費は **製造部門** へ配賦する(仕掛品へ直接は入れない)
> - 直接配賦法は、基準から **補助部門の使用量を除く**
> - 相互配賦法は、1回目は補助部門にも、**2回目は製造部門だけ**
> - 製品へは **製造部門ごとの予定配賦率** で配賦する

## 引っかけポイント {#traps}

1. 部門共通費は、補助部門にも配賦する(製造部門だけで割らない)。
2. 直接配賦法では、修繕部門が使った電力など、補助部門どうしの分を基準から除いて割る。
3. 相互配賦法の1回目は、補助部門の使用量も基準に入れる。2回目は除く。
4. どちらの方法でも、製造部門に配賦される合計額は、補助部門費の合計と同じ(各部門への分け方だけがちがう)。
5. 予定配賦の仕訳の貸方は、製造間接費ではなく各製造部門費。

## 決算書ではここに出る {#fs}

部門別計算は工場の中の計算なので、決算書には直接出ません。製品の原価(棚卸資産・売上原価)の正確さを支えます。M&Aでは、動力部・修繕部などの補助部門の費用が大きい工場は、設備が古く維持費がかかっている可能性があるので、修繕費の推移を確かめます。
