# C08 有価証券①売買目的

## 要点3行 {#summary}

1. 売買目的有価証券は、**購入代価 + 手数料**(付随費用)で記録する。売ったら、帳簿価額との差額を **有価証券売却益・有価証券売却損** にする。何回かに分けて買ったときは **平均単価** で帳簿価額を出す。
2. 利払日の途中で債券を売買したら、前の利払日の翌日から売買日までの **端数利息** を、買った側が売った側に払う。どちらも **有価証券利息** で処理する(買った側は借方、売った側は貸方)。
3. 決算では **時価** に評価替えし、差額を **有価証券評価益・評価損**(または有価証券評価損益)にする。**切放法** は時価がそのまま次の帳簿価額、**洗替法** は翌期首に元の帳簿価額へ戻す。

## 仕訳パターン {#patterns}

売買目的有価証券は、時価の変動で利益を得るために持つ株式や債券です(公式の科目表では「有価証券」でもよい)。

### 株式を買う {#buy}

**例1** 売買目的で、A社株式100株を1株 ¥1,200 で買い、手数料 ¥3,000 とともに普通預金口座から支払った。

- 取得原価 = 1,200 × 100 + 3,000 = {{ 1,200 * 100 + 3,000 }}(1株あたり {{ (1,200 * 100 + 3,000) / 100 }})

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売買目的有価証券 | {{ 1,200 * 100 + 3,000 }} | 普通預金 | {{ 1,200 * 100 + 3,000 }} |

手数料は支払手数料にせず、**取得原価に含めます**。

### 株式を売る {#sell}

**例2** 例1の株式のうち60株を、1株 ¥1,500 で売り、代金は普通預金口座に入金された。

- 売却価額 = 1,500 × 60 = {{ 1,500 * 60 }}
- 帳簿価額 = {{ (1,200 * 100 + 3,000) / 100 }} × 60 = {{ (1,200 * 100 + 3,000) / 100 * 60 }}
- 売却益 = {{ 1,500 * 60 }} − {{ (1,200 * 100 + 3,000) / 100 * 60 }} = {{ 1,500 * 60 - (1,200 * 100 + 3,000) / 100 * 60 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 普通預金 | {{ 1,500 * 60 }} | 売買目的有価証券 | {{ (1,200 * 100 + 3,000) / 100 * 60 }} |
| | | 有価証券売却益 | {{ 1,500 * 60 - (1,200 * 100 + 3,000) / 100 * 60 }} |

- 帳簿価額と売却損益を分けて書く方法を **分記法** という(2級の基本。売買をまとめて記録する総記法は1級の範囲)
- 売却価額が帳簿価額より低ければ、差額は **有価証券売却損**(借方)
- 代金をあとで受け取るときは **未収入金**(売掛金ではない)

### 何回かに分けて買ったとき(平均単価) {#average}

**例3** B社株式を、1回目に200株を1株 ¥800、2回目に300株を1株 ¥900 で買った。このうち250株を1株 ¥950 で売り、代金は普通預金口座に入金された。

- 平均単価 = (800 × 200 + 900 × 300)÷(200 + 300)= {{ (800 * 200 + 900 * 300) / (200 + 300) }}
- 帳簿価額 = {{ (800 * 200 + 900 * 300) / (200 + 300) }} × 250 = {{ (800 * 200 + 900 * 300) / (200 + 300) * 250 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 普通預金 | {{ 950 * 250 }} | 売買目的有価証券 | {{ (800 * 200 + 900 * 300) / (200 + 300) * 250 }} |
| | | 有価証券売却益 | {{ 950 * 250 - (800 * 200 + 900 * 300) / (200 + 300) * 250 }} |

### 債券を買う(端数利息) {#bond-buy}

債券の利息は、利払日にその日の持ち主がまとめて受け取ります。そこで利払日の途中で売買したときは、前の持ち主の分の利息(**端数利息**)を、買った側が先に払います。

**例4** 売買目的で、額面 ¥1,000,000 の社債(年利率3.65%、利払日は3月末と9月末)を、額面 ¥100 につき ¥98 で6月12日に買い、端数利息とともに普通預金口座から支払った(1年は365日)。

- 取得原価 = 1,000,000 × 98 ÷ 100 = {{ 1,000,000 * 98 / 100 }}
- 日数 = 4月1日〜6月12日 = 30 + 31 + 12 = {{ 30 + 31 + 12 }}日
- 端数利息 = 1,000,000 × 3.65% × {{ 30 + 31 + 12 }} ÷ 365 = {{ 1,000,000 * 365 / 10,000 * (30 + 31 + 12) / 365 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売買目的有価証券 | {{ 1,000,000 * 98 / 100 }} | 普通預金 | {{ 1,000,000 * 98 / 100 + 1,000,000 * 365 / 10,000 * (30 + 31 + 12) / 365 }} |
| 有価証券利息 | {{ 1,000,000 * 365 / 10,000 * (30 + 31 + 12) / 365 }} | | |

- 日数は、前の利払日の **翌日** から売買日 **当日** まで(数え方は問題文の指示に従う)
- 端数利息は **取得原価に含めない**。有価証券利息(借方)にする
- 9月末に半年分の利息を全部受け取るので、借方の有価証券利息と相殺されて、持っていた期間の分だけが利益に残る

### 債券を売る(端数利息) {#bond-sell}

**例5** 例4の社債を、8月18日に額面 ¥100 につき ¥99 で売り、端数利息とともに普通預金口座に入金された。

- 売却価額 = 1,000,000 × 99 ÷ 100 = {{ 1,000,000 * 99 / 100 }}、売却益 = {{ 1,000,000 * 99 / 100 }} − {{ 1,000,000 * 98 / 100 }} = {{ 1,000,000 * 99 / 100 - 1,000,000 * 98 / 100 }}
- 日数 = 4月1日〜8月18日 = 30 + 31 + 30 + 31 + 18 = {{ 30 + 31 + 30 + 31 + 18 }}日
- 端数利息 = 1,000,000 × 3.65% × {{ 30 + 31 + 30 + 31 + 18 }} ÷ 365 = {{ 1,000,000 * 365 / 10,000 * (30 + 31 + 30 + 31 + 18) / 365 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 普通預金 | {{ 1,000,000 * 99 / 100 + 1,000,000 * 365 / 10,000 * (30 + 31 + 30 + 31 + 18) / 365 }} | 売買目的有価証券 | {{ 1,000,000 * 98 / 100 }} |
| | | 有価証券売却益 | {{ 1,000,000 * 99 / 100 - 1,000,000 * 98 / 100 }} |
| | | 有価証券利息 | {{ 1,000,000 * 365 / 10,000 * (30 + 31 + 30 + 31 + 18) / 365 }} |

売った側は、持っていた期間の利息を受け取るので、有価証券利息は **貸方**。

### 配当金・利息を受け取る {#income}

**例6** 持っている株式の配当金 ¥5,000 が、普通預金口座に入金された。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 普通預金 | 5,000 | 受取配当金 | 5,000 |

株式からは **受取配当金**、債券からは **有価証券利息** です。

### 決算の評価替え {#valuation}

**例7** 決算で、売買目的有価証券(帳簿価額 ¥300,000)の時価は ¥320,000 だった。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売買目的有価証券 | {{ 320,000 - 300,000 }} | 有価証券評価益 | {{ 320,000 - 300,000 }} |

- 時価が下がったときは「有価証券評価損 / 売買目的有価証券」
- 評価益と評価損をまとめた **有価証券評価損益** を使うこともある。問題の選択肢にある方を使う

### 切放法と洗替法 {#methods}

**例8** 例7の有価証券を、翌期に ¥330,000 で全部売った。

**洗替法** では、翌期首に例7の仕訳を逆にして、元の帳簿価額に戻します。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 有価証券評価益 | {{ 320,000 - 300,000 }} | 売買目的有価証券 | {{ 320,000 - 300,000 }} |

| 方法 | 売るときの帳簿価額 | 売却益 |
|---|--:|--:|
| 切放法 | 320,000 | {{ 330,000 - 320,000 }} |
| 洗替法 | 300,000 | {{ 330,000 - 300,000 }} |

切放法は、決算の時価がそのまま翌期の帳簿価額になります(期首の仕訳なし)。

## T勘定・ボックス図 {#t-account}

### 端数利息の図 {#t-interest}

例4の社債の、4月1日から9月30日までの利息です。

| 期間 | 利息を受け取るべき人 |
|---|---|
| 4月1日〜6月12日({{ 30 + 31 + 12 }}日) | 前の持ち主(端数利息として当社が払う) |
| 6月13日〜9月30日 | 当社 |

9月30日に半年分を全部受け取るので、先に払った端数利息を差し引くと、当社が持っていた期間の分だけが残ります。

### 洗替法の売買目的有価証券 {#t-securities}

例7・例8を洗替法で記録したときの、翌期の勘定です。

**売買目的有価証券**

| 借方 | 貸方 |
|---|---|
| 前期繰越 320,000 | 有価証券評価益(期首の戻し) {{ 320,000 - 300,000 }} |
| | 普通預金など(売却) 300,000 |

> [!覚える]
> - 取得原価 = **購入代価 + 手数料**(端数利息は含めない)
> - 端数利息は **前の利払日の翌日から売買日まで**。買った側は有価証券利息を借方、売った側は貸方
> - 売却損益 = **売却価額 − 帳簿価額**(何回かに分けて買ったら平均単価)
> - 決算は **時価** に評価替え。洗替法は **翌期首に元へ戻す**、切放法は時価のまま

## 引っかけポイント {#traps}

1. 買ったときの手数料は、支払手数料ではなく取得原価に含める。
2. 端数利息は取得原価に含めない(有価証券利息)。
3. 端数利息の日数は、前の利払日の翌日から売買日まで。利払日当日を数えない。
4. 何回かに分けて買った株式を売ったら、帳簿価額は平均単価で出す(先に買った分からではない)。
5. 洗替法と切放法で、翌期の売却損益が変わる。
6. 債券の価額は「額面 × @単価 ÷ 100」。額面で記録しない。
7. 有価証券を売った代金の未回収分は未収入金(売掛金ではない)。

## 決算書ではここに出る {#fs}

貸借対照表では、売買目的有価証券を「有価証券」として流動資産に、時価で表示します。損益計算書では、売却損益・評価損益・有価証券利息・受取配当金を、営業外収益・営業外費用に表示します。M&Aでは、有価証券の時価と、評価益がどれだけ利益に入っているかを確かめます。評価益は売らないと現金にならず、時価が下がればすぐに消えるからです。
