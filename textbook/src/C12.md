# C12 無形固定資産・研究開発費

## 要点3行 {#summary}

1. **無形固定資産**(のれん・ソフトウェア・特許権など)は、形はないが長く使う資産。**残存価額ゼロ・定額法** で償却し、**直接法**(資産そのものを減らす)で記帳する。
2. **のれん** は、事業などを買ったとき、受け入れた純資産(資産 − 負債)より多く払った部分で、**20年以内** に償却する。自社で使う **ソフトウェア** は使い始めてから償却し、制作途中の支払いは **ソフトウェア仮勘定** にする。
3. 研究開発のための支出は、研究にだけ使う機械も含めて、全額をその期の費用(**研究開発費**)にする。1年を超えて先の分の前払いは **長期前払費用**。

## 仕訳パターン {#patterns}

### のれん(事業の譲受け) {#goodwill}

**例1** B社の事業の一部を ¥3,000,000 で譲り受け、代金は当座預金口座から支払った。受け入れた資産と負債(時価)は、売掛金 ¥1,200,000、建物 ¥2,000,000、買掛金 ¥800,000、借入金 ¥600,000。

- 受け入れた純資産 =(1,200,000 + 2,000,000)−(800,000 + 600,000)= {{ 1,200,000 + 2,000,000 - (800,000 + 600,000) }}
- のれん = 3,000,000 − {{ 1,200,000 + 2,000,000 - (800,000 + 600,000) }} = {{ 3,000,000 - (1,200,000 + 2,000,000 - (800,000 + 600,000)) }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売掛金 | 1,200,000 | 買掛金 | 800,000 |
| 建物 | 2,000,000 | 借入金 | 600,000 |
| のれん | {{ 3,000,000 - (1,200,000 + 2,000,000 - (800,000 + 600,000)) }} | 当座預金 | 3,000,000 |

- 資産・負債は **時価** で受け入れる
- のれんは、その事業の稼ぐ力(ブランドや顧客など)に払った分
- 会社ごと受け入れる **合併** は C20 で学ぶ
- 区分表には「事業の譲受け」という名前はないため、このアプリでは問題1問を要確認にしている

### のれんの償却 {#goodwill-amort}

**例2** 決算。例1ののれん(期首に取得)を20年で償却する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| のれん償却 | {{ (3,000,000 - (1,200,000 + 2,000,000 - (800,000 + 600,000))) / 20 }} | のれん | {{ (3,000,000 - (1,200,000 + 2,000,000 - (800,000 + 600,000))) / 20 }} |

- 20年以内の、その効果が及ぶ期間で、定額法により償却する
- 期の途中で取得したときは、最初の年は月割り

### ソフトウェア(自社で使うもの) {#software}

**例3** 期首に、自社で使う販売管理ソフトを ¥600,000 で買い、設定作業の費用 ¥60,000 とともに普通預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| ソフトウェア | {{ 600,000 + 60,000 }} | 普通預金 | {{ 600,000 + 60,000 }} |

**例4** 決算。例3のソフトウェアを5年で償却する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| ソフトウェア償却 | {{ (600,000 + 60,000) / 5 }} | ソフトウェア | {{ (600,000 + 60,000) / 5 }} |

- 使えるようにするための費用(設定作業など)は取得原価に含める
- 2級は自社で使うソフトウェアだけ。受注制作・市場販売目的のソフトウェアは1級の範囲

### ソフトウェア仮勘定 {#software-cip}

**例5** 自社で使うソフトウェアの開発を外部に頼み、制作の途中で ¥400,000 を当座預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| ソフトウェア仮勘定 | 400,000 | 当座預金 | 400,000 |

**例6** ソフトウェアが完成して引渡しを受け、残りの ¥600,000 を当座預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| ソフトウェア | {{ 400,000 + 600,000 }} | ソフトウェア仮勘定 | 400,000 |
| | | 当座預金 | 600,000 |

建設仮勘定(C10)と同じ考え方です。ソフトウェア仮勘定は、まだ使っていないので償却しません。

### 特許権など {#patents}

**例7** 決算。期首に ¥800,000 で取得した特許権を、8年で償却する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 特許権償却 | {{ 800,000 / 8 }} | 特許権 | {{ 800,000 / 8 }} |

商標権なども同じように「○○償却 / ○○」で償却します。

### 研究開発費 {#rd}

**例8** 研究開発部門の研究員の給料 ¥500,000 と、研究開発にだけ使う測定機器 ¥300,000 を、普通預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 研究開発費 | {{ 500,000 + 300,000 }} | 普通預金 | {{ 500,000 + 300,000 }} |

- 研究開発の成果が出るかわからないので、すべてその期の費用にする
- 研究開発にだけ使う機械は、固定資産にせず **研究開発費**(ほかの目的にも使える機械なら、ふつうの固定資産)
- 研究員の給料も、給料ではなく研究開発費

### 長期前払費用 {#long-prepaid}

**例9** X1年4月1日(期首)に、3年分の保険料 ¥360,000 を普通預金口座から支払い、保険料で処理した。X2年3月31日に決算を迎えた。

- 当期の分 {{ 360,000 / 3 }} は保険料のまま
- 次期の分(決算日の翌日から1年以内)は **前払保険料**
- その先の分(1年を超える)は **長期前払保険料**(長期前払費用)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 前払保険料 | {{ 360,000 / 3 }} | 保険料 | {{ 360,000 / 3 * 2 }} |
| 長期前払保険料 | {{ 360,000 / 3 }} | | |

## T勘定・ボックス図 {#t-account}

### 無形固定資産の償却 {#t-amort}

| 資産 | 償却の期間 | 費用の科目 |
|---|---|---|
| のれん | 20年以内 | のれん償却 |
| ソフトウェア | 問題文の年数(5年が多い) | ソフトウェア償却 |
| 特許権 | 問題文の年数 | 特許権償却 |

どれも残存価額ゼロ・定額法・直接法です。

### 3年分の保険料の分け方 {#t-prepaid}

例9の保険料 ¥360,000 です。

| 期間 | 金額 | 科目 |
|---|--:|---|
| 当期 | {{ 360,000 / 3 }} | 保険料 |
| 次期(1年以内) | {{ 360,000 / 3 }} | 前払保険料 |
| その先(1年超) | {{ 360,000 / 3 }} | 長期前払保険料 |

> [!覚える]
> - 無形固定資産は **残存価額ゼロ・定額法・直接法** で償却する
> - のれん = 払った額 − **受け入れた純資産(時価)**。**20年以内** に償却
> - 制作途中のソフトウェアは **ソフトウェア仮勘定**。完成して使い始めたら償却
> - 研究開発のための支出は、専用の機械も含めて **全額 研究開発費**
> - 決算日の翌日から1年を超える前払いは **長期前払費用**

## 引っかけポイント {#traps}

1. 無形固定資産は直接法。減価償却累計額のような科目は使わず、資産を直接減らす。
2. のれんは、払った額と、受け入れた資産から負債を引いた純資産との差。資産だけと比べない。
3. ソフトウェアを使えるようにするための費用(設定作業など)は、取得原価に含める。
4. ソフトウェア仮勘定は償却しない。完成して使い始めてから償却する。
5. 研究開発にだけ使う機械は、固定資産にせず研究開発費にする。
6. 前払保険料と長期前払保険料の分かれ目は、決算日の翌日から1年。

## 決算書ではここに出る {#fs}

のれん・ソフトウェア・特許権は、貸借対照表の無形固定資産です。長期前払費用は「投資その他の資産」に入ります。のれん償却・ソフトウェア償却・研究開発費は、損益計算書の販売費及び一般管理費です。M&Aでは、のれんが特に大切です。買収で払った額と純資産の差なので、のれんが大きい会社は、過去の買収の値段が高かったことを意味します。買収した事業が期待どおりに稼げないと、のれんの価値を下げる処理が必要になります(のれんの減損は1級の範囲)。

## 確認問題 {#check}

アプリの「問題を解く」で、C12の問題(10問)を解けます。ここでは3問だけ、すぐに答えを確認できます。

<details>
<summary>Q1. 事業を ¥2,000,000 で譲り受けた。受け入れた資産(時価)は ¥2,500,000、負債は ¥900,000。のれんは?</summary>

¥{{ 2,000,000 - (2,500,000 - 900,000) }}(2,000,000 − 純資産 {{ 2,500,000 - 900,000 }})。

</details>

<details>
<summary>Q2. 期首に取得したのれん ¥1,000,000 を20年で償却する。1年分は?</summary>

¥{{ 1,000,000 / 20 }}(のれん償却 / のれん)。

</details>

<details>
<summary>Q3. 研究開発にだけ使う機械を ¥300,000 で買った。借方の科目は?</summary>

研究開発費(機械装置にはしない)。

</details>
