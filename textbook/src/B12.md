# B12 株式会社の資本

## 要点3行 {#summary}

1. 株式を発行して受け取ったお金は **資本金**(純資産)。会社をつくるとき(設立)も、あとで追加で発行するとき(増資)も同じ。
2. 会社がこれまでに稼いだ利益のうち、配当などで使わずに残っている分が **繰越利益剰余金**。決算で当期純利益の分だけ増え、純損失なら減る。
3. 株主総会で配当を決めたら、繰越利益剰余金を減らして **未払配当金**(負債)と **利益準備金**(法律で積み立てる分)にする。支払ったら未払配当金を減らす。

## 仕訳パターン {#patterns}

### 設立 {#establish}

**例1** 会社の設立にあたり、株式100株を1株 ¥50,000 で発行し、全額が普通預金口座に払い込まれた。全額を資本金とする。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 普通預金 | {{ 100 * 50,000 }} | 資本金 | {{ 100 * 50,000 }} |

株主から受け取ったお金は、返す必要がないので借入金ではありません。会社の元手として **資本金**(純資産)にします。

### 増資 {#increase}

**例2** 取締役会の決議により、新たに株式40株を1株 ¥60,000 で発行し、全額が当座預金口座に払い込まれた。全額を資本金とする。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 当座預金 | {{ 40 * 60,000 }} | 資本金 | {{ 40 * 60,000 }} |

- 発行した株数 × 1株の金額 が払い込まれた額
- 払い込まれた額の一部を資本準備金にする方法や、株式を発行するための費用(株式交付費)は2級(C19)で学ぶ

### 剰余金の配当 {#dividend}

**例3** 株主総会で、繰越利益剰余金を財源として株主配当金 ¥300,000 を支払うことと、利益準備金 ¥30,000 を積み立てることが決まった。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 繰越利益剰余金 | {{ 300,000 + 30,000 }} | 未払配当金 | 300,000 |
| | | 利益準備金 | 30,000 |

**例4** 例3の配当金を、普通預金口座から株主に支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 未払配当金 | 300,000 | 普通預金 | 300,000 |

- 株主総会で決めた時点では、まだ払っていないので **未払配当金**(負債)
- 配当をするときは、会社法で一定額を **利益準備金** として積み立てる。積み立てる額の計算(配当の10分の1など)は2級(C19)で学び、ここでは問題文で与えられる
- 繰越利益剰余金が減る額 = 配当金 + 利益準備金の積立額

### 当期純利益の振替(紹介) {#net-income}

**例5** 決算で、当期純利益 ¥800,000 を繰越利益剰余金に振り替えた。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 損益 | 800,000 | 繰越利益剰余金 | 800,000 |

当期純損失のときは逆(繰越利益剰余金 / 損益)で、繰越利益剰余金が減ります。損益勘定の使い方は、B14(決算②)で詳しく学びます。

## T勘定・ボックス図 {#t-account}

### 繰越利益剰余金の1年間 {#t-retained}

期首の残高が ¥1,000,000 で、例3の配当と例5の当期純利益があった年です。

**繰越利益剰余金**

| 借方 | 貸方 |
|---|---|
| 未払配当金 300,000 | 前期繰越 1,000,000 |
| 利益準備金 30,000 | 損益 800,000 |
| 次期繰越 {{ 1,000,000 + 800,000 - 300,000 - 30,000 }} | |

期末の残高 = 期首 + 当期純利益 − 配当金 − 利益準備金の積立 = {{ 1,000,000 + 800,000 - 300,000 - 30,000 }}

### 貸借対照表の純資産の部 {#equity-section}

例1・例2の資本金と、上の繰越利益剰余金がある会社です(利益準備金は例3の積立分だけ)。

| 純資産の部 | 金額 |
|---|--:|
| 資本金 | {{ 100 * 50,000 + 40 * 60,000 }} |
| 利益準備金 | 30,000 |
| 繰越利益剰余金 | {{ 1,000,000 + 800,000 - 300,000 - 30,000 }} |
| 純資産合計 | {{ 100 * 50,000 + 40 * 60,000 + 30,000 + 1,000,000 + 800,000 - 300,000 - 30,000 }} |

利益準備金と繰越利益剰余金をあわせて **利益剰余金** といいます(2級の貸借対照表では区分して表示)。

## 引っかけポイント {#traps}

1. 株式の発行で受け取ったお金は資本金。返す必要がないので借入金ではない。
2. 配当を決めた時点では **未払配当金**。まだ普通預金は減らさない。
3. 利益準備金の積立も繰越利益剰余金から。繰越利益剰余金は「配当金 + 積立額」だけ減る。
4. 配当金を払ったら **未払配当金** を減らす。繰越利益剰余金を二回減らさない。
5. 繰越利益剰余金は **現金ではない**。利益が残っていても、お金が手元にあるとは限らない。

## 決算書ではここに出る {#fs}

貸借対照表の「純資産の部」に、資本金・利益準備金・繰越利益剰余金が並びます(2級では「株主資本等変動計算書」で1年間の増減も見る)。M&Aでは、純資産は会社の帳簿上の値打ち(簿価)で、買収価格を考える出発点の一つです。ただし繰越利益剰余金が大きくても現金があるとは限らないので、配当を出せるかどうかは手元のお金とあわせて確かめます。
