# C19 純資産(2級)

## 要点3行 {#summary}

1. 株式を発行して払い込まれた額は、原則は全額 **資本金**。ただし、**少なくとも半分** を資本金にすれば、残りを **資本準備金** にできる。申込期日までに受け取った申込証拠金は **株式申込証拠金**(預金は **別段預金**)。
2. 繰越利益剰余金から配当したら、配当額の **10分の1** を **利益準備金** に積み立てる。ただし、資本準備金と利益準備金の合計が **資本金の4分の1** に達したら、それ以上は積み立てなくてよい。
3. 純資産の中の金額は、株主総会の決議などで振り替えられる(**計数の変動**)。会社を作る・始める・株式を発行するための費用は、**創立費・開業費・株式交付費**(費用)。

## 仕訳パターン {#patterns}

設立・増資・配当の基本は3級(B12)と同じです。ここでは2級で加わる内容を学びます。

### 増資(資本準備金) {#capital-reserve}

**例1** 増資のため、株式100株を1株 ¥50,000 で発行し、払込金が当座預金口座に入金された。会社法で認められる最低額を資本金とする。

- 払込金 = 50,000 × 100 = {{ 50,000 * 100 }}
- 資本金(半分)= {{ 50,000 * 100 / 2 }}、残りは資本準備金

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 当座預金 | {{ 50,000 * 100 }} | 資本金 | {{ 50,000 * 100 / 2 }} |
| | | 資本準備金 | {{ 50,000 * 100 / 2 }} |

「会社法で認められる最低額」「2分の1」などの指示がなければ、全額を資本金にします。

### 株式申込証拠金 {#subscription}

**例2** 株式の申込みを受け、申込証拠金 ¥3,000,000 を受け取り、別段預金とした。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 別段預金 | 3,000,000 | 株式申込証拠金 | 3,000,000 |

**例3** 払込期日になり、申込証拠金を払込金に充て、資本金と資本準備金(2分の1ずつ)にした。別段預金は当座預金に移した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 株式申込証拠金 | 3,000,000 | 資本金 | {{ 3,000,000 / 2 }} |
| | | 資本準備金 | {{ 3,000,000 / 2 }} |
| 当座預金 | 3,000,000 | 別段預金 | 3,000,000 |

- 払込期日までは、まだ株主ではないので資本金にしない(株式申込証拠金)
- 別段預金は、払込期日まで会社が自由に使えない預金

### 創立費・開業費・株式交付費 {#costs}

| 支払ったもの | 科目 |
|---|---|
| 会社を作るまでの費用(定款の作成など) | 創立費 |
| 会社を作ってから営業を始めるまでの費用(広告など) | 開業費 |
| 設立後に株式を発行するための費用(増資の広告など) | 株式交付費 |

**例4** 増資のための株式発行の費用 ¥200,000 を、当座預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 株式交付費 | 200,000 | 当座預金 | 200,000 |

2級では、支払ったときに費用にします(繰延資産として資産にする方法は1級の範囲)。

### 剰余金の配当と準備金の積立て {#reserve}

**例5** 株主総会で、繰越利益剰余金から配当 ¥1,000,000 を行い、別途積立金 ¥300,000 を積み立てることが決まった。資本金 ¥20,000,000、資本準備金 ¥3,000,000、利益準備金 ¥1,800,000。

- 配当の10分の1 = 1,000,000 ÷ 10 = {{ 1,000,000 / 10 }}
- 積立ての上限(資本金の4分の1 − 準備金の合計)= 20,000,000 ÷ 4 −(3,000,000 + 1,800,000)= {{ 20,000,000 / 4 - (3,000,000 + 1,800,000) }}
- 少ない方の {{ 20,000,000 / 4 - (3,000,000 + 1,800,000) }} を利益準備金に積み立てる

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 繰越利益剰余金 | {{ 1,000,000 + 300,000 + 20,000,000 / 4 - (3,000,000 + 1,800,000) }} | 未払配当金 | 1,000,000 |
| | | 利益準備金 | {{ 20,000,000 / 4 - (3,000,000 + 1,800,000) }} |
| | | 別途積立金 | 300,000 |

### その他資本剰余金からの配当 {#capital-surplus}

**例6** その他資本剰余金から配当 ¥500,000 を行うことが決まった(準備金の上限には達していない)。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| その他資本剰余金 | {{ 500,000 + 500,000 / 10 }} | 未払配当金 | 500,000 |
| | | 資本準備金 | {{ 500,000 / 10 }} |

その他資本剰余金(資本の側)から配当したら、積み立てるのも資本の側の **資本準備金** です。

### 計数の変動・任意積立金 {#transfer}

**例7** 株主総会の決議で、資本準備金 ¥1,000,000 を資本金に組み入れた。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 資本準備金 | 1,000,000 | 資本金 | 1,000,000 |

**例8** 別途積立金 ¥400,000 を取り崩して、繰越利益剰余金に振り替えた。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 別途積立金 | 400,000 | 繰越利益剰余金 | 400,000 |

## T勘定・ボックス図 {#t-account}

### 純資産の部の分類 {#equity}

| 区分 | 科目 |
|---|---|
| 資本金 | 資本金 |
| 資本剰余金 | 資本準備金、その他資本剰余金 |
| 利益剰余金 | 利益準備金、任意積立金(別途積立金など)、繰越利益剰余金 |
| 評価・換算差額等 | その他有価証券評価差額金(C09) |

資本金・資本剰余金・利益剰余金をまとめて **株主資本** といいます。

### 準備金の積立額の決め方 {#reserve-rule}

| 計算 | 例5の金額 |
|---|--:|
| ① 配当額 × 10分の1 | {{ 1,000,000 / 10 }} |
| ② 資本金 × 4分の1 −(資本準備金 + 利益準備金) | {{ 20,000,000 / 4 - (3,000,000 + 1,800,000) }} |
| 積み立てる額(①と②の少ない方) | {{ 20,000,000 / 4 - (3,000,000 + 1,800,000) }} |

> [!覚える]
> - 払込金の **半分以上** を資本金、残りを **資本準備金** にできる
> - 払込期日までは **株式申込証拠金**・**別段預金**
> - 準備金の積立額 = 配当の **10分の1** と **資本金の4分の1 − 準備金の合計** の少ない方
> - 繰越利益剰余金からの配当 → 利益準備金、その他資本剰余金からの配当 → **資本準備金**
> - 株式交付費・創立費・開業費は、支払ったときに費用

## 引っかけポイント {#traps}

1. 「最低額を資本金」の指示があれば、払込金の半分が資本金。指示がなければ全額資本金。
2. 申込証拠金を受け取った時点では、資本金にしない。
3. 準備金の積立額は、配当の10分の1をそのまま使わず、上限(資本金の4分の1)と比べる。
4. その他資本剰余金から配当したときの積立ては、利益準備金ではなく資本準備金。
5. 増資のための株式発行の費用は株式交付費(創立費ではない)。

## 決算書ではここに出る {#fs}

貸借対照表の純資産の部は、株主資本(資本金・資本剰余金・利益剰余金)と、評価・換算差額等に分けて表示します。株式交付費・創立費・開業費は、損益計算書の営業外費用(開業費は販売費及び一般管理費とすることもある)です。M&Aでは、純資産の中身(払い込まれた資本と、稼いでためた利益の割合)と、配当の出し方を確かめます。
