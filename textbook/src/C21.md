# C21 決算整理と精算表(2級)

## 要点3行 {#summary}

1. 2級の決算整理は、3級(B13)の項目に、**棚卸減耗損・商品評価損**、貸倒引当金の個別評価、定率法の減価償却、**有価証券の評価替**、引当金、外貨の換算、税効果、法人税等が加わる。
2. 決算整理のあとに **決算整理後残高試算表** を作る。整理前の金額に決算整理仕訳を足し引きすると、整理後の金額になる。
3. 精算表では、資産・費用は「試算表 + 修正借方 − 修正貸方」、負債・純資産・収益は「試算表 + 修正貸方 − 修正借方」。整理で新しくできる科目(棚卸減耗損など)は下の行に追加する。

### 売上原価と棚卸減耗・評価替 {#inventory}

**例1** 期末商品は、帳簿 400個(原価 ¥800)、実地 380個、時価 ¥750。売上原価は仕入の行で計算し、棚卸減耗損と商品評価損は独立の科目で表示する。

- 棚卸減耗損 = 800 ×(400 − 380)= {{ 800 * (400 - 380) }}
- 商品評価損 =(800 − 750)× 380 = {{ (800 - 750) * 380 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕入 | 300,000 | 繰越商品 | 300,000 |
| 繰越商品 | {{ 800 * 400 }} | 仕入 | {{ 800 * 400 }} |
| 棚卸減耗損 | {{ 800 * (400 - 380) }} | 繰越商品 | {{ 800 * (400 - 380) + (800 - 750) * 380 }} |
| 商品評価損 | {{ (800 - 750) * 380 }} | | |

整理後の繰越商品 = 時価 × 実地数量 = 750 × 380 = {{ 750 * 380 }}。

### 貸倒引当金(個別評価と一括評価) {#allowance}

**例2** 売掛金のうち A社の ¥100,000 は回収が難しいので 50% を、残りには 2% を見積もる(差額補充法)。

- 見積額 = 100,000 × 50% +(800,000 − 100,000)× 2% = {{ 100,000 * 50 / 100 + (800,000 - 100,000) * 2 / 100 }}
- 繰入額 = 見積額 − 残高 10,000 = {{ 100,000 * 50 / 100 + (800,000 - 100,000) * 2 / 100 - 10,000 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 貸倒引当金繰入 | {{ 100,000 * 50 / 100 + (800,000 - 100,000) * 2 / 100 - 10,000 }} | 貸倒引当金 | {{ 100,000 * 50 / 100 + (800,000 - 100,000) * 2 / 100 - 10,000 }} |

### 減価償却(200%定率法) {#depreciation}

**例3** 備品は 200%定率法(償却率 0.4)。

- 減価償却費 =(1,000,000 − 360,000)× 0.4 = {{ (1,000,000 - 360,000) * 4 / 10 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 減価償却費 | {{ (1,000,000 - 360,000) * 4 / 10 }} | 備品減価償却累計額 | {{ (1,000,000 - 360,000) * 4 / 10 }} |

### その他有価証券(税効果あり) {#securities}

**例4** その他有価証券の時価は ¥640,000。全部純資産直入法で、税効果会計を適用する(実効税率 30%)。

- 評価差額 = 640,000 − 600,000 = {{ 640,000 - 600,000 }}、そのうち 30% = {{ (640,000 - 600,000) * 30 / 100 }} が繰延税金負債

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| その他有価証券 | {{ 640,000 - 600,000 }} | 繰延税金負債 | {{ (640,000 - 600,000) * 30 / 100 }} |
| | | その他有価証券評価差額金 | {{ (640,000 - 600,000) * 70 / 100 }} |

### 法人税等 {#tax}

**例5** 当期の法人税、住民税及び事業税は ¥380,000。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 法人税、住民税及び事業税 | 380,000 | 仮払法人税等 | 150,000 |
| | | 未払法人税等 | {{ 380,000 - 150,000 }} |

### 決算整理後残高試算表 {#after}

例1〜例5の結果、決算整理後残高試算表の金額は次のようになります。

| 勘定科目 | 整理前 | 整理後 |
|---|--:|--:|
| 繰越商品 | 300,000 | {{ 750 * 380 }} |
| 貸倒引当金 | 10,000 | {{ 100,000 * 50 / 100 + (800,000 - 100,000) * 2 / 100 }} |
| 備品減価償却累計額 | 360,000 | {{ 360,000 + (1,000,000 - 360,000) * 4 / 10 }} |
| その他有価証券 | 600,000 | 640,000 |
| 仕入 | 4,000,000 | {{ 4,000,000 + 300,000 - 800 * 400 }} |
| 仮払法人税等 | 150,000 | 0 |

## T勘定・ボックス図 {#t-account}

### 精算表の1行の計算 {#worksheet}

| 区分 | 試算表の側 | 計算 | 移す欄 |
|---|---|---|---|
| 資産 | 借方 | 試算表 + 修正借方 − 修正貸方 | 貸借対照表の借方 |
| 費用 | 借方 | 試算表 + 修正借方 − 修正貸方 | 損益計算書の借方 |
| 負債・純資産 | 貸方 | 試算表 + 修正貸方 − 修正借方 | 貸借対照表の貸方 |
| 収益 | 貸方 | 試算表 + 修正貸方 − 修正借方 | 損益計算書の貸方 |

例1の繰越商品の行は、300,000 + {{ 800 * 400 }} −({{ 300,000 }} + {{ 800 * (400 - 380) + (800 - 750) * 380 }})= {{ 750 * 380 }} で、貸借対照表の借方に移ります。

> [!覚える]
> - 整理後の繰越商品 = **時価 × 実地数量**
> - 貸倒引当金は、**個別評価 + 一括評価** の合計まで補充する
> - その他有価証券の評価差額は、税効果の分を **繰延税金負債(資産)** に分ける
> - 精算表は、試算表の側(借方・貸方)と同じ側の修正を **足し**、反対側を **引く**

## 引っかけポイント {#traps}

1. 繰越商品の修正記入の貸方には、期首の振替だけでなく、棚卸減耗損と商品評価損の分も入る。
2. 貸倒引当金の一括評価は、個別評価した債権を除いた残りに対して計算する。
3. 定率法は、取得原価ではなく、期首の帳簿価額(取得原価 − 累計額)に償却率をかける。
4. 仮払法人税等は、決算整理で法人税等に振り替えるので、整理後は残らない。

## 決算書ではここに出る {#fs}

決算整理後残高試算表の金額が、そのまま損益計算書・貸借対照表の材料になります(C22)。M&Aでは、決算整理の見積り(貸倒引当金・評価損・引当金)が少なすぎないかを確かめます。見積りが甘いと、資産が大きく、利益が多く見えるからです。
