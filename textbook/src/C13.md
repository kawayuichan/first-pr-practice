# C13 リース(新基準)

## 要点3行 {#summary}

1. 機械や車などをリースで借りたら、借手は使う権利を **使用権資産**、払う義務を **リース負債** として計上する(新しいリース会計基準)。
2. **利子込み法** はリース料の総額で計上し、**利子抜き法** は総額から利息相当額を引いた額で計上して、利息は毎期 **定額法** で支払利息にする。使用権資産は減価償却する。
3. 12か月以内の **短期リース** や **少額リース** は、資産・負債にせず、払うたびに **支払リース料**(賃貸借処理)にできる。不動産の賃借も、賃貸借処理と使用権資産の両方がある。

## 仕訳パターン {#patterns}

新しい基準では、借手はリースを2つの種類に分けず、原則として使用権資産とリース負債を計上します(旧基準のファイナンス・リースとオペレーティング・リースの区分、リース資産・リース債務の科目は使わない)。2級では、取引がリースに当たるかどうかの判断は問われません(問題文で与えられる)。

### 利子込み法 {#gross}

**例1** 期首に、複合機をリースで借りて使い始めた。リース期間は5年、リース料は年額 ¥240,000(毎年期末に当座預金口座から後払い)。利子込み法で処理する。

- リース料総額 = 240,000 × 5年 = {{ 240,000 * 5 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 使用権資産 | {{ 240,000 * 5 }} | リース負債 | {{ 240,000 * 5 }} |

**例2** 期末に、1回目のリース料を支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| リース負債 | 240,000 | 当座預金 | 240,000 |

**例3** 決算で、使用権資産を耐用年数5年(リース期間)、残存価額ゼロ、定額法、間接法で減価償却する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 減価償却費 | {{ 240,000 * 5 / 5 }} | 使用権資産減価償却累計額 | {{ 240,000 * 5 / 5 }} |

利子込み法では利息を分けないので、支払利息は出てきません。

### 利子抜き法 {#net}

**例4** 例1と同じリースを、利子抜き法で処理する。リース料総額 ¥1,200,000 のうち、利息相当額は ¥150,000。

- 使用権資産・リース負債 = 1,200,000 − 150,000 = {{ 1,200,000 - 150,000 }}
- 1年分の利息(定額法)= 150,000 ÷ 5年 = {{ 150,000 / 5 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 使用権資産 | {{ 1,200,000 - 150,000 }} | リース負債 | {{ 1,200,000 - 150,000 }} |

リース料を払ったとき(期末):

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| リース負債 | {{ 240,000 - 150,000 / 5 }} | 当座預金 | 240,000 |
| 支払利息 | {{ 150,000 / 5 }} | | |

決算の減価償却:

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 減価償却費 | {{ (1,200,000 - 150,000) / 5 }} | 使用権資産減価償却累計額 | {{ (1,200,000 - 150,000) / 5 }} |

- 払ったリース料のうち、利息の分は **支払利息**、残りは **リース負債** を減らす
- 2級の利子抜き法の利息は **定額法** だけ(利息法は1級の範囲)

### 期の途中で始まったとき {#midyear}

**例5** 10月1日に、営業用の車両をリースで借りて使い始めた(決算日は3月31日)。リース期間は4年、リース料は年額 ¥360,000(毎年9月30日に後払い)、利息相当額は ¥120,000。利子抜き法で処理する。

- 使用権資産 = 360,000 × 4 − 120,000 = {{ 360,000 * 4 - 120,000 }}
- 決算の減価償却費(10月〜3月の6か月)= {{ 360,000 * 4 - 120,000 }} ÷ 4 × 6 ÷ 12 = {{ (360,000 * 4 - 120,000) / 4 * 6 / 12 }}
- まだ払っていない6か月分の利息 = 120,000 ÷ 4 × 6 ÷ 12 = {{ 120,000 / 4 * 6 / 12 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 減価償却費 | {{ (360,000 * 4 - 120,000) / 4 * 6 / 12 }} | 使用権資産減価償却累計額 | {{ (360,000 * 4 - 120,000) / 4 * 6 / 12 }} |
| 支払利息 | {{ 120,000 / 4 * 6 / 12 }} | 未払利息 | {{ 120,000 / 4 * 6 / 12 }} |

リース料は9月30日に払うので、決算日までの6か月分の利息を **未払利息** として計上します(B10 の経過勘定と同じ)。

### 短期リース・少額リース {#short}

リース期間が **12か月以内** の短期リースや、金額の小さい少額リースは、使用権資産・リース負債を計上せず、払うたびに費用にできます(賃貸借処理)。

**例6** 6か月だけ借りる契約の機械のリース料(月額) ¥50,000 を、普通預金口座から支払った。賃貸借処理する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 支払リース料 | 50,000 | 普通預金 | 50,000 |

### 不動産を借りたとき {#realestate}

事務所や土地を借りたときも、リースです。2級では、次の両方が出題されます。

- **賃貸借処理**: 家賃・地代を払うたびに **支払リース料**(2級では支払家賃・支払地代を使わない)
- **使用権資産として計上**: 例1・例4と同じように、使用権資産とリース負債を計上する

問題文の指示に従います。

## T勘定・ボックス図 {#t-account}

### 利子込み法と利子抜き法 {#compare}

例1・例4の、1年目の金額です。

| 項目 | 利子込み法 | 利子抜き法 |
|---|--:|--:|
| 使用権資産(リース開始時) | {{ 240,000 * 5 }} | {{ 1,200,000 - 150,000 }} |
| 支払利息 | 0 | {{ 150,000 / 5 }} |
| 減価償却費 | {{ 240,000 * 5 / 5 }} | {{ (1,200,000 - 150,000) / 5 }} |
| 費用の合計 | {{ 240,000 * 5 / 5 }} | {{ 150,000 / 5 + (1,200,000 - 150,000) / 5 }} |

どちらの方法でも、1年目の費用の合計は同じになります(利息が定額法のため)。

### リース負債(利子抜き法) {#t-liability}

例4の1年目のリース負債です。

**リース負債**

| 借方 | 貸方 |
|---|---|
| 当座預金(支払い) {{ 240,000 - 150,000 / 5 }} | 使用権資産(開始時) {{ 1,200,000 - 150,000 }} |
| 次期繰越 {{ 1,200,000 - 150,000 - (240,000 - 150,000 / 5) }} | |

> [!覚える]
> - リースで借りたら「**使用権資産 / リース負債**」
> - 利子込み法は **リース料総額**、利子抜き法は **総額 − 利息相当額** で計上
> - 利子抜き法の利息は **定額法** で、払うたびに支払利息
> - 使用権資産は減価償却する(使用権資産減価償却累計額)
> - 短期(12か月以内)・少額リースは、払うたびに **支払リース料**

## 引っかけポイント {#traps}

1. 旧基準の科目(リース資産・リース債務)は使わない。新基準は使用権資産・リース負債。
2. 利子込み法で、支払利息を計上しない。払ったリース料は全額リース負債を減らす。
3. 利子抜き法で、払ったリース料の全額をリース負債から減らさない。利息分は支払利息。
4. 期の途中で始まったら、減価償却も利息も月割り。払う日が決算日より後なら、利息は未払利息で計上する。
5. 短期リースは12か月以内。賃貸借処理では支払リース料を使う(2級では支払家賃・支払地代を使わない)。

## 決算書ではここに出る {#fs}

使用権資産は有形固定資産(または無形固定資産)に、リース負債は負債(1年以内に払う分は流動負債、それ以外は固定負債)に表示します。新しい基準では、多くのリースが貸借対照表に載るので、負債が増えて見えます。M&Aでは、リース負債を借入金と同じような「借金」として、ネットデット(有利子負債 − 現金)に含めて考えることが多いので、金額と残りの期間を確かめます。

<details>
<summary>Q1. リース期間3年、リース料年額 ¥100,000 のリースを、利子込み法で始めた。使用権資産の額は?</summary>

¥{{ 100,000 * 3 }}(リース料総額)。

</details>

<details>
<summary>Q2. Q1 を利子抜き法(利息相当額 ¥30,000)で処理したとき、1回のリース料の支払いで支払利息はいくら?</summary>

¥{{ 30,000 / 3 }}(定額法。残りの {{ 100,000 - 30,000 / 3 }} はリース負債を減らす)。

</details>

<details>
<summary>Q3. リース期間8か月の機械のリース料を払った。賃貸借処理するときの科目は?</summary>

支払リース料(12か月以内の短期リース)。

</details>
