# C24 製造業の決算

## 要点3行 {#summary}

1. 製造業の決算では、**材料・仕掛品・製品** の3つの棚卸資産がある。工場の費用は製造原価(製造間接費など)、本社の費用は販売費及び一般管理費に分ける。
2. 製造原価は **製造原価報告書** にまとめる。当期総製造費用 + 期首仕掛品 − 期末仕掛品 = **当期製品製造原価**。
3. 売上原価 = 期首製品 + 当期製品製造原価 − 期末製品。予定配賦などで生じた **原価差異** は、売上原価に加減する。

## 仕訳パターン {#patterns}

### 工場の費用と本社の費用 {#split}

同じ種類の費用でも、工場の分は製造原価、本社の分は販売費及び一般管理費です。

**例1** 決算にあたり、賞与引当金を設定する。工場の従業員の分は ¥300,000、本社の従業員の分は ¥200,000。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 製造間接費 | 300,000 | 賞与引当金 | {{ 300,000 + 200,000 }} |
| 賞与引当金繰入 | 200,000 | | |

### 月次決算の調整 {#monthly}

**例2** 工場の建物の減価償却費は、年額 ¥240,000 を見積もり、毎月 ¥20,000 を製造間接費に計上している(11か月分を計上済み)。決算で、残りの1か月分を計上する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 製造間接費 | {{ 240,000 - 20,000 * 11 }} | 建物減価償却累計額 | {{ 240,000 - 20,000 * 11 }} |

### 材料の棚卸減耗 {#materials}

**例3** 材料の帳簿棚卸高は ¥104,000、実地棚卸高は ¥100,000 だった。減耗は正常なもの(原価性あり)。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 製造間接費 | {{ 104,000 - 100,000 }} | 材料 | {{ 104,000 - 100,000 }} |

正常な材料の棚卸減耗は、製造のための費用として製造間接費(間接経費)にします。

### 原価差異 {#variance}

**例4** 製造間接費の予定配賦額は ¥480,000、実際発生額は ¥500,000 だった。差額を原価差異に振り替え、決算で売上原価に賦課する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 原価差異 | {{ 500,000 - 480,000 }} | 製造間接費 | {{ 500,000 - 480,000 }} |
| 売上原価 | {{ 500,000 - 480,000 }} | 原価差異 | {{ 500,000 - 480,000 }} |

実際が予定より多い不利差異なので、売上原価を増やします(有利差異なら減らす)。

### 製造原価報告書と売上原価 {#report}

**例5** 当期の資料で、製造原価報告書と売上原価を計算する。

| 項目 | 金額 |
|---|--:|
| 材料費 | {{ 80,000 + 900,000 - 100,000 }} |
| 労務費 | 600,000 |
| 経費 | 300,000 |
| 当期総製造費用 | {{ 80,000 + 900,000 - 100,000 + 600,000 + 300,000 }} |
| 期首仕掛品棚卸高 | 150,000 |
| 期末仕掛品棚卸高 | 130,000 |
| 当期製品製造原価 | {{ 80,000 + 900,000 - 100,000 + 600,000 + 300,000 + 150,000 - 130,000 }} |

- 材料費 = 期首材料 80,000 + 当期仕入 900,000 − 期末材料 100,000 = {{ 80,000 + 900,000 - 100,000 }}
- 売上原価 = 期首製品 200,000 + {{ 80,000 + 900,000 - 100,000 + 600,000 + 300,000 + 150,000 - 130,000 }} − 期末製品 250,000 = {{ 200,000 + 80,000 + 900,000 - 100,000 + 600,000 + 300,000 + 150,000 - 130,000 - 250,000 }}
- 原価差異(不利){{ 500,000 - 480,000 }} を加えて、損益計算書の売上原価は {{ 200,000 + 80,000 + 900,000 - 100,000 + 600,000 + 300,000 + 150,000 - 130,000 - 250,000 + 500,000 - 480,000 }}

## T勘定・ボックス図 {#t-account}

### 原価の流れ {#flow}

| 勘定 | 借方(入) | 貸方(出) |
|---|---|---|
| 材料 | 期首 + 仕入 | 消費(仕掛品・製造間接費)+ 期末 |
| 仕掛品 | 期首 + 当期総製造費用 | 当期製品製造原価 + 期末 |
| 製品 | 期首 + 当期製品製造原価 | 売上原価 + 期末 |

貸借対照表には、期末の材料・仕掛品・製品が棚卸資産として表示されます。

> [!覚える]
> - 工場の費用は **製造原価**、本社の費用は **販売費及び一般管理費**
> - 当期製品製造原価 = 当期総製造費用 + **期首仕掛品 − 期末仕掛品**
> - 売上原価 = 期首製品 + 当期製品製造原価 − 期末製品(**± 原価差異**)
> - 月次で見積もって計上した分は、決算で **差額だけ** を計上する

## 引っかけポイント {#traps}

1. 減価償却費・賞与引当金繰入・退職給付費用は、工場の分と本社の分に分ける。工場の分は製造間接費。
2. 月次決算で毎月計上した分は、決算で年額から計上済みの額を引いた残りだけを計上する。
3. 当期製品製造原価は仕掛品勘定、売上原価は製品勘定で計算する。仕掛品と製品の期首・期末を取り違えない。
4. 不利な原価差異は売上原価に加え、有利な原価差異は差し引く。

## 決算書ではここに出る {#fs}

材料・仕掛品・製品は貸借対照表の棚卸資産、売上原価は損益計算書、製造原価の内訳は製造原価報告書に出ます。M&Aでは、製造原価報告書の材料費・労務費・経費の割合を見ると、その会社のコストの中身(材料の値上がりや人件費の影響を受けやすいか)がわかります。

<details>
<summary>Q1. 当期総製造費用 ¥1,000,000、期首仕掛品 ¥50,000、期末仕掛品 ¥80,000。当期製品製造原価は?</summary>

1,000,000 + 50,000 − 80,000 = ¥{{ 1,000,000 + 50,000 - 80,000 }}。

<details>
<summary>Q2. 本社の建物の減価償却費は、製造原価と販売費及び一般管理費のどちら?</summary>

販売費及び一般管理費(工場の建物なら製造間接費)。

</details>

<details>
<summary>Q3. 年額 ¥120,000 を毎月 ¥10,000 ずつ11か月計上済み。決算で計上する額は?</summary>

120,000 − 10,000 × 11 = ¥{{ 120,000 - 10,000 * 11 }}。

</details>
