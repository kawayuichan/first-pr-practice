# C04 債務の保証

## 要点3行 {#summary}

1. ほかの会社の借入金などの **保証人** になったら、「**保証債務見返 / 保証債務**」で備忘のための記録をする(対照勘定)。お金も借入金も動かない。
2. 保証した相手が **返済** したら、保証は終わるので、逆の仕訳で取り消す。
3. 相手が返済できず **代わりに払った** ら、相手に請求できる権利を **未収入金** にし、保証の記録も取り消す。

## 仕訳パターン {#patterns}

### 保証人になったとき {#guarantee}

**例1** 取引先A社の銀行からの借入金 ¥1,000,000 について、保証人になった。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 保証債務見返 | 1,000,000 | 保証債務 | 1,000,000 |

- まだお金を払っておらず、払うかどうかもわからない。忘れないための **備忘記録**
- 「保証債務見返」と「保証債務」は、いつも同じ金額で、セットで記録する(対照勘定)

### 相手が返済したとき {#release}

**例2** 例1のA社が、借入金を全額返済した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 保証債務 | 1,000,000 | 保証債務見返 | 1,000,000 |

保証する必要がなくなったので、例1の逆の仕訳で取り消します。

### 代わりに払ったとき {#default}

**例3** 例1のA社が返済できなくなり、当社が借入金 ¥1,000,000 と利息 ¥20,000 を、A社に代わって普通預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 未収入金 | {{ 1,000,000 + 20,000 }} | 普通預金 | {{ 1,000,000 + 20,000 }} |
| 保証債務 | 1,000,000 | 保証債務見返 | 1,000,000 |

- 代わりに払った額(利息を含む)は、あとでA社に請求できるので **未収入金**(資産)
- 保証は終わったので、保証債務と保証債務見返も取り消す

## T勘定・ボックス図 {#t-account}

### 3つの場面のまとめ {#overview}

| 場面 | 仕訳 |
|---|---|
| 保証人になった | 保証債務見返 / 保証債務 |
| 相手が返済した | 保証債務 / 保証債務見返 |
| 代わりに払った | 未収入金 / 普通預金 と 保証債務 / 保証債務見返 |

- 保証債務見返(借方)と保証債務(貸方)は、セットで増え、セットで消える
- 保証債務は **貸借対照表に載せず**、注記に「保証債務 ¥○○」と書く(まだ払うと決まっていない **偶発債務**)

> [!覚える]
> - 保証人になったら **保証債務見返 / 保証債務**(備忘記録)
> - 相手が返済したら **逆の仕訳で取り消す**
> - 代わりに払ったら **未収入金** にして、保証の記録も取り消す
> - 保証債務は貸借対照表に載せず **注記** する

## 引っかけポイント {#traps}

1. 保証人になっただけでは、お金も借入金も動かない。借入金を増やさない。
2. 保証債務見返は **借方**、保証債務は **貸方**。逆にしない。
3. 代わりに払ったときは2本の仕訳。未収入金の計上と、保証の記録の取り消し。
4. 未収入金は、代わりに払った額(利息を含む)。取り消す保証債務は、保証していた額。
5. 代わりに払った額は、まだ回収できる見込みがあるので、すぐに貸倒損失にしない。

## 決算書ではここに出る {#fs}

保証債務は貸借対照表には載らず、注記(決算書の脚注)に金額が書かれます。M&Aでは、こうした **簿外債務**(貸借対照表に出てこない負担)を必ず確かめます。買収した会社がほかの会社の借金を保証していて、その会社が返済できなくなると、代わりに払う義務を引き継ぐからです。

## 確認問題 {#check}

アプリの「問題を解く」で、C04の問題(6問)を解けます。ここでは3問だけ、すぐに答えを確認できます。

<details>
<summary>Q1. 取引先の借入金 ¥500,000 の保証人になった。仕訳は?</summary>

保証債務見返 500,000 / 保証債務 500,000。

</details>

<details>
<summary>Q2. 保証していた相手が、借入金を返済した。仕訳は?</summary>

保証債務 / 保証債務見返(保証したときの逆)。

</details>

<details>
<summary>Q3. 保証債務は貸借対照表のどこに載る?</summary>

載らない。注記に書く。

</details>
