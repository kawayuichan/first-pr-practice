# C05 銀行勘定調整表

## 要点3行 {#summary}

1. 決算日の当座預金の残高は、会社の帳簿と **銀行の残高証明書** で一致しないことがある。2つの残高を突き合わせて、ずれの原因を示す表が **銀行勘定調整表**。
2. 原因は、**会社側** を直すもの(連絡未通知・誤記入)と、銀行の記録が遅れているだけの **銀行側** のもの(時間外預入など)に分かれる。**仕訳が必要なのは会社側だけ**。
3. 2級の中心は **両者区分調整法**。会社の残高と銀行の残高をそれぞれ直して、同じ「正しい残高」にそろえる。貸借対照表には、この正しい残高を書く。

## 仕訳パターン {#patterns}

決算日に、銀行から **残高証明書**(その日の預金の残高を銀行が証明する書類)を取り寄せ、当座預金勘定の残高と比べます。

> 旧基準では小切手による不一致が中心でしたが、2027年度から小切手は範囲外です。このアプリでは、振込・引落し・預入による不一致を扱います。

### 不一致の原因 {#causes}

| 原因 | 直す側 | 仕訳 |
|---|---|---|
| 連絡未通知 | 会社 | 必要 |
| 誤記入 | 会社 | 必要 |
| 時間外預入 | 銀行 | 不要 |
| 振込の未処理 | 銀行 | 不要 |

- 会社側: 会社の帳簿に記録漏れや間違いがある → 帳簿を直す(仕訳する)
- 銀行側: 会社の帳簿は正しく、銀行の記録が遅れているだけ → 仕訳しない

### 連絡未通知 {#unnotified}

銀行では入金・引落しが済んでいるのに、会社に連絡が届かず、帳簿に記録していないものです。

**例1** 得意先から売掛金 ¥60,000 が当座預金に振り込まれていたが、連絡が届いていなかった。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 当座預金 | 60,000 | 売掛金 | 60,000 |

**例2** 電気料金 ¥18,000 が当座預金から引き落とされていたが、連絡が届いていなかった。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 水道光熱費 | 18,000 | 当座預金 | 18,000 |

### 誤記入 {#error}

会社が帳簿に間違った金額を書いたものです。**正しい金額との差額** だけを直します。

**例3** 買掛金の支払い(振込)¥43,000 を、帳簿に ¥34,000 と記入していた。

- 書いた仕訳: 買掛金 34,000 / 当座預金 34,000
- 正しい仕訳: 買掛金 43,000 / 当座預金 43,000
- 差額 {{ 43,000 - 34,000 }} だけ、当座預金をさらに減らす

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 買掛金 | {{ 43,000 - 34,000 }} | 当座預金 | {{ 43,000 - 34,000 }} |

入金を出金と **逆に** 書いたときは、間違いを取り消す分と正しく書く分で、**金額の2倍** を直します(入金 ¥25,000 を出金と書いた → 当座預金を {{ 25,000 * 2 }} 増やす)。

### 時間外預入 {#after-hours}

**例4** 決算日に現金 ¥50,000 を当座預金に預け入れたが、銀行の営業時間が終わったあとだったため、銀行では翌日の入金として扱われた。

仕訳なし。会社の帳簿は正しく、銀行の記録が1日遅れているだけです。銀行勘定調整表で **銀行の残高に加算** します。

### 振込の未処理 {#transfer}

**例5** 決算日に、買掛金 ¥70,000 を支払う振込の手続きをして帳簿に記入したが、受付時間を過ぎていたため、銀行の処理は翌営業日になった。

仕訳なし。銀行の残高にはまだ引落しが入っていないので、銀行勘定調整表で **銀行の残高から減算** します。

(公式の資料には、2027年度からの不一致の原因の例が書かれていません。振込の未処理は、このアプリで考えた例です。試験での扱いがわかったら見直します。)

### 両者区分調整法 {#both}

例1〜例5 をまとめます。決算日の当座預金勘定の残高は ¥400,000、銀行の残高証明書の残高は ¥{{ 400,000 + 60,000 - 18,000 - (43,000 - 34,000) - 50,000 + 70,000 }} でした。

**会社側**(仕訳する)

| 項目 | 金額 |
|---|--:|
| 当座預金勘定の残高 | 400,000 |
| 加算: 例1 売掛金の入金 | 60,000 |
| 減算: 例2 電気料金 | 18,000 |
| 減算: 例3 誤記入 | {{ 43,000 - 34,000 }} |
| 正しい残高 | {{ 400,000 + 60,000 - 18,000 - (43,000 - 34,000) }} |

**銀行側**(仕訳しない)

| 項目 | 金額 |
|---|--:|
| 残高証明書の残高 | {{ 400,000 + 60,000 - 18,000 - (43,000 - 34,000) - 50,000 + 70,000 }} |
| 加算: 例4 時間外預入 | 50,000 |
| 減算: 例5 振込の未処理 | 70,000 |
| 正しい残高 | {{ 400,000 + 60,000 - 18,000 - (43,000 - 34,000) }} |

両方が同じ **正しい残高** になれば、原因はすべて見つかったことになります。会社側の例1〜例3 を仕訳すると、当座預金勘定の残高も正しい残高になります。

### 企業残高基準法・銀行残高基準法 {#other-methods}

片方の残高から出発して、もう片方の残高に合わせる作り方です。

| 作り方 | 出発 | 合わせる先 |
|---|---|---|
| 企業残高基準法 | 会社の残高 | 銀行の残高 |
| 銀行残高基準法 | 銀行の残高 | 会社の残高 |

ポイントは、**相手側の項目は加算・減算を逆にする** ことです。例1〜例5 を企業残高基準法で書くと、次のようになります。

| 項目 | 金額 |
|---|--:|
| 当座預金勘定の残高 | 400,000 |
| 加算: 例1 売掛金の入金 | 60,000 |
| 加算: 例5 振込の未処理 | 70,000 |
| 減算: 例2 電気料金 | 18,000 |
| 減算: 例3 誤記入 | {{ 43,000 - 34,000 }} |
| 減算: 例4 時間外預入 | 50,000 |
| 残高証明書の残高 | {{ 400,000 + 60,000 + 70,000 - 18,000 - (43,000 - 34,000) - 50,000 }} |

- 例4 の時間外預入は、会社の残高には入っているが、銀行の残高にはまだ入っていない → 銀行の残高に合わせるには **減算**
- 銀行残高基準法は、この表を逆向きにたどる(銀行側の項目はそのまま、会社側の項目は加算・減算を逆にする)

## T勘定・ボックス図 {#t-account}

### 当座預金勘定の修正 {#t-bank}

例1〜例3 の仕訳を当座預金勘定に書くと、残高が正しい残高になります。

**当座預金**

| 借方 | 貸方 |
|---|---|
| 修正前の残高 400,000 | 例2 水道光熱費 18,000 |
| 例1 売掛金 60,000 | 例3 買掛金 {{ 43,000 - 34,000 }} |
| | 正しい残高 {{ 400,000 + 60,000 - 18,000 - (43,000 - 34,000) }} |

### 3つの残高の関係 {#relation}

- 会社の残高 400,000 → 会社側を直す(+60,000、−18,000、−{{ 43,000 - 34,000 }})→ **正しい残高 {{ 400,000 + 60,000 - 18,000 - (43,000 - 34,000) }}**
- 銀行の残高 {{ 400,000 + 60,000 - 18,000 - (43,000 - 34,000) - 50,000 + 70,000 }} → 銀行側を直す(+50,000、−70,000)→ **正しい残高 {{ 400,000 + 60,000 - 18,000 - (43,000 - 34,000) }}**

> [!覚える]
> - 仕訳が必要なのは **会社側**(連絡未通知・誤記入)だけ
> - 時間外預入は **銀行の残高に加算**、仕訳なし
> - 誤記入は **正しい金額との差額** だけ直す
> - 両者区分調整法は、両方を **正しい残高** にそろえる
> - 企業残高基準法・銀行残高基準法では、相手側の項目の **加算・減算を逆** にする

## 引っかけポイント {#traps}

1. 時間外預入・振込の未処理には仕訳をしない(会社の帳簿は正しい)。
2. 誤記入は、書いた金額ではなく **差額** を直す。入金と出金を逆に書いたときは **2倍**。
3. 連絡未通知の引落しは、相手の科目(水道光熱費・電子記録債務など)も忘れずに書く。
4. 貸借対照表の当座預金は、残高証明書の金額でも、修正前の帳簿の金額でもなく、**正しい残高**。
5. 企業残高基準法では、時間外預入は **減算**(両者区分調整法の「銀行に加算」と逆)。

## 決算書ではここに出る {#fs}

貸借対照表の「現金及び預金」には、銀行勘定調整表で確かめた正しい残高が入ります。M&Aの調査では、決算日の残高証明書と帳簿の残高を突き合わせ、ずれの理由を一つずつ確かめます。理由を説明できないずれは、記録漏れや不正のサインになるからです。

## 確認問題 {#check}

アプリの「問題を解く」で、C05の問題(10問)を解けます。ここでは3問だけ、すぐに答えを確認できます。

<details>
<summary>Q1. 両者区分調整法で、時間外預入はどちらの残高に加算・減算する?</summary>

銀行の残高に加算する。仕訳はしない(会社の帳簿は正しい)。

</details>

<details>
<summary>Q2. 通信費の支払い ¥12,000 を、帳簿に ¥21,000 と記入していた。修正の仕訳は?</summary>

当座預金 {{ 21,000 - 12,000 }} / 通信費 {{ 21,000 - 12,000 }}(多く減らしすぎた差額を戻す)。

</details>

<details>
<summary>Q3. 当座預金勘定の残高 ¥300,000。原因は、売掛金の入金 ¥20,000 の連絡未通知だけ。正しい残高は?</summary>

¥{{ 300,000 + 20,000 }}(会社側に加算)。

</details>
