# C20 合併

## 要点3行 {#summary}

1. **吸収合併** では、合併する会社(当社)が、消える会社の資産と負債を **時価** で受け入れ、その代わりに当社の株式を相手の株主に渡す。
2. 渡した株式の額(時価)は、問題文の指示どおりに **資本金・資本準備金・その他資本剰余金** に分けて増やす。
3. 渡した株式の額が、受け入れた純資産(資産 − 負債)より **多ければのれん**(資産)、**少なければ負ののれん発生益**(収益)。

## 仕訳パターン {#patterns}

### 吸収合併(のれん) {#goodwill}

**例1** 当社はB社を吸収合併し、B社の株主に当社の株式200株(1株の時価 ¥50,000)を交付した。全額を資本金とする。B社から受け入れた資産と負債(時価)は、売掛金 ¥3,000,000、建物 ¥6,000,000、買掛金 ¥2,000,000、借入金 ¥1,000,000。

- 交付した株式 = 50,000 × 200 = {{ 50,000 * 200 }}
- 受け入れた純資産 =(3,000,000 + 6,000,000)−(2,000,000 + 1,000,000)= {{ 3,000,000 + 6,000,000 - (2,000,000 + 1,000,000) }}
- のれん = {{ 50,000 * 200 }} − {{ 3,000,000 + 6,000,000 - (2,000,000 + 1,000,000) }} = {{ 50,000 * 200 - (3,000,000 + 6,000,000 - (2,000,000 + 1,000,000)) }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売掛金 | 3,000,000 | 買掛金 | 2,000,000 |
| 建物 | 6,000,000 | 借入金 | 1,000,000 |
| のれん | {{ 50,000 * 200 - (3,000,000 + 6,000,000 - (2,000,000 + 1,000,000)) }} | 資本金 | {{ 50,000 * 200 }} |

- 資産・負債は、B社の帳簿の金額ではなく **時価** で受け入れる
- のれんは、B社の稼ぐ力に対して多く払った分(C12 と同じ。20年以内に償却する)

### 資本金・資本準備金・その他資本剰余金に分ける {#equity-split}

**例2** 例1で、交付した株式 ¥10,000,000 のうち ¥6,000,000 を資本金、¥3,000,000 を資本準備金、残りをその他資本剰余金とする場合。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売掛金 | 3,000,000 | 買掛金 | 2,000,000 |
| 建物 | 6,000,000 | 借入金 | 1,000,000 |
| のれん | {{ 50,000 * 200 - (3,000,000 + 6,000,000 - (2,000,000 + 1,000,000)) }} | 資本金 | 6,000,000 |
| | | 資本準備金 | 3,000,000 |
| | | その他資本剰余金 | {{ 50,000 * 200 - 6,000,000 - 3,000,000 }} |

### 負ののれん {#negative}

**例3** C社を吸収合併し、当社の株式 ¥4,000,000 を交付した(全額資本金)。受け入れた資産(時価)は ¥7,000,000、負債(時価)は ¥2,500,000。

- 受け入れた純資産 = 7,000,000 − 2,500,000 = {{ 7,000,000 - 2,500,000 }}
- 負ののれん = {{ 7,000,000 - 2,500,000 }} − 4,000,000 = {{ 7,000,000 - 2,500,000 - 4,000,000 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 諸資産 | 7,000,000 | 諸負債 | 2,500,000 |
| | | 資本金 | 4,000,000 |
| | | 負ののれん発生益 | {{ 7,000,000 - 2,500,000 - 4,000,000 }} |

(「諸資産」「諸負債」は資産・負債をまとめて書いた説明用の表記。問題では個別の科目で答える)

純資産より安く手に入れたので、その差額は **負ののれん発生益**(特別利益)として、その期の収益にします。

## T勘定・ボックス図 {#t-account}

### のれんのボックス図 {#box}

例1の合併です。

| 項目 | 金額 |
|---|--:|
| 受け入れた資産(時価) | {{ 3,000,000 + 6,000,000 }} |
| 受け入れた負債(時価) | {{ 2,000,000 + 1,000,000 }} |
| 受け入れた純資産 | {{ 3,000,000 + 6,000,000 - (2,000,000 + 1,000,000) }} |
| 交付した株式 | {{ 50,000 * 200 }} |
| のれん(株式 − 純資産) | {{ 50,000 * 200 - (3,000,000 + 6,000,000 - (2,000,000 + 1,000,000)) }} |

> [!覚える]
> - 受け入れる資産・負債は **時価**
> - 交付した株式の額を、指示どおりに **資本金・資本準備金・その他資本剰余金** にする
> - 株式 > 純資産 → **のれん**(資産)、株式 < 純資産 → **負ののれん発生益**(収益)
> - のれんは **20年以内** に償却(C12)

## 引っかけポイント {#traps}

1. 受け入れる資産・負債を、相手の会社の帳簿の金額(簿価)で記録しない。時価。
2. のれんは、交付した株式と、資産だけではなく純資産(資産 − 負債)を比べる。
3. 交付した株式の額を、指示がなければ全額資本金にする。指示があれば分ける。
4. 負ののれんは、負債ではなく収益(負ののれん発生益)。

## 決算書ではここに出る {#fs}

合併で受け入れた資産・負債と、のれんが、貸借対照表に加わります。負ののれん発生益は、損益計算書の特別利益です。M&Aそのものの会計なので、M&Aの仕事ではとても大切です。買収の値段(交付した株式など)と、受け入れた純資産の時価の差がのれんになり、のれんが大きいほど「高く買った」ことを表します。

## 確認問題 {#check}

アプリの「問題を解く」で、C20の問題(8問)を解けます。ここでは3問だけ、すぐに答えを確認できます。

<details>
<summary>Q1. 合併で株式 ¥5,000,000 を交付した。受け入れた資産(時価) ¥6,000,000、負債(時価) ¥2,000,000。のれんは?</summary>

¥{{ 5,000,000 - (6,000,000 - 2,000,000) }}。

</details>

<details>
<summary>Q2. 交付した株式が、受け入れた純資産より少ないとき、差額の科目は?</summary>

負ののれん発生益(収益)。

</details>

<details>
<summary>Q3. 合併で受け入れる資産は、相手の帳簿の金額と時価のどちらで記録する?</summary>

時価。

</details>
