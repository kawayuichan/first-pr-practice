# C06 電子記録債権(2級)

## 要点3行 {#summary}

1. 電子記録債権は、仕入先への支払いに使う **譲渡** と、銀行に売ってお金にする **割引** ができる。割引で差し引かれる割引料は **電子記録債権売却損**(営業外費用)。
2. 電子記録債権は **分割** できるので、一部だけを譲渡・割引できる。使った分だけ電子記録債権を減らす。
3. 固定資産の売買など、商品売買以外の取引で生じたものは **営業外電子記録債権・営業外電子記録債務** にする。その割引の売却損は **営業外電子記録債権売却損**。

## 仕訳パターン {#patterns}

発生(電子記録債権 / 売掛金)と期日の決済は、3級(B06)と同じです。ここでは2級で加わる内容を学びます。

### 譲渡 {#transfer}

**例1(譲渡する側)** 仕入先に対する買掛金 ¥300,000 を支払うため、得意先に対する電子記録債権 ¥300,000 を、譲渡記録により仕入先に譲渡した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 買掛金 | 300,000 | 電子記録債権 | 300,000 |

**例2(受け取る側)** 例1の仕入先は、売掛金 ¥300,000 の回収として電子記録債権の譲渡を受けた。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 電子記録債権 | 300,000 | 売掛金 | 300,000 |

- 譲渡する側は、持っていた電子記録債権が減る(**電子記録債務は増えない**)
- 受け取る側は、売掛金が電子記録債権に変わる

### 一部の譲渡(分割) {#split}

**例3** 電子記録債権 ¥500,000 のうち ¥200,000 を、買掛金の支払いのため仕入先に譲渡した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 買掛金 | 200,000 | 電子記録債権 | 200,000 |

残りの {{ 500,000 - 200,000 }} は手元に残り、支払期日に決済されます。

### 割引 {#discount}

**例4** 電子記録債権 ¥400,000 を取引銀行で割り引き、割引料 ¥6,000 を差し引かれた残額が当座預金に入金された。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 当座預金 | {{ 400,000 - 6,000 }} | 電子記録債権 | 400,000 |
| 電子記録債権売却損 | 6,000 | | |

- 支払期日より前にお金にする代わりに、銀行に割引料を払う
- 債権を売った損なので **電子記録債権売却損**(支払利息ではない)
- 入金されるのは、額面から割引料を **差し引いた残り**

### 割引料の日割り計算 {#days}

割引料は「支払期日までの利息」にあたるので、年利率と日数から計算することもあります。

割引料 = 額面 × 年利率 × 支払期日までの日数 ÷ 365

**例5** 電子記録債権 ¥730,000 を、支払期日の60日前に年利率3%で割り引いた(1年は365日)。

- 割引料 = 730,000 × 3% × 60 ÷ 365 = {{ 730,000 * 3 / 100 * 60 / 365 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 当座預金 | {{ 730,000 - 730,000 * 3 / 100 * 60 / 365 }} | 電子記録債権 | 730,000 |
| 電子記録債権売却損 | {{ 730,000 * 3 / 100 * 60 / 365 }} | | |

### 営業外電子記録債権・営業外電子記録債務 {#nonoperating}

商品売買(本業)以外の取引で、電子記録債権・債務の発生記録をしたものです。3級(B07)の、売掛金と未収入金、買掛金と未払金の区別と同じ考え方です。

**例6(受け取る側)** 備品(取得原価 ¥500,000、減価償却累計額 ¥300,000、間接法)を ¥250,000 で売却し、代金は電子記録債権の発生記録により受け取ることにした。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 備品減価償却累計額 | 300,000 | 備品 | 500,000 |
| 営業外電子記録債権 | 250,000 | 固定資産売却益 | {{ 250,000 - (500,000 - 300,000) }} |

**例7(払う側)** 土地 ¥2,000,000 を購入し、代金は電子記録債務の発生記録を行った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 土地 | 2,000,000 | 営業外電子記録債務 | 2,000,000 |

支払期日の決済は「営業外電子記録債務 / 当座預金」です。

| 取引 | 受け取る側 | 払う側 |
|---|---|---|
| 商品売買 | 電子記録債権 | 電子記録債務 |
| 固定資産の売買など | 営業外電子記録債権 | 営業外電子記録債務 |

### 営業外電子記録債権の割引 {#nonop-discount}

**例8** 例6の営業外電子記録債権 ¥250,000 を銀行で割り引き、割引料 ¥2,000 を差し引かれた残額が当座預金に入金された。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 当座預金 | {{ 250,000 - 2,000 }} | 営業外電子記録債権 | 250,000 |
| 営業外電子記録債権売却損 | 2,000 | | |

(電子記録債権が支払期日に決済されなかったときの処理は、2027年度の区分表では範囲外です。)

## T勘定・ボックス図 {#t-account}

### 電子記録債権の1年間 {#t-denshi}

当期に売掛金から ¥900,000 が電子記録債権になり、¥200,000 を譲渡、¥400,000 を割引、¥100,000 が期日に決済されたとします(期首の残高はなし)。

**電子記録債権**

| 借方 | 貸方 |
|---|---|
| 売掛金(発生) 900,000 | 買掛金(譲渡) 200,000 |
| | 当座預金など(割引) 400,000 |
| | 当座預金(決済) 100,000 |
| | 次期繰越 {{ 900,000 - 200,000 - 400,000 - 100,000 }} |

- 譲渡・割引・決済のどれでも、電子記録債権は **減る**
- 期末に残るのは、まだ使っていない分だけ

### 決算書での表示 {#display}

| 科目 | 表示する場所 |
|---|---|
| 電子記録債権 | 貸借対照表の流動資産 |
| 営業外電子記録債権 | 貸借対照表の資産(1年以内に決済されるものは流動資産) |
| 電子記録債権売却損 | 損益計算書の営業外費用 |
| 営業外電子記録債権売却損 | 損益計算書の営業外費用 |

> [!覚える]
> - 譲渡 = 「**買掛金 / 電子記録債権**」(電子記録債務は増えない)
> - 割引の割引料は **電子記録債権売却損**(営業外費用)
> - 日割りの割引料 = **額面 × 年利率 × 日数 ÷ 365**
> - 一部だけ譲渡・割引したら、**使った分だけ** 減らす
> - 固定資産の売買など → **営業外** 電子記録債権・債務

## 引っかけポイント {#traps}

1. 譲渡して買掛金を払っても、電子記録債務は増えない。減るのは手元の **電子記録債権**。
2. 割引の入金額は額面ではなく、割引料を引いた残り。
3. 割引料は支払利息ではなく **電子記録債権売却損**。
4. 一部だけ譲渡・割引したとき、電子記録債権を全額減らさない。
5. 固定資産の売却代金・購入代金は **営業外** 電子記録債権・債務。営業外電子記録債権の割引は **営業外電子記録債権売却損**。
6. 日割りの計算を忘れて、1年分の割引料にしない。

## 決算書ではここに出る {#fs}

電子記録債権は、売掛金と合わせて貸借対照表の売上債権になります。譲渡・割引した分は手元からなくなるので、貸借対照表には残りません。割引の売却損は営業外費用です。M&Aでは、割引をよく使っている会社に注意します。売上債権が少なく見えても、割引で早めにお金にしているだけかもしれず、資金繰りが苦しいサインのこともあるからです。電子記録債権売却損の金額の推移を確かめます。

<details>
<summary>Q1. 買掛金 ¥100,000 を支払うため、電子記録債権 ¥100,000 を仕入先に譲渡した。仕訳は?</summary>

買掛金 100,000 / 電子記録債権 100,000。

</details>

<details>
<summary>Q2. 電子記録債権 ¥200,000 を割り引き、割引料 ¥3,000 を差し引かれて当座預金に入金された。当座預金に入る額は?</summary>

¥{{ 200,000 - 3,000 }}(差額の 3,000 は電子記録債権売却損)。

</details>

<details>
<summary>Q3. 車両を売却し、代金について電子記録債権の発生記録をした。使う科目は?</summary>

営業外電子記録債権(商品売買以外の取引のため)。

</details>
