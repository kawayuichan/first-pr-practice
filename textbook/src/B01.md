# B01 簿記の基本

## 要点3行 {#summary}

1. 会社の取引は **資産・負債・純資産・収益・費用** の5つの要素に分けて記録する。
2. 1つの取引を **左(借方)と右(貸方)に同じ金額** で記録するのが仕訳。だから左右の合計はいつも一致する。
3. **資産・費用は増えたら左**、**負債・純資産・収益は増えたら右**。減ったら反対側に書く。

## 仕訳パターン {#patterns}

### 5つの要素と置き場所 {#elements}

| 要素 | 意味と例 | 増えたら |
|---|---|---|
| 資産 | 会社が持っている財産・権利(現金、普通預金、備品、貸付金) | 借方(左) |
| 負債 | あとで払う義務(借入金、未払金、買掛金) | 貸方(右) |
| 純資産 | 株主の出資と、もうけのたくわえ(資本金、繰越利益剰余金) | 貸方(右) |
| 収益 | もうけを生む原因(売上、受取手数料、受取利息) | 貸方(右) |
| 費用 | もうけを減らす原因(給料、通信費、支払利息) | 借方(左) |

減ったとき(収益・費用は取り消すとき)は、表の反対側に書きます。

置き場所は、貸借対照表(左に資産、右に負債・純資産)と損益計算書(左に費用、右に収益)の形と同じです。→ [ボックス図](#box)

### 取引の8要素 {#eight}

仕訳の左右は、必ず次の組み合わせでできています。

| 借方(左)に書くもの | 貸方(右)に書くもの |
|---|---|
| 資産の増加 | 資産の減少 |
| 負債の減少 | 負債の増加 |
| 純資産の減少 | 純資産の増加 |
| 費用の発生 | 収益の発生 |

### 基本の仕訳 {#basic}

**例1** 株式を発行し、株主からの払込金 ¥500,000 が普通預金口座に入金された。(資産の増加/純資産の増加)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 普通預金 | 500,000 | 資本金 | 500,000 |

**例2** 銀行から ¥300,000 を借り入れ、現金で受け取った。(資産の増加/負債の増加)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 現金 | 300,000 | 借入金 | 300,000 |

**例3** 備品 ¥200,000 を買い、¥50,000 は現金で払い、残りは月末に払うことにした。(資産の増加/資産の減少・負債の増加)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 備品 | 200,000 | 現金 | 50,000 |
| | | 未払金 | {{ 200,000 - 50,000 }} |

**例4** 手数料 ¥30,000 を現金で受け取った。(資産の増加/収益の発生)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 現金 | 30,000 | 受取手数料 | 30,000 |

**例5** 給料 ¥120,000 を普通預金から支払った。(費用の発生/資産の減少)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 給料 | 120,000 | 普通預金 | 120,000 |

**例6** 借入金 ¥100,000 を、利息 ¥2,000 とともに現金で返した。(負債の減少・費用の発生/資産の減少)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 借入金 | 100,000 | 現金 | {{ 100,000 + 2,000 }} |
| 支払利息 | 2,000 | | |

> コツ: 先に「お金(現金・預金)がどうなったか」を書くと、もう片方が決まります。

## T勘定・ボックス図 {#t-account}

### 転記:仕訳をT勘定に写す {#posting}

- 仕訳の借方の金額は、その勘定の **借方** へ。貸方の金額は **貸方** へ。
- 金額の横には **相手の科目名** を書く。相手が2つ以上のときは「**諸口**」と書く。

例1〜例6のうち「現金」が出てくる仕訳(例2・例3・例4・例6)を、現金勘定に転記すると次のとおりです。

**現金**

| 借方 | 貸方 |
|---|---|
| 借入金 300,000 | 備品 50,000 |
| 受取手数料 30,000 | 諸口 {{ 100,000 + 2,000 }} |

- 借方の合計 {{ 300,000 + 30,000 }} − 貸方の合計 {{ 50,000 + 100,000 + 2,000 }} = **残高 {{ 300,000 + 30,000 - 50,000 - 100,000 - 2,000 }}**(借方に残る = 手元にある現金)

### 貸借平均の原理 {#balance}

どの仕訳も左右が同じ金額なので、すべての勘定の借方の合計と貸方の合計は **必ず一致** します。これを試算表で確かめます(→ B13)。

- 例1〜例6の借方の合計: {{ 500,000 + 300,000 + 200,000 + 30,000 + 120,000 + 100,000 + 2,000 }}
- 例1〜例6の貸方の合計: {{ 500,000 + 300,000 + 50,000 + (200,000 - 50,000) + 30,000 + 120,000 + (100,000 + 2,000) }}

### ボックス図:貸借対照表と損益計算書 {#box}

- **当期純利益 = 収益 − 費用 = 期末の純資産 − 期首の純資産**(増資・配当がないとき)
- 貸借対照表はいつでも **資産 = 負債 + 純資産**

**期首の貸借対照表**

| 借方 | 貸方 |
|---|---|
| 資産 800,000 | 負債 300,000 |
| | 純資産 {{ 800,000 - 300,000 }} |

**損益計算書(1年間)**

| 借方 | 貸方 |
|---|---|
| 費用 320,000 | 収益 400,000 |
| 当期純利益 {{ 400,000 - 320,000 }} | |

**期末の貸借対照表**(期末の負債は 350,000 とする)

| 借方 | 貸方 |
|---|---|
| 資産 {{ 350,000 + (800,000 - 300,000) + (400,000 - 320,000) }} | 負債 350,000 |
| | 純資産 {{ (800,000 - 300,000) + (400,000 - 320,000) }} |

期末の純資産 {{ (800,000 - 300,000) + (400,000 - 320,000) }} = 期首の純資産 {{ 800,000 - 300,000 }} + 当期純利益 {{ 400,000 - 320,000 }}

> [!覚える]
> - 5つの要素は **資産・負債・純資産・収益・費用**
> - **資産・費用** は増えたら左(借方)、**負債・純資産・収益** は増えたら右(貸方)
> - 仕訳の左右の合計は **いつも一致** する(貸借平均の原理)
> - 注文・契約だけでは **取引ではない**。盗難・火災は取引
> - 株主からの出資は **資本金(純資産)**。負債でも収益でもない

## 引っかけポイント {#traps}

1. **注文や契約だけでは取引にならない**。5つの要素がどれも増減していないから。反対に、**盗難や火災** は財産が減るので取引になる。
2. 商品以外(備品など)の代金を後払いにしたら **未払金**。**買掛金** は商品を仕入れたときだけ使う。
3. 借入金を返すときに払った利息は、借入金を減らさず **支払利息(費用)** にする。
4. 名前で判断しない。「未払金」は負債、「前払金」は資産(先に払って、あとで受け取る権利)、「支払利息」は費用。
5. 株主からの出資は返す必要がないので **負債ではなく純資産(資本金)**。もうけでもないので収益でもない。

## 決算書ではここに出る {#fs}

貸借対照表は「ある日の財産の一覧(資産 = 負債 + 純資産)」、損益計算書は「1年間のもうけの計算(収益 − 費用)」。M&Aで会社を調べるときも、まずこの2つの表の形から読みます。

## 確認問題 {#check}

アプリの「問題を解く」で、B01の問題(10問)を解けます。ここでは3問だけ、すぐに答えを確認できます。

<details>
<summary>Q1. 「前払金」は5つの要素のどれ?</summary>

資産。先に代金を払ったので、あとで商品などを受け取る権利がある。

</details>

<details>
<summary>Q2. 費用が発生したら、借方・貸方のどちらに書く?</summary>

借方(左)。

</details>

<details>
<summary>Q3. 期首の純資産 ¥400,000、当期純利益 ¥60,000(増資・配当なし)のとき、期末の純資産は?</summary>

¥{{ 400,000 + 60,000 }}(期首の純資産 + 当期純利益)

</details>
