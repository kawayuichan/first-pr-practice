# K03 労務費

## 要点3行 {#summary}

1. 賃金を払ったら、総額を **賃金・給料** の借方に記録し、源泉所得税などは **預り金**。月末に払っていない分は **未払賃金**(翌月初に元へ戻す)。
2. **直接工** の賃金は、**直接作業時間** の分を **仕掛品**(直接労務費)、**間接作業時間・手待時間** の分を **製造間接費** にする。多くは **予定賃率 × 作業時間** で計算する。
3. **間接工** の賃金は、当月の **要支払額**(当月支払 − 前月未払 + 当月未払)を全額 **製造間接費** にする。予定賃率で計算した消費額と実際の差は **賃率差異**。

## 仕訳パターン {#patterns}

### 賃金を払ったとき {#pay}

**例1** 当月の賃金の総額 ¥800,000 から、源泉所得税など ¥80,000 を差し引き、残りを当座預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 賃金・給料 | 800,000 | 預り金 | 80,000 |
| | | 当座預金 | {{ 800,000 - 80,000 }} |

### 直接工の賃金の消費 {#direct}

直接工の就業時間は、次のように分かれます。

| 時間 | 中身 | 振替先 |
|---|---|---|
| 直接作業時間 | 製品を作る作業(段取・加工) | 仕掛品(直接労務費) |
| 間接作業時間 | 機械の修理など、製品を直接作らない作業 | 製造間接費 |
| 手待時間 | 材料待ちなど、働けなかった時間 | 製造間接費 |

**例2** 直接工の当月の作業時間は、直接作業 500時間、間接作業 40時間、手待 10時間。予定賃率は1時間 ¥1,200。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕掛品 | {{ 1,200 * 500 }} | 賃金・給料 | {{ 1,200 * (500 + 40 + 10) }} |
| 製造間接費 | {{ 1,200 * (40 + 10) }} | | |

### 間接工の賃金の消費(要支払額) {#indirect}

**例3** 間接工の当月支払額は ¥300,000、前月末の未払は ¥50,000、当月末の未払は ¥60,000。

- 要支払額 = 300,000 − 50,000 + 60,000 = {{ 300,000 - 50,000 + 60,000 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 製造間接費 | {{ 300,000 - 50,000 + 60,000 }} | 賃金・給料 | {{ 300,000 - 50,000 + 60,000 }} |

当月に払った額には前月の分が含まれ、当月の分の一部はまだ払っていないので、当月に働いた分(要支払額)に直します。

### 賃率差異 {#variance}

**例4** 例2の直接工の、予定賃率による消費額は ¥{{ 1,200 * (500 + 40 + 10) }}、実際の消費額(要支払額)は ¥675,000 だった。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 賃率差異 | {{ 675,000 - 1,200 * (500 + 40 + 10) }} | 賃金・給料 | {{ 675,000 - 1,200 * (500 + 40 + 10) }} |

実際が予定より多いので **不利差異**(借方)。

### 未払賃金 {#accrued}

**例5** 月末に、当月分の賃金のうち未払の ¥60,000 を計上した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 賃金・給料 | 60,000 | 未払賃金 | 60,000 |

翌月初には逆の仕訳(未払賃金 / 賃金・給料)で元に戻します(再振替)。

## T勘定・ボックス図 {#t-account}

### 賃金・給料の勘定(間接工) {#t-wages}

例3を賃金・給料勘定で見ると、次のようになります。

**賃金・給料**

| 借方 | 貸方 |
|---|---|
| 当月支払 300,000 | 前月未払(再振替) 50,000 |
| 当月未払 60,000 | 消費(要支払額) {{ 300,000 - 50,000 + 60,000 }} |

> [!覚える]
> - 直接工の **直接作業時間** → 仕掛品、**間接作業・手待時間** → 製造間接費
> - 消費額 = **予定賃率 × 作業時間**
> - 間接工の要支払額 = **当月支払 − 前月未払 + 当月未払**(全額 製造間接費)
> - 予定と実際の差は **賃率差異**(実際が多い → 不利・借方)

## 引っかけポイント {#traps}

1. 手待時間の賃金も原価。直接労務費ではなく製造間接費。
2. 間接工の賃金は、当月の支払額ではなく要支払額で計算する。
3. 支払時は総額を賃金・給料に記録する(差し引いた手取額ではない)。
4. 賃率差異の向きは、実際の消費額が予定より多ければ不利(借方)。
5. 工場の事務員の給料も、製造間接費(間接労務費)。

## 決算書ではここに出る {#fs}

労務費は製造原価報告書の「労務費」に入り、未払賃金は貸借対照表の流動負債(未払費用)です。M&Aでは、製造原価に占める労務費の割合と、手待時間など働けなかった時間が多くないか(生産性)を確かめます。
