# K01 工業簿記の基礎

## 要点3行 {#summary}

1. 工業簿記は、材料を買い、製品を作り、売るまでを記録する。製品を作るのにかかった **原価** は、**材料費・労務費・経費** の3つに分ける。
2. どの製品にかかったかがはっきりわかる原価は **製造直接費**(仕掛品へ直接)、わからない原価は **製造間接費**(いったん集めて、あとで製品に配る=配賦)。
3. 原価は「材料・賃金・経費 → **仕掛品** → **製品** → **売上原価**」と流れる(勘定連絡)。1か月の製造の結果は **製造原価報告書** にまとめる。

## 仕訳パターン {#patterns}

この章から工業簿記です。工業簿記で使う科目(材料・賃金・給料・製造間接費・製品など)は、公式の商業簿記の勘定科目表にはないので、このアプリでは「公式表外」の補助リストから選びます。

### 原価の分け方 {#classes}

| 原価 | 製造直接費(どの製品かわかる) | 製造間接費(わからない) |
|---|---|---|
| 材料費 | 主要材料(製品の本体になる材料) | 補助材料・工場消耗品 |
| 労務費 | 直接工が製品を作る作業の賃金 | 間接工の賃金・工場の事務員の給料 |
| 経費 | 外注加工賃 | 工場の電力料・減価償却費・保険料 |

### 原価にならないもの(非原価項目) {#non-cost}

製品を作ること・売ることと関係のない費用は、原価に入れません。

- 支払利息(お金を借りたことによる費用)
- 火災損失など、めったに起きない損失
- 法人税等

販売費・一般管理費は原価ですが、製品を作る原価(**製造原価**)ではありません。製造原価に販売費・一般管理費を加えたものを **総原価** といいます。

### 原価計算の種類 {#types}

| 分け方 | 種類 | 使う場面 |
|---|---|---|
| 作り方 | 個別原価計算(K07) | 注文を受けて1つずつ作る |
| 作り方 | 総合原価計算(K08・K09) | 同じ製品をたくさん作る |
| 原価の種類 | 実際原価計算 | 実際にかかった原価で計算 |
| 原価の種類 | 標準原価計算(K10) | 目標の原価で計算し、実際と比べる |

### 勘定連絡(原価の流れ) {#flow}

**例1** 材料 ¥500,000 を掛けで買った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 材料 | 500,000 | 買掛金 | 500,000 |

**例2** 材料 ¥420,000 を消費した。このうち直接材料費は ¥360,000、間接材料費は ¥60,000。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕掛品 | 360,000 | 材料 | 420,000 |
| 製造間接費 | 60,000 | | |

**例3** 賃金 ¥400,000 を消費した。直接労務費 ¥300,000、間接労務費 ¥100,000。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕掛品 | 300,000 | 賃金・給料 | 400,000 |
| 製造間接費 | 100,000 | | |

**例4** 製造間接費 ¥250,000 を、製品(仕掛品)に配賦した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕掛品 | 250,000 | 製造間接費 | 250,000 |

**例5** 製品が完成した。完成品の原価は ¥800,000。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 製品 | 800,000 | 仕掛品 | 800,000 |

**例6** 製品(原価 ¥600,000)を ¥900,000 で掛けで売った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売掛金 | 900,000 | 売上 | 900,000 |
| 売上原価 | 600,000 | 製品 | 600,000 |

## T勘定・ボックス図 {#t-account}

### 原価の流れ {#flow-chart}

| 順番 | 勘定 | 入ってくるもの | 出ていくもの |
|---|---|---|---|
| 1 | 材料・賃金・給料・経費 | 買った額・支払った額 | 消費した額 |
| 2 | 製造間接費 | 間接費の消費額 | 製品への配賦額 |
| 3 | 仕掛品 | 直接費 + 配賦額 | 完成品の原価 |
| 4 | 製品 | 完成品の原価 | 売れた分の原価 |
| 5 | 売上原価 | 売れた分の原価 | (損益へ) |

### 製造原価報告書 {#report}

1か月の仕掛品の動きをまとめた表です(数字は例)。

| 項目 | 金額 |
|---|--:|
| 材料費 | 420,000 |
| 労務費 | 400,000 |
| 経費 | 180,000 |
| 当期総製造費用 | {{ 420,000 + 400,000 + 180,000 }} |
| 期首仕掛品棚卸高 | 70,000 |
| 合計 | {{ 420,000 + 400,000 + 180,000 + 70,000 }} |
| 期末仕掛品棚卸高 | 90,000 |
| 当期製品製造原価 | {{ 420,000 + 400,000 + 180,000 + 70,000 - 90,000 }} |

- 当期製品製造原価 = 期首仕掛品 + 当期総製造費用 − 期末仕掛品
- 売上原価 = 期首製品 + 当期製品製造原価 − 期末製品

> [!覚える]
> - 原価は **材料費・労務費・経費**、それぞれ **直接費と間接費** に分ける
> - 支払利息・火災損失・法人税等は **原価にならない**
> - 流れは「材料・賃金・経費 → **仕掛品** → **製品** → **売上原価**」
> - 当期製品製造原価 = **期首仕掛品 + 当期総製造費用 − 期末仕掛品**

## 引っかけポイント {#traps}

1. 間接材料費・間接労務費は、仕掛品ではなく製造間接費に入れる。
2. 工場の事務員の給料は間接労務費(製造原価)。本社の事務員の給料は一般管理費(製造原価ではない)。
3. 支払利息は原価に入れない。
4. 完成したら「製品 / 仕掛品」、売れたら「売上原価 / 製品」。
5. 製造原価報告書で、期首仕掛品は足し、期末仕掛品は引く。

## 決算書ではここに出る {#fs}

製造業の会社は、損益計算書の売上原価の計算に「当期製品製造原価」を使い、その内訳を製造原価報告書で示します。貸借対照表では、材料・仕掛品・製品が「棚卸資産」になります。M&Aでは、製造原価のうち材料費・労務費の割合や、在庫(材料・仕掛品・製品)が多すぎないかを確かめます。

## 確認問題 {#check}

アプリの「問題を解く」で、K01の問題(10問)を解けます。ここでは3問だけ、すぐに答えを確認できます。

<details>
<summary>Q1. 間接材料費 ¥30,000 を消費した。借方の科目は?</summary>

製造間接費(貸方は材料)。

</details>

<details>
<summary>Q2. 当期総製造費用 ¥900,000、期首仕掛品 ¥50,000、期末仕掛品 ¥80,000。当期製品製造原価は?</summary>

¥{{ 900,000 + 50,000 - 80,000 }}。

</details>

<details>
<summary>Q3. 支払利息は原価に入る?</summary>

入らない(非原価項目)。

</details>
