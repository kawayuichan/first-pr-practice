# C10 有形固定資産②取得

## 要点3行 {#summary}

1. **割賦購入** は、代金を何回かに分けて払う買い方。取得原価は一括で買うときの値段(**現金正価**)で、分割にして高くなった差額は **利息** として区分し、支払いのたびに **定額法** で費用(支払利息)にする。
2. **圧縮記帳** は、国からの **国庫補助金** や **工事負担金** を使って固定資産を買ったとき、その額だけ取得原価を減らす方法。2級は **直接控除方式** で、減らした額は **固定資産圧縮損**。減価償却は **圧縮後の金額** で計算する。
3. 建設中の建物などに払った代金は **建設仮勘定** にしておき、完成して引渡しを受けたら **建物** などに振り替える。建設仮勘定は減価償却しない。

## 仕訳パターン {#patterns}

### 割賦購入(前払利息で処理) {#installment}

**例1** X1年11月1日に、備品(現金正価 ¥500,000)を割賦で買った。代金は ¥520,000 で、11月末から毎月末に ¥52,000 ずつ10回で払う。利息相当額は前払利息で処理する。

- 利息 = 520,000 − 500,000 = {{ 520,000 - 500,000 }}(1回あたり {{ (520,000 - 500,000) / 10 }})

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 備品 | 500,000 | 未払金 | 520,000 |
| 前払利息 | {{ 520,000 - 500,000 }} | | |

**例2** 11月30日に、1回目の ¥52,000 を当座預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 未払金 | 52,000 | 当座預金 | 52,000 |
| 支払利息 | {{ (520,000 - 500,000) / 10 }} | 前払利息 | {{ (520,000 - 500,000) / 10 }} |

- 取得原価は分割払いの総額ではなく **現金正価**
- 支払うたびに、1回分の利息を前払利息から **支払利息** へ振り替える(定額法)。利息法は1級の範囲
- 固定資産の代金なので **未払金**(買掛金ではない)

### もう一つの形(支払利息で処理) {#alternative}

**例3** 例1で、利息相当額を買ったときに支払利息で処理した場合。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 備品 | 500,000 | 未払金 | 520,000 |
| 支払利息 | {{ 520,000 - 500,000 }} | | |

支払うときは「未払金 / 当座預金」だけです。決算日(3月31日)には5回(11月〜3月)を払い終えているので、残り5回分の利息を **前払利息** に振り替えます。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 前払利息 | {{ (520,000 - 500,000) / 10 * 5 }} | 支払利息 | {{ (520,000 - 500,000) / 10 * 5 }} |

どちらの形でも、当期の支払利息は {{ (520,000 - 500,000) / 10 * 5 }}、決算日の前払利息は {{ (520,000 - 500,000) / 10 * 5 }} になります。

### 電子記録債務で払う {#denshi}

**例4** 機械装置(現金正価 ¥1,200,000)を割賦で買い、代金 ¥1,260,000 について、6回分(1回 ¥210,000)の電子記録債務の発生記録を行った。利息相当額は前払利息で処理する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 機械装置 | 1,200,000 | 営業外電子記録債務 | 1,260,000 |
| 前払利息 | {{ 1,260,000 - 1,200,000 }} | | |

固定資産の代金なので **営業外** 電子記録債務(C06)。支払期日には「営業外電子記録債務 210,000 / 当座預金 210,000」と、1回分の利息 {{ (1,260,000 - 1,200,000) / 6 }} の振替(支払利息 / 前払利息)をします。

### 圧縮記帳(国庫補助金) {#compression}

**例5** 備品を買うための国庫補助金 ¥400,000 を受け取り、普通預金口座に入金された。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 普通預金 | 400,000 | 国庫補助金受贈益 | 400,000 |

**例6** X1年4月1日に、補助金と自己資金で備品 ¥1,000,000 を買い、普通預金口座から支払った。補助金の分だけ、直接控除方式で圧縮記帳した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 備品 | 1,000,000 | 普通預金 | 1,000,000 |
| 固定資産圧縮損 | 400,000 | 備品 | 400,000 |

- 圧縮後の備品の帳簿価額は {{ 1,000,000 - 400,000 }}
- 受贈益(収益)と圧縮損(費用)が同じ額で打ち消し合うので、補助金を受け取った年に利益(税金)が増えない
- **工事負担金**(電力会社などが、設備の工事の費用として利用者から受け取るお金)も、受け取ったら **工事負担金受贈益**、圧縮は同じく「固定資産圧縮損 / 設備の科目」
- 2級は直接控除方式だけ。積立金方式は1級の範囲

### 圧縮記帳したあとの減価償却 {#after}

**例7** X2年3月31日(決算)。例6の備品を、定額法(耐用年数5年、残存価額ゼロ)、間接法で減価償却する。

- 減価償却費 = (1,000,000 − 400,000)÷ 5年 = {{ (1,000,000 - 400,000) / 5 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 減価償却費 | {{ (1,000,000 - 400,000) / 5 }} | 備品減価償却累計額 | {{ (1,000,000 - 400,000) / 5 }} |

**圧縮後の金額** で計算します(圧縮前の 1,000,000 で計算しない)。

### 建設仮勘定 {#cip}

**例8** 店舗の建設を建設会社に頼み、請負代金 ¥8,000,000 のうち手付金 ¥2,000,000 を当座預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 建設仮勘定 | 2,000,000 | 当座預金 | 2,000,000 |

**例9** 店舗が完成して引渡しを受け、残りの代金を当座預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 建物 | 8,000,000 | 建設仮勘定 | 2,000,000 |
| | | 当座預金 | {{ 8,000,000 - 2,000,000 }} |

- 完成前の支払いは、まだ使える建物がないので **建設仮勘定**(減価償却しない)
- 完成したら、手付金を含めた **全額** を建物にする

## T勘定・ボックス図 {#t-account}

### 割賦の前払利息(例1・例2の形) {#t-prepaid}

決算日(3月31日)までに5回払ったときの前払利息です。

**前払利息**

| 借方 | 貸方 |
|---|---|
| 未払金(買ったとき) {{ 520,000 - 500,000 }} | 支払利息(5回分) {{ (520,000 - 500,000) / 10 * 5 }} |
| | 次期繰越 {{ (520,000 - 500,000) - (520,000 - 500,000) / 10 * 5 }} |

### 圧縮記帳の帳簿価額 {#t-compression}

| 項目 | 金額 |
|---|--:|
| 取得原価 | 1,000,000 |
| 圧縮額(国庫補助金) | 400,000 |
| 帳簿価額(減価償却の基準) | {{ 1,000,000 - 400,000 }} |

> [!覚える]
> - 割賦の取得原価は **現金正価**。総額との差額は **利息**(前払利息)
> - 前払利息は、支払うたびに **定額法** で支払利息へ振り替える
> - 圧縮記帳(直接控除方式)は「**固定資産圧縮損** / 備品など」
> - 圧縮後の減価償却は **取得原価 − 圧縮額** で計算する
> - 建設中の支払いは **建設仮勘定**、完成したら全額を建物へ(減価償却しない)

## 引っかけポイント {#traps}

1. 割賦の取得原価は、分割払いの総額ではなく現金正価。
2. 前払利息で処理したら、支払うたびに支払利息への振替を忘れない。
3. 固定資産の割賦代金は、未払金または営業外電子記録債務(買掛金・電子記録債務ではない)。
4. 圧縮記帳した固定資産の減価償却費は、圧縮後の金額で計算する。
5. 建設仮勘定は減価償却しない。完成したら、手付金を含めた全額を建物に振り替える。
6. 補助金を受け取ったときは収益(国庫補助金受贈益)。借入金ではないので返さない。

## 決算書ではここに出る {#fs}

割賦で買った固定資産の未払分は、貸借対照表の負債(未払金・営業外電子記録債務。1年を超えて払う分は長期未払金など)です。圧縮記帳した固定資産は、補助金の分だけ小さい金額で貸借対照表に載ります。国庫補助金受贈益は特別利益、固定資産圧縮損は特別損失に表示します。建設仮勘定は有形固定資産です。M&Aでは、建設仮勘定が大きければ、完成までにまだお金がかかるかを確かめます。圧縮記帳した資産は実際に払った額より小さく見えるので、補助金の条件(返す必要がないか)も確かめます。
