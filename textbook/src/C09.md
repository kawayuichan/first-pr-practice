# C09 有価証券②満期保有・子会社・その他

## 要点3行 {#summary}

1. 有価証券は持つ目的で4つに分ける。**売買目的有価証券**(C08)、**満期保有目的債券**、**子会社株式・関連会社株式**、**その他有価証券**。決算での評価が目的ごとに違う。
2. 満期保有目的債券は、額面と取得価額の差額を満期までの期間に **定額法** で配分し、帳簿価額を額面に近づける(**償却原価法**)。相手の科目は **有価証券利息**。子会社株式・関連会社株式は **取得原価のまま**(評価替えしない)。
3. その他有価証券は **時価** に評価替えし、差額は損益にせず **その他有価証券評価差額金**(純資産)にする(**全部純資産直入法**)。翌期首に元の取得原価へ戻す。

## 仕訳パターン {#patterns}

### 4つの分類 {#classes}

| 分類 | 決算の評価 | 差額の処理 |
|---|---|---|
| 売買目的(C08) | 時価 | 有価証券評価益・評価損(損益) |
| 満期保有目的 | 償却原価 | 有価証券利息(損益) |
| 子会社・関連会社 | 取得原価 | なし |
| その他 | 時価 | その他有価証券評価差額金(純資産) |

- **満期保有目的債券**: 満期まで持ち続けるつもりの社債・国債など
- **子会社株式**: 発行済株式の50%超を持つなど、支配している会社の株式
- **関連会社株式**: 発行済株式の20%以上を持つなど、大きな影響を与えられる会社の株式
- **その他有価証券**: 上のどれにも当たらないもの(取引先との関係を保つために持つ株式など)

### 満期保有目的債券を買う {#htm-buy}

**例1** X1年4月1日(期首)に、満期まで持つ目的で、A社社債(額面 ¥1,000,000、満期はX6年3月31日)を ¥970,000 で買い、普通預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 満期保有目的債券 | 970,000 | 普通預金 | 970,000 |

### 償却原価法(定額法) {#amortized}

額面より安く買った差額は、満期までの利息の調整と考えて、毎期少しずつ帳簿価額に足します。

**例2** X2年3月31日(決算)。例1の社債に償却原価法(定額法)を適用する。

- 差額 = 1,000,000 − 970,000 = {{ 1,000,000 - 970,000 }}
- 1年分 = {{ 1,000,000 - 970,000 }} ÷ 5年 = {{ (1,000,000 - 970,000) / 5 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 満期保有目的債券 | {{ (1,000,000 - 970,000) / 5 }} | 有価証券利息 | {{ (1,000,000 - 970,000) / 5 }} |

- 相手の科目は **有価証券利息**(評価益ではない)
- 毎期同じ額を足し、満期の日にちょうど額面になる
- 2級の問題は、差額が金利の調整と認められる前提。利息法は1級の範囲

### 期の途中で買ったとき(月割り) {#midyear}

**例3** X1年7月1日に、満期まで持つ目的で、社債(額面 ¥2,000,000、満期はX6年6月30日)を ¥1,940,000 で買った。決算日は3月31日。

- 差額 = 2,000,000 − 1,940,000 = {{ 2,000,000 - 1,940,000 }}、満期までは60か月
- 1か月分 = {{ 2,000,000 - 1,940,000 }} ÷ 60 = {{ (2,000,000 - 1,940,000) / 60 }}
- X2年3月31日の償却額 = {{ (2,000,000 - 1,940,000) / 60 }} × 9か月(7月〜3月)= {{ (2,000,000 - 1,940,000) / 60 * 9 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 満期保有目的債券 | {{ (2,000,000 - 1,940,000) / 60 * 9 }} | 有価証券利息 | {{ (2,000,000 - 1,940,000) / 60 * 9 }} |

次の期からは、1年分の {{ (2,000,000 - 1,940,000) / 60 * 12 }} ずつ償却します。

### 利息を受け取る {#coupon}

**例4** 例1の社債の利息 ¥10,000(年1回、3月末払い)が、普通預金口座に入金された。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 普通預金 | 10,000 | 有価証券利息 | 10,000 |

### 子会社株式・関連会社株式 {#affiliates}

**例5** B社の発行済株式の60%を ¥3,000,000 で買い、B社を子会社にした。代金は普通預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 子会社株式 | 3,000,000 | 普通預金 | 3,000,000 |

**例6** 決算で、例5のB社株式の時価は ¥3,200,000 だった。

仕訳なし。子会社株式・関連会社株式は、売るために持っているのではないので、**取得原価のまま** にします。

### その他有価証券 {#afs}

**例7** 取引先C社との関係を保つため、C社株式を ¥500,000 で買い、普通預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| その他有価証券 | 500,000 | 普通預金 | 500,000 |

**例8** 決算で、C社株式の時価は ¥560,000 だった(全部純資産直入法)。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| その他有価証券 | {{ 560,000 - 500,000 }} | その他有価証券評価差額金 | {{ 560,000 - 500,000 }} |

- 時価が下がったときは「その他有価証券評価差額金 / その他有価証券」
- 評価差額は損益計算書を通さず、全部を貸借対照表の純資産に入れる(**全部純資産直入法**)。部分純資産直入法は1級の範囲
- 税効果会計を使う場合の仕訳は、C18 で学ぶ

**例9** 翌期首に、例8の評価替えを元に戻す。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| その他有価証券評価差額金 | {{ 560,000 - 500,000 }} | その他有価証券 | {{ 560,000 - 500,000 }} |

**例10** その後、C社株式をすべて ¥580,000 で売り、代金は普通預金口座に入金された。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 普通預金 | 580,000 | その他有価証券 | 500,000 |
| | | 投資有価証券売却益 | {{ 580,000 - 500,000 }} |

期首に取得原価へ戻しているので、売却益は **取得原価との差** です。科目は **投資有価証券売却益**(売却損なら投資有価証券売却損)。

## T勘定・ボックス図 {#t-account}

### 満期保有目的債券の帳簿価額 {#t-htm}

例1の社債の、決算後の帳簿価額です。毎期 {{ (1,000,000 - 970,000) / 5 }} ずつ増え、満期に額面になります。

| 決算日 | 帳簿価額 |
|---|--:|
| 買った日(X1年4月1日) | 970,000 |
| X2年3月31日 | {{ 970,000 + (1,000,000 - 970,000) / 5 }} |
| X3年3月31日 | {{ 970,000 + (1,000,000 - 970,000) / 5 * 2 }} |
| X4年3月31日 | {{ 970,000 + (1,000,000 - 970,000) / 5 * 3 }} |
| X5年3月31日 | {{ 970,000 + (1,000,000 - 970,000) / 5 * 4 }} |
| X6年3月31日(満期) | {{ 970,000 + (1,000,000 - 970,000) / 5 * 5 }} |

### 決算書での表示 {#display}

| 科目 | 貸借対照表の表示 |
|---|---|
| 満期保有目的債券 | 投資有価証券(固定資産)。1年以内に満期が来るものは有価証券(流動資産) |
| 子会社株式・関連会社株式 | 関係会社株式(固定資産) |
| その他有価証券 | 投資有価証券(固定資産) |
| その他有価証券評価差額金 | 純資産(評価・換算差額等) |

> [!覚える]
> - 満期保有目的債券の差額は **定額法** で配分 → 「満期保有目的債券 / **有価証券利息**」
> - 期の途中で買ったら、最初の年は **月割り**
> - 子会社株式・関連会社株式は **評価替えしない**(取得原価のまま)
> - その他有価証券の評価差額は **その他有価証券評価差額金**(純資産)。翌期首に **元へ戻す**
> - その他有価証券の売却損益は **取得原価との差**(投資有価証券売却益・売却損)

## 引っかけポイント {#traps}

1. 償却原価法の相手の科目は有価証券利息。有価証券評価益ではない。
2. 償却額は、買った日から満期までの期間で割る。期の途中で買ったら、最初の年は月割り。
3. 子会社株式・関連会社株式は、時価が変わっても仕訳しない。
4. その他有価証券の評価差額は損益にしない(その他有価証券評価差額金)。
5. その他有価証券を売ったときの売却損益は、前期末の時価ではなく取得原価との差。科目は投資有価証券売却益・売却損(有価証券売却益ではない)。
6. 子会社(50%超など)と関連会社(20%以上など)を取り違えない。

## 決算書ではここに出る {#fs}

子会社株式・関連会社株式は取得原価のままなので、貸借対照表の金額が今の価値とずれていることがあります。その他有価証券評価差額金は純資産に入るので、時価が上がると純資産は増えますが、利益(損益計算書)には出ません。M&Aでは、関係会社株式の中身(どの会社を、いくらで、何%持っているか)と、その他有価証券評価差額金の大きさ(株価が下がると純資産が減る)を確かめます。

## 確認問題 {#check}

アプリの「問題を解く」で、C09の問題(12問)を解けます。ここでは3問だけ、すぐに答えを確認できます。

<details>
<summary>Q1. 額面 ¥500,000 の社債(期首に買い、満期まで4年)を ¥480,000 で買った。1年分の償却額は?</summary>

¥{{ (500,000 - 480,000) / 4 }}(差額 {{ 500,000 - 480,000 }} ÷ 4年)。相手の科目は有価証券利息。

</details>

<details>
<summary>Q2. 子会社株式の決算日の時価が、取得原価より上がっていた。仕訳は?</summary>

仕訳なし(取得原価のまま)。

</details>

<details>
<summary>Q3. その他有価証券(取得原価 ¥300,000)の決算日の時価が ¥280,000 だった。仕訳は?</summary>

その他有価証券評価差額金 {{ 300,000 - 280,000 }} / その他有価証券 {{ 300,000 - 280,000 }}。

</details>
