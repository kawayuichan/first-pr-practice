# B08 貸倒れと貸倒引当金

## 要点3行 {#summary}

1. 決算で、売掛金・電子記録債権のうち回収できなくなりそうな額を見積もり、**貸倒引当金** を設定する。見積額 = 期末の債権 × 貸倒実績率。
2. **差額補充法**: 見積額と貸倒引当金の残高の差額だけ、**貸倒引当金繰入**(費用)にする。残高のほうが多ければ **貸倒引当金戻入**(収益)。
3. 前期以前の債権が貸倒れたら貸倒引当金を取り崩し、足りない分と当期の債権の貸倒れは **貸倒損失**。貸倒れ処理した債権をあとで回収したら **償却債権取立益**。

## 仕訳パターン {#patterns}

### 決算で貸倒引当金を設定する {#setting}

**例1** 決算で、売掛金 ¥300,000 と電子記録債権 ¥200,000 の期末残高に対して、貸倒実績率2%で貸倒引当金を設定する(差額補充法)。貸倒引当金の残高は ¥4,000。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 貸倒引当金繰入 | {{ (300,000 + 200,000) * 2 / 100 - 4,000 }} | 貸倒引当金 | {{ (300,000 + 200,000) * 2 / 100 - 4,000 }} |

- 見積額 = (300,000 + 200,000) × 2% = {{ (300,000 + 200,000) * 2 / 100 }}
- 繰入額 = 見積額 − 残高 = {{ (300,000 + 200,000) * 2 / 100 }} − 4,000 = {{ (300,000 + 200,000) * 2 / 100 - 4,000 }}

**例2** 例1で、貸倒引当金の残高が ¥12,000 だった場合。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 貸倒引当金 | {{ 12,000 - (300,000 + 200,000) * 2 / 100 }} | 貸倒引当金戻入 | {{ 12,000 - (300,000 + 200,000) * 2 / 100 }} |

残高 12,000 が見積額 {{ (300,000 + 200,000) * 2 / 100 }} より多いので、多すぎる分を減らして **貸倒引当金戻入**(収益)にします。

### 貸倒れが起きたとき {#writeoff}

**例3** 前期に販売した商品の売掛金 ¥5,000 が貸倒れた。貸倒引当金の残高は ¥8,000。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 貸倒引当金 | 5,000 | 売掛金 | 5,000 |

**例4** 前期に販売した商品の売掛金 ¥10,000 が貸倒れた。貸倒引当金の残高は ¥6,000。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 貸倒引当金 | 6,000 | 売掛金 | 10,000 |
| 貸倒損失 | {{ 10,000 - 6,000 }} | | |

**例5** 当期に販売した商品の売掛金 ¥3,000 が貸倒れた。貸倒引当金の残高は ¥8,000。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 貸倒損失 | 3,000 | 売掛金 | 3,000 |

- 貸倒引当金は、**前期末の債権** に備えて設定したもの。前期以前の債権の貸倒れに使う
- 引当金で足りない分は **貸倒損失**(費用)
- 当期に発生した債権の貸倒れは、引当金を使わずに全額 **貸倒損失**

### 貸倒れ処理した債権を回収したとき {#recovery}

**例6** 前期に貸倒れとして処理した売掛金のうち ¥7,000 を、現金で回収した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 現金 | 7,000 | 償却債権取立益 | 7,000 |

売掛金は貸倒れのときにもう消しているので、売掛金は使いません。思いがけず戻ってきたお金として **償却債権取立益**(収益)にします。

## T勘定・ボックス図 {#t-account}

### 貸倒引当金の1年間 {#t-allowance}

期首の残高が ¥8,000、期中に例3の貸倒れ(¥5,000)があり、期末の見積額が ¥10,000 だったとします。

**貸倒引当金**

| 借方 | 貸方 |
|---|---|
| 売掛金(貸倒れ) 5,000 | 前期繰越 8,000 |
| 次期繰越 10,000 | 貸倒引当金繰入 {{ 10,000 - (8,000 - 5,000) }} |

- 決算の前の残高 = 8,000 − 5,000 = {{ 8,000 - 5,000 }}
- 繰入額 = 見積額 − 決算の前の残高 = 10,000 − {{ 8,000 - 5,000 }} = {{ 10,000 - (8,000 - 5,000) }}
- 期末の残高(次期繰越)は、必ず **見積額** になる

### 貸借対照表での見せ方 {#bs}

貸倒引当金は、債権から差し引く形で表示します(例1の見積額を、売掛金と電子記録債権に分けたもの)。

| 科目 | 金額 | 差し引き後 |
|---|--:|--:|
| 売掛金 | 300,000 | |
| 貸倒引当金 | △{{ 300,000 * 2 / 100 }} | {{ 300,000 - 300,000 * 2 / 100 }} |
| 電子記録債権 | 200,000 | |
| 貸倒引当金 | △{{ 200,000 * 2 / 100 }} | {{ 200,000 - 200,000 * 2 / 100 }} |

(△ はマイナスの意味)

> [!覚える]
> - 決算の繰入額 = **見積額 − 残高**(差額補充法)。残高が多ければ **貸倒引当金戻入**
> - 前期以前の債権の貸倒れ → **貸倒引当金** を取り崩す。足りない分は **貸倒損失**
> - **当期に発生した** 債権の貸倒れ → 全額 **貸倒損失**
> - 前期に貸倒れ処理した債権の回収 → **償却債権取立益**

## 引っかけポイント {#traps}

1. 決算の繰入額は「見積額 − 残高」の **差額**。見積額をそのまま繰入にしない。
2. 残高が見積額より多いときは、貸倒引当金を減らして **貸倒引当金戻入**(収益)。
3. **当期に発生した** 債権の貸倒れは、引当金を使わずに貸倒損失。
4. 前期以前の債権の貸倒れで、引当金が足りない分は貸倒損失。
5. 前期以前に貸倒れ処理した債権を回収したら **償却債権取立益**。売掛金は使わない。
6. 設定する対象(売掛金だけか、電子記録債権も入るか)を問題文で確かめる。

## 決算書ではここに出る {#fs}

貸借対照表では、売掛金・電子記録債権から貸倒引当金を差し引いて表示します。損益計算書では、売上債権に対する貸倒引当金繰入は「販売費及び一般管理費」です。M&Aでは、回収が遅れている債権(滞留債権)に対して引当金が足りているかを確かめます。足りなければ、その分だけ資産(と利益)が実際より多く見えていることになります。
