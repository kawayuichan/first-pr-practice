# C26 連結①資本連結

## 要点3行 {#summary}

1. 親会社が他の会社の議決権の **過半数** を持つなど、その会社を支配しているとき、その会社は **子会社**。親会社と子会社をまとめて1つの会社のように見た **連結財務諸表** を作る。
2. 連結では、親会社と子会社の財務諸表を合算し、親会社の **子会社株式(投資)** と子会社の **純資産(資本)** を相殺する(資本連結)。
3. 親会社が持っていない分の子会社の純資産は **非支配株主持分**。子会社株式が親会社の持分を上回る額は **のれん**(下回るときは負ののれん発生益)。

## 仕訳パターン {#patterns}

連結の修正仕訳は、親会社・子会社の帳簿には記録しません。連結財務諸表を作るときだけ、合算した金額に対して行います。

### 100%を取得したとき {#full}

**例1** P社は、S社の株式の100%を ¥2,300,000 で取得し、支配した。支配獲得日のS社の純資産は、資本金 1,500,000、資本剰余金 300,000、利益剰余金 400,000。

- S社の純資産 = 1,500,000 + 300,000 + 400,000 = {{ 1,500,000 + 300,000 + 400,000 }}
- のれん = 2,300,000 − {{ 1,500,000 + 300,000 + 400,000 }} = {{ 2,300,000 - (1,500,000 + 300,000 + 400,000) }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 資本金 | 1,500,000 | 子会社株式 | 2,300,000 |
| 資本剰余金 | 300,000 | | |
| 利益剰余金 | 400,000 | | |
| のれん | {{ 2,300,000 - (1,500,000 + 300,000 + 400,000) }} | | |

### 一部を取得したとき(非支配株主持分) {#partial}

**例2** P社は、S社(純資産は例1と同じ)の株式の80%を ¥2,000,000 で取得し、支配した。

- 非支配株主持分 = {{ 1,500,000 + 300,000 + 400,000 }} × 20% = {{ (1,500,000 + 300,000 + 400,000) * 20 / 100 }}
- 親会社の持分 = {{ 1,500,000 + 300,000 + 400,000 }} × 80% = {{ (1,500,000 + 300,000 + 400,000) * 80 / 100 }}
- のれん = 2,000,000 − {{ (1,500,000 + 300,000 + 400,000) * 80 / 100 }} = {{ 2,000,000 - (1,500,000 + 300,000 + 400,000) * 80 / 100 }}

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 資本金 | 1,500,000 | 子会社株式 | 2,000,000 |
| 資本剰余金 | 300,000 | 非支配株主持分 | {{ (1,500,000 + 300,000 + 400,000) * 20 / 100 }} |
| 利益剰余金 | 400,000 | | |
| のれん | {{ 2,000,000 - (1,500,000 + 300,000 + 400,000) * 80 / 100 }} | | |

子会社の資本金などは、100%分をすべて消します。そのうち親会社が持っていない分を非支配株主持分にします。

### 負ののれん {#negative}

**例3** P社は、S社(純資産は例1と同じ)の株式の100%を ¥2,100,000 で取得した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 資本金 | 1,500,000 | 子会社株式 | 2,100,000 |
| 資本剰余金 | 300,000 | 負ののれん発生益 | {{ 1,500,000 + 300,000 + 400,000 - 2,100,000 }} |
| 利益剰余金 | 400,000 | | |

純資産より安く買えた差額 {{ 1,500,000 + 300,000 + 400,000 - 2,100,000 }} は、**負ののれん発生益**(特別利益)にします。

## T勘定・ボックス図 {#t-account}

### 子会社の純資産のボックス図 {#box}

例2です。子会社の純資産を、親会社の持分と非支配株主の持分に分けます。

| 区分 | 金額 |
|---|--:|
| 子会社の純資産(100%) | {{ 1,500,000 + 300,000 + 400,000 }} |
| 親会社の持分(80%) | {{ (1,500,000 + 300,000 + 400,000) * 80 / 100 }} |
| 非支配株主持分(20%) | {{ (1,500,000 + 300,000 + 400,000) * 20 / 100 }} |
| 子会社株式(取得原価) | 2,000,000 |
| のれん(取得原価 − 親会社の持分) | {{ 2,000,000 - (1,500,000 + 300,000 + 400,000) * 80 / 100 }} |

### 連結貸借対照表 {#cbs}

**例4** 例2の支配獲得日の連結貸借対照表。P社は諸資産 6,000,000・子会社株式 2,000,000・諸負債 3,000,000・資本金 4,000,000・資本剰余金 500,000・利益剰余金 500,000、S社は諸資産 3,000,000・諸負債 800,000(純資産は例1)。

| 項目 | 連結 | 計算 |
|---|--:|---|
| 諸資産 | {{ 6,000,000 + 3,000,000 }} | P + S |
| のれん | {{ 2,000,000 - (1,500,000 + 300,000 + 400,000) * 80 / 100 }} | 例2 |
| 諸負債 | {{ 3,000,000 + 800,000 }} | P + S |
| 資本金 | 4,000,000 | Pだけ |
| 資本剰余金 | 500,000 | Pだけ |
| 利益剰余金 | 500,000 | Pだけ |
| 非支配株主持分 | {{ (1,500,000 + 300,000 + 400,000) * 20 / 100 }} | 例2 |

子会社株式とS社の資本金・資本剰余金・利益剰余金は、相殺されて残りません。資産合計 {{ 6,000,000 + 3,000,000 + 2,000,000 - (1,500,000 + 300,000 + 400,000) * 80 / 100 }} と、負債・純資産合計 {{ 3,000,000 + 800,000 + 4,000,000 + 500,000 + 500,000 + (1,500,000 + 300,000 + 400,000) * 20 / 100 }} が一致します。

> [!覚える]
> - 子会社株式と、子会社の **資本金・資本剰余金・利益剰余金(100%分)** を相殺する
> - 非支配株主持分 = 子会社の純資産 × **非支配株主の持分比率**
> - のれん = 子会社株式 − 子会社の純資産 × **親会社の持分比率**
> - 連結の純資産(資本金など)は **親会社の分だけ** 残る

## 引っかけポイント {#traps}

1. 子会社の資本金などは、持分比率をかけずに全額(100%分)を消す。
2. のれんは、子会社株式から子会社の純資産の全額ではなく、親会社の持分(比率をかけた額)を引いて求める。
3. 非支配株主持分は、連結貸借対照表の純資産の部に表示する(負債ではない)。
4. 連結の修正仕訳は、親会社・子会社の帳簿には記録しない。

## 決算書ではここに出る {#fs}

上場会社の決算書の中心は連結財務諸表です。M&Aでは、買収価格と相手の純資産の差がのれんになります。のれんが大きいほど、純資産より高く買った(将来のもうけに期待した)ことを意味し、期待どおりにもうからないと、のれんの価値が下がる(減損)おそれがあります。

## 確認問題 {#check}

アプリの「問題を解く」で、C26の問題(8問)を解けます。ここでは3問だけ、すぐに答えを確認できます。

<details>
<summary>Q1. 子会社の純資産 ¥1,000,000、親会社の持分 60%。非支配株主持分は?</summary>

1,000,000 × 40% = ¥{{ 1,000,000 * 40 / 100 }}。

</details>

<details>
<summary>Q2. 子会社株式 ¥700,000、子会社の純資産 ¥1,000,000、持分 60%。のれんは?</summary>

700,000 − 1,000,000 × 60% = ¥{{ 700,000 - 1,000,000 * 60 / 100 }}。

</details>

<details>
<summary>Q3. 連結貸借対照表に残る資本金は、親会社・子会社のどちらの分?</summary>

親会社の分だけ(子会社の資本金は相殺して消す)。

</details>
