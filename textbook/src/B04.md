# B04 商品売買①三分法

## 要点3行 {#summary}

1. 三分法は、商品の売買を **仕入(費用)・売上(収益)・繰越商品(資産)** の3つの勘定で記録する。
2. 仕入れるときにかかった運賃などは **仕入に含める**。売るときに当社が払う送料は **発送費**。返品は、仕入・売上を取り消す(逆の仕訳)。
3. 商品有高帳で商品ごとの数量と原価を管理し(先入先出法・移動平均法)、決算では「期首商品 + 当期仕入 − 期末商品 = **売上原価**」を仕入勘定で計算する。

## 仕訳パターン {#patterns}

### 仕入と売上 {#buy-sell}

**例1** 商品 ¥100,000 を掛けで仕入れ、引取運賃 ¥3,000 を現金で払った。(運賃は仕入に含める)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕入 | {{ 100,000 + 3,000 }} | 買掛金 | 100,000 |
| | | 現金 | 3,000 |

**例2** 商品 ¥150,000 を掛けで売り上げた。当社負担の送料 ¥2,000 は現金で払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売掛金 | 150,000 | 売上 | 150,000 |
| 発送費 | 2,000 | 現金 | 2,000 |

**例3** 商品 ¥150,000 を売り上げ、送料 ¥2,000 を **加えた合計額** を掛けとした。送料は配送業者に現金で払った。(送料も受け取るので、送料込みの額が売上)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売掛金 | {{ 150,000 + 2,000 }} | 売上 | {{ 150,000 + 2,000 }} |
| 発送費 | 2,000 | 現金 | 2,000 |

### 返品 {#returns}

返品は、元の仕訳の **逆** を書いて取り消します。

**例4** 掛けで仕入れた商品のうち ¥10,000 を、品違いのため返品した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 買掛金 | 10,000 | 仕入 | 10,000 |

**例5** 掛けで売り上げた商品のうち ¥8,000 が、品違いのため返品された。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売上 | 8,000 | 売掛金 | 8,000 |

### 決算: 売上原価の計算 {#cogs}

三分法では、期中は仕入れた額を仕入勘定に記録するだけです。決算で、売れ残り(期末商品)を差し引き、前期からの在庫(期首商品)を足して、**売れた商品の原価(売上原価)** にします。

**例6** 期首商品 ¥30,000、当期の仕入 ¥400,000、期末商品 ¥50,000。売上原価を仕入勘定で計算する。

① 期首商品を仕入勘定へ(繰越商品 → 仕入)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕入 | 30,000 | 繰越商品 | 30,000 |

② 期末商品を繰越商品勘定へ(仕入 → 繰越商品)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 繰越商品 | 50,000 | 仕入 | 50,000 |

覚え方は「**しーくりくりしー**」(仕入・繰越商品、繰越商品・仕入)。この結果、仕入勘定の残高が売上原価 {{ 30,000 + 400,000 - 50,000 }} になります。

## T勘定・ボックス図 {#t-account}

### 売上原価のボックス図 {#cogs-box}

| 借方 | 貸方 |
|---|---|
| 期首商品 30,000 | 売上原価 {{ 30,000 + 400,000 - 50,000 }} |
| 当期仕入 400,000 | 期末商品 50,000 |

- 左の合計(期首 + 仕入 = {{ 30,000 + 400,000 }})= 右の合計(売上原価 + 期末)
- 売上 − 売上原価 = **売上総利益**(いわゆる粗利)

**仕入**(決算整理のあと)

| 借方 | 貸方 |
|---|---|
| 当期の仕入 400,000 | 繰越商品 50,000 |
| 繰越商品 30,000 | |

残高 = {{ 400,000 + 30,000 - 50,000 }} = 売上原価

### 商品有高帳 {#inventory-book}

商品ごとに、受入・払出・残高を **原価** で記録する帳簿です。売上の行も、売った値段ではなく **原価(仕入単価)** で書きます。

**先入先出法**: 先に仕入れたものから先に払い出す。

| 日付・摘要 | 受入数量 | 受入単価 | 受入金額 | 払出数量 | 払出単価 | 払出金額 | 残高数量 | 残高単価 | 残高金額 |
|---|--:|--:|--:|--:|--:|--:|--:|--:|--:|
| 1日 前月繰越 | 10 | 200 | {{ 10 * 200 }} | | | | 10 | 200 | {{ 10 * 200 }} |
| 5日 仕入 | 20 | 230 | {{ 20 * 230 }} | | | | 10 | 200 | {{ 10 * 200 }} |
| | | | | | | | 20 | 230 | {{ 20 * 230 }} |
| 12日 売上 | | | | 10 | 200 | {{ 10 * 200 }} | | | |
| | | | | 5 | 230 | {{ 5 * 230 }} | 15 | 230 | {{ 15 * 230 }} |

12日は15個を払い出しますが、先に仕入れた @200 の10個を先に出し、足りない5個を @230 から出します(2行に分けて書く)。

**移動平均法**: 仕入れるたびに「残高の金額 ÷ 残高の数量」で平均単価を計算し直す。

| 日付・摘要 | 受入数量 | 受入単価 | 受入金額 | 払出数量 | 払出単価 | 払出金額 | 残高数量 | 残高単価 | 残高金額 |
|---|--:|--:|--:|--:|--:|--:|--:|--:|--:|
| 1日 前月繰越 | 10 | 200 | {{ 10 * 200 }} | | | | 10 | 200 | {{ 10 * 200 }} |
| 5日 仕入 | 20 | 230 | {{ 20 * 230 }} | | | | {{ 10 + 20 }} | {{ (10 * 200 + 20 * 230) / (10 + 20) }} | {{ 10 * 200 + 20 * 230 }} |
| 12日 売上 | | | | 15 | {{ (10 * 200 + 20 * 230) / (10 + 20) }} | {{ 15 * (10 * 200 + 20 * 230) / (10 + 20) }} | 15 | {{ (10 * 200 + 20 * 230) / (10 + 20) }} | {{ 15 * (10 * 200 + 20 * 230) / (10 + 20) }} |

5日の平均単価 = 残高の金額 {{ 10 * 200 + 20 * 230 }} ÷ 残高の数量 {{ 10 + 20 }} = {{ (10 * 200 + 20 * 230) / (10 + 20) }}

## 引っかけポイント {#traps}

1. 仕入れるときの運賃(引取運賃)は **仕入に含める**。売るときに当社が払う送料は **発送費(費用)**。
2. 送料を加えた額を請求したときは、**送料込みの額を売上** にし、払った送料は発送費にする。
3. 仕入の返品は「買掛金 / 仕入」、売上の返品は「売上 / 売掛金」。現金は動いていない。
4. 売上原価の決算整理は「しーくりくりしー」。期末商品は **仕入から差し引く**(繰越商品 / 仕入)。
5. 商品有高帳は **原価** で書く。売上の行の単価も、売った値段ではなく仕入単価。
6. 移動平均法の単価は、単価どうしの平均ではなく **金額の合計 ÷ 数量の合計**。

## 決算書ではここに出る {#fs}

損益計算書の「売上高」「売上原価」と、その差の「売上総利益(粗利)」。貸借対照表の「商品」(期末商品)。M&Aでは、粗利率(売上総利益 ÷ 売上高)が安定しているか、在庫が増えすぎていないかを確認します。
