# C01 商品売買(2級)

## 要点3行 {#summary}

1. 2級の商品売買では、三分法(B04)に **仕入割戻**(仕入を減らす)、**総平均法**(期間の最後にまとめて平均単価を出す)、**月次による処理**、補助簿の集計が加わる。
2. 決算で、実際の数量が帳簿より少なければ **棚卸減耗損**(原価 × 減った数量)、時価が原価より下がっていれば **商品評価損**((原価 − 時価)× 実地数量)を計上し、繰越商品を減らす。
3. 期末商品の図で、帳簿棚卸高から減耗損と評価損を引いた残り(時価 × 実地数量)が **貸借対照表の商品**。指示があれば減耗損・評価損を **売上原価(仕入)に含める**。

## 仕訳パターン {#patterns}

### 仕入割戻 {#rebate}

**例1** 仕入先から、一定期間にたくさん仕入れたことによる割戻し ¥8,000 を受け、買掛金と相殺した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 買掛金 | 8,000 | 仕入割戻 | 8,000 |

- 割戻しは、まとめて仕入れたお礼に代金を減らしてもらうこと。返品と違い、**商品は戻らない**
- 仕入から差し引く。公式の勘定科目表の標準は **仕入割戻**(「仕入」でもよい)
- 売上割戻(売った側)は、収益認識(C14)で学ぶ

### 補助簿の集計 {#subledgers}

仕入帳・売上帳の合計から、次の金額を求めます。

| 求める金額 | 計算 |
|---|---|
| 純仕入高 | 総仕入高 − 仕入戻し(返品) − 仕入割戻 |
| 純売上高 | 総売上高 − 売上戻り(返品) |
| 売上原価 | 期首商品 + 純仕入高 − 期末商品 |
| 売上総利益 | 純売上高 − 売上原価 |

**例2** 総仕入高 ¥500,000、仕入戻し ¥12,000、仕入割戻 ¥8,000 → 純仕入高 ¥{{ 500,000 - 12,000 - 8,000 }}

### 総平均法 {#average}

**例3** 1か月の商品の動きは次のとおり。払出単価は総平均法で計算する。

| 日付・摘要 | 数量 | 単価 | 金額 |
|---|--:|--:|--:|
| 1日 前月繰越 | 10個 | 500 | 5,000 |
| 10日 仕入 | 30個 | 620 | {{ 30 * 620 }} |
| 20日 仕入 | 20個 | 650 | {{ 20 * 650 }} |
| 合計 | 60個 | | {{ 5,000 + 30 * 620 + 20 * 650 }} |

- 平均単価 = 金額の合計 ÷ 数量の合計 = {{ 5,000 + 30 * 620 + 20 * 650 }} ÷ 60 = {{ (5,000 + 30 * 620 + 20 * 650) / 60 }}
- 45個を売ったら、売上原価 = {{ (5,000 + 30 * 620 + 20 * 650) / 60 }} × 45 = {{ (5,000 + 30 * 620 + 20 * 650) / 60 * 45 }}、月末の在庫 = {{ (5,000 + 30 * 620 + 20 * 650) / 60 }} × 15 = {{ (5,000 + 30 * 620 + 20 * 650) / 60 * 15 }}
- **移動平均法**(B04)は仕入のたびに単価を出し直す。**総平均法** は期間の最後に一度だけ出す

### 月次による処理 {#monthly}

毎月末に、その月の売上原価を計算する処理です。月初の在庫を仕入に足し、月末の在庫を仕入から引く仕訳(しーくりくりしー)を、決算のときだけでなく **毎月末** に行います。

**例4** 4月の月初商品棚卸高 ¥50,000、4月末の商品棚卸高 ¥62,000。4月末に売上原価を計算する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕入 | 50,000 | 繰越商品 | 50,000 |
| 繰越商品 | 62,000 | 仕入 | 62,000 |

(区分表には「月次による処理」と名前だけが書かれ、くわしい説明がありません。ここでは一般的な意味で説明しています。)

### 棚卸減耗と評価替 {#inventory}

**例5** 決算で、商品の帳簿数量は100個、実地数量は95個だった。原価は @800、時価(正味売却価額)は @750。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 棚卸減耗損 | {{ 800 * (100 - 95) }} | 繰越商品 | {{ 800 * (100 - 95) + (800 - 750) * 95 }} |
| 商品評価損 | {{ (800 - 750) * 95 }} | | |

- 棚卸減耗損 = **原価** × 減った数量 = 800 × 5 = {{ 800 * (100 - 95) }}
- 商品評価損 = (原価 − 時価)× **実地数量** = 50 × 95 = {{ (800 - 750) * 95 }}
- 時価が原価より **高い** ときは評価替をしない(評価益は計上しない)
- 時価(正味売却価額)= 売れると見込まれる値段 − 売るためにかかる費用

**例6(売上原価に含める)** 例5の棚卸減耗損と商品評価損を、売上原価に算入する(売上原価は仕入勘定で計算)。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕入 | {{ 800 * (100 - 95) + (800 - 750) * 95 }} | 棚卸減耗損 | {{ 800 * (100 - 95) }} |
| | | 商品評価損 | {{ (800 - 750) * 95 }} |

## T勘定・ボックス図 {#t-account}

### 期末商品の図 {#box}

例5を図にしたものです。横が数量(実地 95個 + 減った 5個)、縦が単価(下の段が時価 750、上の段が原価 800 との差 50)で、面積が金額になります。

| 単価 | 実地 95個 | 減った 5個 |
|---|---|---|
| 差 50 | 商品評価損 {{ (800 - 750) * 95 }} | 棚卸減耗損 {{ 800 * (100 - 95) }} |
| 時価 750 | 貸借対照表の商品 {{ 750 * 95 }} | (上の減耗損に含む) |

- 全体(原価 × 帳簿数量)= 帳簿棚卸高 {{ 800 * 100 }}
- 帳簿棚卸高 − 棚卸減耗損 − 商品評価損 = {{ 800 * 100 - 800 * (100 - 95) - (800 - 750) * 95 }} = 時価 × 実地数量({{ 750 * 95 }})
- 減った5個は、もう手元にないので **原価のまま** 全部が減耗損になる

> [!覚える]
> - 仕入割戻は **仕入を減らす**(公式表の標準は仕入割戻)
> - 総平均法は **期間の最後に一度だけ** 平均単価を出す
> - 棚卸減耗損 = **原価 × 減った数量**
> - 商品評価損 = **(原価 − 時価)× 実地数量**
> - 貸借対照表の商品 = **時価 × 実地数量**

## 引っかけポイント {#traps}

1. 仕入割戻は返品ではない。商品は戻らず、**仕入を減らす** だけ。
2. 棚卸減耗損は **原価** で計算する。時価を使わない。
3. 商品評価損は **実地数量** にかける。帳簿数量ではない(減った分は減耗損で処理済み)。
4. 時価が原価より高いときは、評価替をしない。
5. 「売上原価に算入する」指示があれば「仕入 / 棚卸減耗損・商品評価損」。指示がなければ、そのまま費用として残す。
6. 総平均法は、期間の途中で売った分も、期間の最後に出した平均単価で計算する。

## 決算書ではここに出る {#fs}

貸借対照表の「商品」は、減耗損と評価損を引いたあとの金額(時価 × 実地数量)です。損益計算書では、商品評価損は売上原価に含めることが多く、棚卸減耗損は問題の指示で売上原価か販売費及び一般管理費に表示します(表示のくわしい区分は C22)。M&Aでは在庫をよく確かめます。売れ残った古い在庫に評価損を計上していないと、資産と利益が実際より多く見えるからです。

## 確認問題 {#check}

アプリの「問題を解く」で、C01の問題(12問)を解けます。ここでは3問だけ、すぐに答えを確認できます。

<details>
<summary>Q1. 帳簿数量 50個、実地数量 48個、原価 @1,000。棚卸減耗損は?</summary>

¥{{ 1,000 * (50 - 48) }}(原価 × 減った数量)。

</details>

<details>
<summary>Q2. Q1 で時価が @900 のとき、商品評価損は?</summary>

¥{{ (1,000 - 900) * 48 }}((原価 − 時価)× 実地数量)。

</details>

<details>
<summary>Q3. 仕入割戻 ¥5,000 を受け、買掛金と相殺した。仕訳は?</summary>

買掛金 5,000 / 仕入割戻 5,000(仕入 でもよい)。

</details>
