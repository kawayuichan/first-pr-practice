# K02 材料費

## 要点3行 {#summary}

1. 材料の購入原価 = 購入代価 + **材料副費**(引取運賃・保管費など)。材料副費を **予定配賦** したら、実際との差は **材料副費差異**。
2. 消費した材料の単価は、**先入先出法** か **平均法** で計算する。**予定価格** で計算したら、実際との差は **材料消費価格差異**。
3. 直接材料費は **仕掛品**、間接材料費は **製造間接費** へ。月末に帳簿より実際の数量が少なければ、**棚卸減耗費** として製造間接費にする。

## 仕訳パターン {#patterns}

### 材料を買ったとき {#purchase}

**例1** 材料 ¥300,000 を掛けで買い、引取運賃 ¥6,000 を現金で払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 材料 | {{ 300,000 + 6,000 }} | 買掛金 | 300,000 |
| | | 現金 | 6,000 |

### 材料副費の予定配賦 {#overhead}

**例2** 材料 ¥500,000 を掛けで買った。材料副費は、購入代価の4%を予定配賦する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 材料 | {{ 500,000 + 500,000 * 4 / 100 }} | 買掛金 | 500,000 |
| | | 材料副費 | {{ 500,000 * 4 / 100 }} |

**例3** 月末、実際の材料副費は ¥19,000 だった(支払時に材料副費勘定の借方に記録済み)。予定配賦額との差を振り替える。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 材料副費 | {{ 500,000 * 4 / 100 - 19,000 }} | 材料副費差異 | {{ 500,000 * 4 / 100 - 19,000 }} |

予定({{ 500,000 * 4 / 100 }})より実際(19,000)が少ないので **有利差異**(貸方差異)。

### 消費単価(先入先出法・平均法) {#unit-cost}

**例4** 月初に材料 100kg(@¥200)があり、月中に 300kg(@¥220)を買った。当月の消費は 250kg。

| 方法 | 消費額の計算 | 消費額 |
|---|---|--:|
| 先入先出法 | 100kg × 200 + 150kg × 220 | {{ 100 * 200 + 150 * 220 }} |
| 平均法(総平均) | 平均単価 {{ (100 * 200 + 300 * 220) / 400 }} × 250kg | {{ (100 * 200 + 300 * 220) / 400 * 250 }} |

### 予定価格と材料消費価格差異 {#planned}

**例5** 例4の材料を、予定価格 @¥210 で消費の記録をした。消費 250kg のうち 200kg は直接材料、50kg は間接材料。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仕掛品 | {{ 210 * 200 }} | 材料 | {{ 210 * 250 }} |
| 製造間接費 | {{ 210 * 50 }} | | |

**例6** 月末、実際の消費額(先入先出法 {{ 100 * 200 + 150 * 220 }})との差を振り替える。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 材料消費価格差異 | {{ 100 * 200 + 150 * 220 - 210 * 250 }} | 材料 | {{ 100 * 200 + 150 * 220 - 210 * 250 }} |

予定より実際の消費額が多いので **不利差異**(借方差異)。

### 棚卸減耗 {#shrinkage}

**例7** 月末の帳簿の数量は 150kg、実際の数量は 147kg だった(単価 @¥220)。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 製造間接費 | {{ (150 - 147) * 220 }} | 材料 | {{ (150 - 147) * 220 }} |

ふつうに起きる程度の減耗は、間接経費として **製造間接費** にします。

## T勘定・ボックス図 {#t-account}

### 材料のボックス図(先入先出法) {#box}

| 借方 | 貸方 |
|---|---|
| 月初 100kg @200 = {{ 100 * 200 }} | 消費 100kg @200 = {{ 100 * 200 }} |
| 購入 300kg @220 = {{ 300 * 220 }} | 消費 150kg @220 = {{ 150 * 220 }} |
| | 月末 150kg @220 = {{ 150 * 220 }} |

### 差異の向き {#variance}

| 差異 | 予定 > 実際 | 予定 < 実際 |
|---|---|---|
| 材料副費差異 | 有利(貸方) | 不利(借方) |
| 材料消費価格差異 | 有利(貸方) | 不利(借方) |

> [!覚える]
> - 購入原価 = 購入代価 + **材料副費**
> - 先入先出法は **古いものから** 消費、平均法は **平均単価** で消費
> - 予定と実際の差は **材料副費差異**・**材料消費価格差異**
> - 実際のほうが多い(コストが高い)→ **不利差異(借方)**
> - 間接材料費・棚卸減耗費は **製造間接費**

## 引っかけポイント {#traps}

1. 引取運賃などの材料副費は、材料の取得原価に含める。
2. 先入先出法では、月初の材料から先に消費したと考える。
3. 予定価格で消費を記録したら、実際との差を材料消費価格差異に振り替える。
4. 差異の向き: 実際の原価のほうが大きければ不利(借方)差異。
5. 棚卸減耗費は、仕掛品ではなく製造間接費。

## 決算書ではここに出る {#fs}

材料は、貸借対照表の棚卸資産です。材料消費価格差異などの原価差異は、会計年度末に売上原価に加減します(売上原価加減法。K05)。M&Aでは、材料の仕入価格の変動(差異の大きさ)と、材料の在庫が多すぎないかを確かめます。
