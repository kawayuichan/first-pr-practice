# C29 連結④連結精算表

## 要点3行 {#summary}

1. **連結精算表** は、親会社と子会社の個別財務諸表を並べ、**修正・消去**(C26〜C28の連結修正仕訳)を加減して、連結財務諸表の金額を出す表。
2. 表は、上から **貸借対照表・損益計算書・株主資本等変動計算書** の3つに分かれる。損益計算書の当期純利益が、株主資本等変動計算書を通って、貸借対照表の利益剰余金・非支配株主持分につながる。
3. 1行の計算は、借方の項目(資産・費用)は「個別の合計 + 修正借方 − 修正貸方」、貸方の項目(負債・純資産・収益)は「個別の合計 − 修正借方 + 修正貸方」。

## 仕訳パターン {#patterns}

この章の例は、C27と同じ会社の支配獲得後1年目です。P社はS社の80%を持ち、のれん 240,000 を10年で償却します。S社の当期純利益は 300,000、配当は 100,000 です。さらに、成果連結(C28)として次の取引があります。

- P社からS社への売上高 ¥600,000(S社の期末商品のうち ¥100,000 がP社から仕入れたもの。P社の売上総利益率 30%)
- P社の売掛金のうちS社に対するもの ¥80,000(P社は 2% の貸倒引当金を設定)

### 当期の修正・消去(まとめ) {#entries}

**例1** 開始仕訳(C27の例1)以外の、当期の修正・消去の仕訳。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| のれん償却 | {{ 240,000 / 10 }} | のれん | {{ 240,000 / 10 }} |
| 非支配株主に帰属する当期純利益 | {{ 300,000 * 20 / 100 }} | 非支配株主持分当期変動額 | {{ 300,000 * 20 / 100 }} |
| 受取配当金 | {{ 100,000 * 80 / 100 }} | 剰余金の配当 | 100,000 |
| 非支配株主持分当期変動額 | {{ 100,000 * 20 / 100 }} | | |
| 売上高 | 600,000 | 売上原価 | 600,000 |
| 売上原価 | {{ 100,000 * 30 / 100 }} | 商品 | {{ 100,000 * 30 / 100 }} |
| 買掛金 | 80,000 | 売掛金 | 80,000 |
| 貸倒引当金 | {{ 80,000 * 2 / 100 }} | 貸倒引当金繰入 | {{ 80,000 * 2 / 100 }} |

### 連結精算表の1行 {#row}

**例2** P社の売掛金 ¥700,000、S社の売掛金 ¥400,000、修正・消去の貸方 ¥80,000(例1)。

- 連結の売掛金 = 700,000 + 400,000 − 80,000 = {{ 700,000 + 400,000 - 80,000 }}(資産なので、修正の貸方を引く)

**例3** P社の売上原価 ¥3,000,000、S社の売上原価 ¥1,500,000。修正・消去は、借方 {{ 100,000 * 30 / 100 }}(未実現利益)、貸方 600,000(グループ内の売上)。

- 連結の売上原価 = 3,000,000 + 1,500,000 + {{ 100,000 * 30 / 100 }} − 600,000 = {{ 3,000,000 + 1,500,000 + 100,000 * 30 / 100 - 600,000 }}(費用なので、借方を足し、貸方を引く)

## T勘定・ボックス図 {#t-account}

### 連結精算表の形 {#form}

本当の表は、横に「個別財務諸表(P社・S社)」「修正・消去(借方・貸方)」「連結財務諸表」の欄が並びます。縦は次の順です。

| 区分 | 主な行 |
|---|---|
| 貸借対照表 | 売掛金・商品・のれん・子会社株式・買掛金・資本金・利益剰余金・非支配株主持分 |
| 損益計算書 | 売上高・売上原価・のれん償却・受取配当金・当期純利益・非支配株主に帰属する当期純利益・親会社株主に帰属する当期純利益 |
| 株主資本等変動計算書 | 資本金当期首残高・利益剰余金当期首残高・剰余金の配当・非支配株主持分当期首残高・当期変動額・当期末残高 |

### 利益のつながり {#flow}

| 順番 | どこからどこへ |
|---|---|
| 1 | 損益計算書の **親会社株主に帰属する当期純利益** を、株主資本等変動計算書の利益剰余金の行へ |
| 2 | 株主資本等変動計算書の **利益剰余金当期末残高** を、貸借対照表の利益剰余金へ |
| 3 | **非支配株主持分当期末残高**(当期首残高 + 当期変動額)を、貸借対照表の非支配株主持分へ |

> [!覚える]
> - 連結 = P社 + S社 ± **修正・消去**
> - 資産・費用は **借方を足し、貸方を引く**。負債・純資産・収益は逆
> - 子会社株式・グループ内の債権債務・グループ内の売上は、連結では **残らない**
> - 損益計算書 → 株主資本等変動計算書 → 貸借対照表 の順に **利益がつながる**

## 引っかけポイント {#traps}

1. 売上原価の行には、グループ内の売上の消去(貸方)と未実現利益(借方)の両方が入る。
2. 貸倒引当金は貸方の項目なので、修正の借方(消去)は引く。
3. 非支配株主持分の期末は、当期首残高に、非支配株主に帰属する当期純利益を足し、非支配株主への配当を引いた額。
4. 連結の当期純利益から非支配株主の分を引いたものが、親会社株主に帰属する当期純利益。

## 決算書ではここに出る {#fs}

連結精算表の右端の欄が、連結貸借対照表・連結損益計算書・連結株主資本等変動計算書の金額です。M&Aでは、買収したあとの連結財務諸表で、のれん償却や未実現利益の消去によって、各社の利益の合計よりも連結の利益が小さくなることを理解しておきます。

## 確認問題 {#check}

アプリの「問題を解く」で、C29の問題(8問)を解けます。ここでは3問だけ、すぐに答えを確認できます。

<details>
<summary>Q1. P社の買掛金 ¥300,000、S社の買掛金 ¥200,000、修正・消去の借方 ¥50,000。連結の買掛金は?</summary>

負債なので借方を引く。300,000 + 200,000 − 50,000 = ¥{{ 300,000 + 200,000 - 50,000 }}。

</details>

<details>
<summary>Q2. 連結精算表で、子会社株式の連結の欄はいくら?</summary>

0(子会社の資本と相殺して消える)。

</details>

<details>
<summary>Q3. 連結の当期純利益 ¥900,000、非支配株主に帰属する当期純利益 ¥60,000。親会社株主に帰属する当期純利益は?</summary>

900,000 − 60,000 = ¥{{ 900,000 - 60,000 }}。

</details>
