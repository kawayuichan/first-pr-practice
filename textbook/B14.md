# B14 決算②締切と財務諸表

## 要点3行 {#summary}

1. 決算整理のあと、収益・費用の残高を **損益** 勘定に集める(収益は損益の貸方へ、費用は損益の借方へ)。損益勘定の差額が当期純利益。
2. 当期純利益は「損益 / 繰越利益剰余金」で繰越利益剰余金に振り替える(純損失なら逆)。資産・負債・純資産の勘定は、**英米式** では仕訳をせずに「次期繰越」と書いて締め切る。
3. 損益計算書・貸借対照表(勘定式)では、繰越商品は **商品**、売上原価を計算した仕入は **売上原価**、売上は **売上高** のように、表示の名前に変えて書く。

## 仕訳パターン {#patterns}

例はすべて同じ会社の決算です(決算整理は終わっている)。

### 収益・費用を損益勘定へ {#to-pl}

**例1(収益)** 売上 ¥900,000 と受取手数料 ¥20,000 を損益勘定に振り替えた。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 売上 | 900,000 | 損益 | 920,000 |
| 受取手数料 | 20,000 | | |

**例2(費用)** 仕入(売上原価の計算後) ¥610,000、給料 ¥232,000、減価償却費 ¥40,000 を損益勘定に振り替えた。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 損益 | 882,000 | 仕入 | 610,000 |
| | | 給料 | 232,000 |
| | | 減価償却費 | 40,000 |

- 収益(貸方の残高)は借方に書いて消し、損益の貸方へ。費用(借方の残高)は貸方に書いて消し、損益の借方へ
- 振り替えると、収益・費用の勘定の残高はゼロになる

### 当期純利益を繰越利益剰余金へ {#to-retained}

**例3** 損益勘定の貸方合計は ¥920,000、借方合計は ¥882,000 なので、差額を繰越利益剰余金に振り替えた。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 損益 | 38,000 | 繰越利益剰余金 | 38,000 |

当期純損失(借方合計のほうが多い)のときは、「繰越利益剰余金 / 損益」と逆になり、繰越利益剰余金が減ります。

### 帳簿の締切(英米式) {#closing}

- **収益・費用の勘定**: 損益勘定への振替で残高がゼロになるので、そのまま締め切る
- **資産・負債・純資産の勘定**: 決算日に、残高の反対側に「次期繰越」と書いて貸借を一致させて締め切り、翌期の最初の日に、残高の側に「前期繰越」と書く(開始記入)。英米式では、この記入は **仕訳をしない**

**例4(売掛金勘定の締切)**

| 日付・摘要 | 借方 | 貸方 |
|---|--:|--:|
| 4月1日 前期繰越 | 250,000 | |
| 期中 売上 | 700,000 | |
| 期中 普通預金 | | 650,000 |
| 3月31日 次期繰越 | | 300,000 |
| 合計 | 950,000 | 950,000 |
| 4月1日 前期繰越 | 300,000 | |

### 繰越試算表(紹介) {#carry-tb}

英米式で締め切ったあと、資産・負債・純資産の勘定の「次期繰越」の金額を集めた表を **繰越試算表** といいます。次期繰越の記入に誤りがないかを、貸借の一致で確かめるために作ります。

> - 収益 → 損益の **貸方**、費用 → 損益の **借方** へ振り替える

> - 英米式: 資産・負債・純資産の次期繰越・前期繰越は **仕訳しない**
> - 表示の名前: 売上 → **売上高**、仕入 → **売上原価**、繰越商品 → **商品**
> - 貸借対照表の繰越利益剰余金は **当期純利益を足したあと** の金額

## 引っかけポイント {#traps}

1. 収益は損益の **貸方** へ、費用は損益の **借方** へ。振替の仕訳は、元の残高と反対側に書いて消す。
2. 損益勘定の貸方(収益)が多ければ当期純利益 →「損益 / 繰越利益剰余金」。借方が多ければ純損失で逆。
3. 英米式では、資産・負債・純資産の次期繰越・前期繰越は **仕訳しない**(勘定に直接書く)。
4. 決算書では表示の名前に変える。繰越商品 → 商品、仕入 → 売上原価、売上 → 売上高。
5. 貸借対照表の繰越利益剰余金は、当期純利益を **足したあと** の金額(当期純利益の行は別にない)。

## 決算書ではここに出る {#fs}

この論点がそのまま決算書です。損益計算書は「1年間でいくら稼いだか」、貸借対照表は「期末に何を持ち、そのお金をどこから集めたか」を表します。2級では、損益計算書を上から順に「売上高 → 売上総利益 → 営業利益 → 経常利益 → 当期純利益」と段階的に表示する **報告式** を学びます(C22)。M&Aで決算書を読むときも、この段階利益が出発点になります。
