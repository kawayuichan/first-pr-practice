# C17 税金(2級)

## 要点3行 {#summary}

1. 法人税等は、会計の利益(税引前当期純利益)ではなく **課税所得** に税率をかけて計算する。課税所得 = 税引前当期純利益 + **損金不算入**(加算)− **益金不算入**(減算)。
2. 前の年度の法人税等を、あとで追加で払うことになったら **追徴法人税等**、返してもらえることになったら **還付法人税等**。
3. 中間納付額が年間の税額より多ければ、差額は **未収還付法人税等**(資産)。消費税で仮払消費税が仮受消費税より多ければ、差額は **未収還付消費税**(資産)。

## 仕訳パターン {#patterns}

法人税等の中間納付と決算の基本(仮払法人税等・未払法人税等)は3級(B11)と同じです。ここでは2級で加わる内容を学びます。

### 課税所得の計算 {#taxable-income}

会計で費用にしても、税法では費用(損金)と認められないものがあります(例: 税法の限度を超えた減価償却費、交際費の一部、税法の基準を超えた貸倒引当金の繰入額)。

**例1** 税引前当期純利益は ¥1,000,000。減価償却費のうち ¥50,000 と、貸倒引当金の繰入額のうち ¥30,000 は、税法では損金と認められない。法人税等の税率は30%。

- 課税所得 = 1,000,000 + 50,000 + 30,000 = 1,080,000
- 法人税等 = 1,080,000 × 30% = 324,000

| 区分 | 意味 | 課税所得の計算 |
|---|---|---|
| 損金不算入 | 会計では費用、税法では費用にならない | 加算する |
| 益金不算入 | 会計では収益、税法では収益にならない | 減算する |

**例2** 決算。例1の法人税等を計上する。中間納付額 ¥150,000 は仮払法人税等で処理している。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 法人税、住民税及び事業税 | 324,000 | 仮払法人税等 | 150,000 |
| | | 未払法人税等 | 174,000 |

### 中間納付が多すぎたとき {#refund-year-end}

**例3** 決算で、法人税等の年間の額は ¥200,000 と計算された。中間納付額 ¥260,000 を仮払法人税等で処理している。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 法人税、住民税及び事業税 | 200,000 | 仮払法人税等 | 260,000 |
| 未収還付法人税等 | 60,000 | | |

払いすぎた分は、あとで返してもらえるので **未収還付法人税等**(資産)。

### 追徴と還付(前の年度の分) {#additional}

**例4** 税務調査の結果、前の年度の法人税等 ¥80,000 を追加で納めることになった(まだ納めていない)。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 追徴法人税等 | 80,000 | 未払法人税等 | 80,000 |

**例5** 前の年度の法人税等のうち ¥40,000 が還付されることになった。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 未収還付法人税等 | 40,000 | 還付法人税等 | 40,000 |

- 当期の分(法人税、住民税及び事業税)と分けて、**追徴法人税等**(費用)・**還付法人税等**(収益)にする
- 還付金が入金されたら「普通預金 / 未収還付法人税等」

### 消費税の還付 {#consumption-refund}

**例6** 決算で、仮払消費税 ¥90,000 と仮受消費税 ¥70,000 を相殺する(設備を多く買った年)。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 仮受消費税 | 70,000 | 仮払消費税 | 90,000 |
| 未収還付消費税 | 20,000 | | |

ふつうは「仮受消費税 > 仮払消費税」で差額が未払消費税(B11)ですが、逆なら返してもらえるので **未収還付消費税**(資産)です。

## T勘定・ボックス図 {#t-account}

### 課税所得のボックス図 {#box}

例1の課税所得です。

| 項目 | 金額 |
|---|--:|
| 税引前当期純利益 | 1,000,000 |
| 加算: 減価償却費の損金不算入 | 50,000 |
| 加算: 貸倒引当金繰入の損金不算入 | 30,000 |
| 課税所得 | 1,080,000 |
| 法人税等(30%) | 324,000 |

### 税金の科目のまとめ {#accounts}

| 場面 | 科目 |
|---|---|
| 当期の法人税等 | 法人税、住民税及び事業税 |
| 前の年度の分を追加で払う | 追徴法人税等 |
| 前の年度の分が返ってくる | 還付法人税等 |
| 中間納付の払いすぎ・還付の未収 | 未収還付法人税等 |
| 消費税の払いすぎ | 未収還付消費税 |

> [!覚える]
> - 課税所得 = 税引前当期純利益 + **損金不算入** − **益金不算入**
> - 法人税等 = **課税所得 × 税率**(会計の利益 × 税率ではない)
> - 中間納付の払いすぎは **未収還付法人税等**
> - 前の年度の分は **追徴法人税等**・**還付法人税等**(当期の分と分ける)
> - 仮払消費税 > 仮受消費税 なら差額は **未収還付消費税**

## 引っかけポイント {#traps}

1. 法人税等を、税引前当期純利益に税率をかけて計算しない。損金不算入を加えた課税所得にかける。
2. 損金不算入は加算、益金不算入は減算。向きを逆にしない。
3. 前の年度の追徴・還付を、法人税、住民税及び事業税に入れない。
4. 中間納付が多すぎたら、未払法人税等ではなく未収還付法人税等。
5. 仮払消費税のほうが多いときの差額は、未払消費税ではなく未収還付消費税。

## 決算書ではここに出る {#fs}

損益計算書では、税引前当期純利益から「法人税、住民税及び事業税」を引き、追徴法人税等を加え(還付法人税等は差し引き)、当期純利益を出します。未収還付法人税等・未収還付消費税は流動資産です。M&Aでは、税務調査で追徴されそうな点(税務リスク)がないか、過去の申告を確かめます。
