# K11 直接原価計算

## 要点3行 {#summary}

1. **直接原価計算** は、原価を **変動費** と **固定費** に分けて、売上高 − 変動費 = **貢献利益**、貢献利益 − 固定費 = 営業利益 と計算する。
2. 固定製造原価は、作った量に関係なく全額をその期の費用にする。全部原価計算との営業利益の差は、在庫に含まれる固定製造原価の差で、**固定費調整** で全部原価計算の利益に直す。
3. 原価を変動費と固定費に分ける方法は、勘定科目ごとに判断する **費目別精査法** と、最高と最低の操業度の2点から計算する **高低点法**。

## 仕訳パターン {#patterns}

直接原価計算は、利益の計画や判断に使う計算で、決算の仕訳はありません。ここでは損益計算書の形を覚えます。

### 直接原価計算の損益計算書 {#direct-pl}

**例1** 販売単価 ¥1,000。変動製造原価 1個 ¥400、固定製造原価 ¥300,000、変動販売費 1個 ¥50、固定販売費及び一般管理費 ¥100,000。当期は 1,000個を作り、800個を売った(期首の在庫はない)。

| 項目 | 計算 | 金額 |
|---|---|--:|
| 売上高 | 800 × 1,000 | 800,000 |
| 変動売上原価 | 800 × 400 | 320,000 |
| 変動製造マージン | | 480,000 |
| 変動販売費 | 800 × 50 | 40,000 |
| 貢献利益 | | 440,000 |
| 固定製造原価 | 全額 | 300,000 |
| 固定販売費及び一般管理費 | | 100,000 |
| 営業利益 | | 40,000 |

変動費は **売った量** に比例します(変動売上原価・変動販売費は 800個分)。

### 全部原価計算との比較 {#full-pl}

**例2** 例1を全部原価計算で計算する。固定製造原価も製品の原価に入れるので、1個の製造原価は 400 + 300,000 ÷ 1,000 = 700。

| 項目 | 計算 | 金額 |
|---|---|--:|
| 売上高 | | 800,000 |
| 売上原価 | 800 × 700 | 560,000 |
| 売上総利益 | | 240,000 |
| 販売費及び一般管理費 | 40,000 + 100,000 | 140,000 |
| 営業利益 | | 100,000 |

全部原価計算では、売れ残った 200個に固定製造原価 200 × 300 = 60,000 が入ったまま翌期に繰り越されるので、その分だけ営業利益が大きくなります。

### 固定費調整 {#adjust}

直接原価計算の営業利益を、全部原価計算の営業利益に直します。

- 全部原価計算の営業利益 = 直接原価計算の営業利益 + **期末** 在庫の固定製造原価 − **期首** 在庫の固定製造原価

**例3** 例1・例2では、40,000 + 60,000 − 0 = 100,000(例2と一致)。

### 原価の予測(固定費と変動費に分ける) {#estimate}

**費目別精査法**: 勘定科目ごとに、経験から変動費か固定費かを決めます。直接材料費・外注加工賃は変動費、工場の減価償却費・固定資産税は固定費、のように分けます。

**高低点法**: 正常な操業の範囲(正常操業圏)の中で、操業度が **最高** の月と **最低** の月の2点を使います。

**例4** 正常操業圏は月 800〜1,200時間。電力料は、最高 1,200時間の月が ¥520,000、最低 800時間の月が ¥400,000 だった。

- 変動費率 = (520,000 − 400,000) ÷ (1,200 − 800) = 300(1時間あたり)
- 固定費 = 520,000 − 300 × 1,200 = 160,000(月額)

正常操業圏の外の月(故障で止まった月や、特別な大量注文の月など)のデータは使いません。

## T勘定・ボックス図 {#t-account}

### 2つの損益計算書の形 {#compare}

| 直接原価計算 | 全部原価計算 |
|---|---|
| 売上高 | 売上高 |
| − 変動費 | − 売上原価(固定製造原価を含む) |
| = 貢献利益 | = 売上総利益 |
| − 固定費(固定製造原価は全額) | − 販売費及び一般管理費 |
| = 営業利益 | = 営業利益 |

### 営業利益の大小 {#which}

| 生産量と販売量 | 営業利益が大きいのは |
|---|---|
| 生産量 > 販売量(在庫が増える) | 全部原価計算 |
| 生産量 < 販売量(在庫が減る) | 直接原価計算 |
| 生産量 = 販売量(期首・期末の在庫なし) | 同じ |

> [!覚える]
> - 貢献利益 = 売上高 − **変動費**(変動売上原価 + 変動販売費)
> - 直接原価計算では、固定製造原価は **全額** その期の費用
> - 全部原価計算の利益 = 直接原価計算の利益 + **期末在庫** の固定費 − **期首在庫** の固定費
> - 高低点法は **正常操業圏** の最高と最低の2点で、変動費率 = 原価の差 ÷ 操業度の差

## 引っかけポイント {#traps}

1. 変動販売費も変動費。貢献利益は、変動製造マージンからさらに変動販売費を引いた額。
2. 直接原価計算では、固定製造原価を売った量で分けない(全額を費用にする)。
3. 固定費調整は、期末在庫の分を足し、期首在庫の分を引く(逆にしない)。
4. 高低点法では、原価が最高・最低の月ではなく、操業度が最高・最低の月を使う。正常操業圏の外の月は除く。

## 決算書ではここに出る {#fs}

外部に公表する決算書は全部原価計算で作るので、直接原価計算の損益計算書は社内の管理用です。M&Aでは、在庫を増やすと全部原価計算の利益が大きく見えるので、利益が増えた年に在庫も大きく増えていないかを確かめます。貢献利益がわかると、売上が減ったときの利益の減り方を予測できます(K12)。
