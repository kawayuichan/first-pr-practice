# C27 連結②支配獲得後

## 要点3行 {#summary}

1. 連結の修正仕訳は各社の帳簿に残らないので、毎年、前期までの修正をもう一度行う(**開始仕訳**)。純資産の項目は「**当期首残高**」の名前で書く。
2. 当期の修正は、**のれん償却**(20年以内に定額法)、子会社の当期純利益のうち非支配株主の分の振替(**非支配株主に帰属する当期純利益**)、子会社の **配当** の修正。
3. 子会社の配当のうち、親会社の分は **受取配当金** と相殺し、非支配株主の分は **非支配株主持分** を減らす。

## 仕訳パターン {#patterns}

この章の例は、C26の例2の会社です。P社はS社の80%を ¥2,000,000 で取得し(支配獲得日のS社の純資産は資本金 1,500,000・資本剰余金 300,000・利益剰余金 400,000)、のれん 240,000 を10年で償却します。支配獲得後1年目に、S社は当期純利益 ¥300,000 をあげ、¥100,000 の配当をしました。

### 開始仕訳(1年目) {#opening}

**例1** 支配獲得日の相殺消去を、当期首残高の名前でもう一度行う。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 資本金当期首残高 | 1,500,000 | 子会社株式 | 2,000,000 |
| 資本剰余金当期首残高 | 300,000 | 非支配株主持分当期首残高 | 440,000 |
| 利益剰余金当期首残高 | 400,000 | | |
| のれん | 240,000 | | |

### のれん償却 {#amortization}

**例2** のれんを10年で定額法により償却する。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| のれん償却 | 24,000 | のれん | 24,000 |

のれん償却は、連結損益計算書の販売費及び一般管理費です。

### 子会社の当期純利益の振替 {#nci-income}

**例3** S社の当期純利益 300,000 のうち、非支配株主の分(20%)を振り替える。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 非支配株主に帰属する当期純利益 | 60,000 | 非支配株主持分当期変動額 | 60,000 |

子会社の利益は、いったん全額が連結の利益に入っています。そのうち非支配株主のものを取り出して、非支配株主持分を増やします。

### 子会社の配当の修正 {#dividend}

**例4** S社は ¥100,000 の配当をした(P社は 80% の 80,000 を受け取った)。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 受取配当金 | 80,000 | 剰余金の配当 | 100,000 |
| 非支配株主持分当期変動額 | 20,000 | | |

親会社が子会社から受け取った配当は、グループの中でお金が動いただけなので取り消します。非支配株主に払った分は、非支配株主持分を減らします。

### 2年目の開始仕訳 {#opening2}

**例5** 2年目は、例1〜例4をまとめて開始仕訳にする。損益の項目(のれん償却・非支配株主に帰属する当期純利益・受取配当金)と剰余金の配当は、**利益剰余金当期首残高** にまとめ、非支配株主持分の増減は **非支配株主持分当期首残高** にまとめる。

- 利益剰余金当期首残高 = 400,000 + のれん償却 24,000 + 非支配株主の利益 60,000 + 受取配当金 80,000 − 剰余金の配当 100,000 = 464,000
- 非支配株主持分当期首残高 = 440,000 + 60,000 − 20,000 = 480,000
- のれん = 240,000 − 24,000 = 216,000

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|--:|---|--:|
| 資本金当期首残高 | 1,500,000 | 子会社株式 | 2,000,000 |
| 資本剰余金当期首残高 | 300,000 | 非支配株主持分当期首残高 | 480,000 |
| 利益剰余金当期首残高 | 464,000 | | |
| のれん | 216,000 | | |

## T勘定・ボックス図 {#t-account}

### 連結損益計算書の最後の部分 {#cpl}

**例6** 1年目。P社の当期純利益は ¥700,000(S社からの受取配当金 80,000 を含む)。

| 項目 | 金額 |
|---|--:|
| 当期純利益 | 896,000 |
| 非支配株主に帰属する当期純利益 | 60,000 |
| 親会社株主に帰属する当期純利益 | 836,000 |

当期純利益は、P社 700,000 + S社 300,000 − のれん償却 − 受取配当金(グループ内の配当)で計算します。

> [!覚える]
> - 開始仕訳では、純資産の項目を **当期首残高** の名前で書く
> - のれん償却 = のれん ÷ 償却年数(**定額法**)
> - 子会社の利益 × **非支配株主の比率** を非支配株主持分へ
> - 子会社の配当: 親会社の分は **受取配当金** を消し、非支配株主の分は **非支配株主持分** を減らす

## 引っかけポイント {#traps}

1. 2年目の開始仕訳には、支配獲得日の相殺だけでなく、1年目ののれん償却・利益の振替・配当の修正も入る(損益の項目は利益剰余金当期首残高にまとめる)。
2. 非支配株主に帰属する当期純利益は、子会社の利益に非支配株主の比率をかける(親会社の比率ではない)。
3. 子会社の配当の相手は剰余金の配当(子会社の利益剰余金の減少を取り消す)。
4. 親会社株主に帰属する当期純利益は、連結の当期純利益から非支配株主の分を引いたもの。

## 決算書ではここに出る {#fs}

連結損益計算書の最後に「非支配株主に帰属する当期純利益」と「親会社株主に帰属する当期純利益」が出ます。M&Aや投資では、親会社の株主のものになる **親会社株主に帰属する当期純利益** を見ます。のれん償却が大きいと、毎年の利益が押し下げられます。
