# 学習順の提案(3級未学習から2級合格まで)

論点IDは [scope.md](scope.md) の論点リストと同じです。

## 結論

- 必要な勉強時間の目安は **約330時間**。平日1時間×5日+休日3時間×2日=**週11時間** で **約30週** かかります。
- 2026年12月に始めると、一通り終わるのは **2027年6月末ごろ**。**受験は2027年7月ごろ** を目安にし、遅れたら8月にずらします。
- 3級の試験は受けなくても2級を受験できます。3級の内容は Phase 0 で2級の土台として学びます。
  - 注意: 2027年3月31日までに3級を受けると旧範囲(手形・小切手あり)で出題されます。

### Phase 0 3級の土台(B01〜B14)

3級は未学習なので、2級に必要な部分を **全部** ここでやります。

1. B01 簿記の基本 → B02 帳簿と伝票
2. B03 現金・預金 → B04 三分法 → **B05 売上原価対立法**
3. B06 売掛金・買掛金・電子記録債権 → B07 その他の債権債務 → B08 貸倒引当金
4. **B09 有形固定資産①** → B10 経過勘定 → B11 税金 → B12 株式会社の資本
5. **B13 決算①** → **B14 決算②**

太字は、2級で特につまずきやすい所です。
- B05・B09 は2027年度に2級から3級へ移った論点です。2級でも前提として出ます。
- B13・B14(精算表と決算の流れ)は、2級の第3問(総合問題)の土台です。ここは問題を多めに解きます。

### Phase 1 2級商業簿記の個別論点(C01〜C20)

3級の続きから入り、仕訳(第1問)で問われる論点をそろえます。

1. 3級の延長: C01 商品売買(2級) → C02 貸倒引当金(2級) → C03 引当金 → C04 債務の保証
2. 預金・債権: C05 銀行勘定調整表 → C06 電子記録債権(2級) → C07 ファクタリング
3. 有価証券: C08 売買目的 → C09 満期保有・子会社・その他有価証券
4. 固定資産: C10 取得 → C11 償却ほか → C12 無形固定資産 → **C13 リース(新基準)**
5. 収益: **C14 収益認識** → C15 役務収益・役務原価
6. 外貨と税金: C16 外貨建取引 → C17 税金(2級) → **C18 税効果会計**
7. 会社: C19 純資産(2級) → **C20 合併**

### Phase 2 工業簿記(K01〜K13)

工業簿記は第4問・第5問で、暫定配点では100点中40点です。パターンが決まっていて得点しやすいので、商業簿記の総合問題の前に固めます。

1. 基礎と費目別計算: K01 → K02 材料費 → K03 労務費 → K04 経費 → K05 製造間接費
2. 製品別計算: K06 部門別計算 → K07 個別原価計算 → K08 総合原価計算① → K09 総合原価計算②
3. 第5問対策: K10 標準原価計算 → K11 直接原価計算 → K12 CVP分析
4. 仕上げ: K13 製品の受払い・本社工場会計

### Phase 3 2級商業簿記の総合問題(C21〜C29)

第2問・第3問の大問です。時間がかかるので休日に解きます。

1. 財務諸表: C21 決算整理と精算表 → C22 財務諸表 → C23 株主資本等変動計算書 → C24 製造業の決算
2. C25 本支店会計
3. **連結**: C26 資本連結 → C27 支配獲得後 → C28 成果連結 → C29 連結精算表

### Phase 4 模試と弱点つぶし

- 模試モード(5問・90分)を週1〜2回
- 弱点ランキングの上位の論点を、参考書に戻って解き直す

## 1週間の使い方

| いつ | やること |
|---|---|
| 平日の通勤(1時間・スマホ) | ① 復習キュー(1日後・3日後・7日後の再出題)を先に消化 → ② その週の論点の仕訳ドリル |
| 休日(3時間) | ① 新しい論点の参考書を読む → ② 確認問題 → ③ 計算問題・総合問題(第2問〜第5問形式) |

- 平日に新しい論点を読むのは短い論点だけにして、長い論点は休日に回します。
- 間違えた問題は自動で復習キューに入るので、平日は「アプリを開いて上から解く」だけで回るようにします。

## M&A業務につながる論点

決算書を読む力に直結するので、参考書では各章に「決算書ではどこに出るか」を一言入れる案があります(→ 確認事項)。

| 論点 | 決算書・M&Aでの使いどころ |
|---|---|
| C26〜C29 連結 | 連結財務諸表の読み方。のれん・非支配株主持分の意味 |
| C20 合併、C12 のれん | 買収で生まれるのれんと、その償却 |
| C13 リース | 新基準で借りている資産も貸借対照表に載る(使用権資産・リース負債)。負債の見え方が変わる |
| C14 収益認識 | 売上をいつ・いくら計上するか。売上の質の確認 |
| C18 税効果会計 | 繰延税金資産・負債の意味 |
| C09 子会社株式・その他有価証券 | 個別財務諸表での株式の評価 |
